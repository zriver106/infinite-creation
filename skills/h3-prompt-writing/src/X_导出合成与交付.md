## X 导出、合成与交付（导出、审片、管理会话读；写提示词不读）

X-001–X-009 原样迁自规则文档库「导出合成通用规则」（2026-11-25，编号不变）；文中「错误案例」指规则文档库里的案例文件，不在规则书。X-010–X-012 是 2026-11-25 新增。导出代码的门禁按本段执行（代码改动另做）。

执行方：X-001–X-009 由导出环节（导出程序、做导出和交付的人）和审片执行；X-010、X-012 由管理会话执行；X-011 由导出环节或管理会话执行。IC 写稿不加载本段（用到时再查），写稿要做的部分在 A 段（A-002 第3条、A-006）。

### 〔X-001〕 【待测】字幕文字只取分镜 dialogue，语音识别只用来对时间（G18，txt L132、L166、L168）

- 原则：字幕上的每个字都要和台词原文一样。语音识别会把词听成同音的别的字，它的转写原文不能当字幕。
- 适用条件：每次导出带字幕的成片或单独导出字幕文件时；做导出的人或导出程序。
- 正确写法：
  1. 字幕文字只从分镜的 dialogue 字段取，逐字照用，不改写、不缩写、不补字。
  2. 语音识别只提供每句话的起止时间；识别出来的文字只用来找到对应的那句 dialogue，不进字幕。
  3. 识别失败、对不上 dialogue 或字幕服务不可用时，停止导出并报错，不拿识别原文、提示词里的台词或别的来源顶上。
  4. dialogue 为空的镜没有字幕；dialogue 有而成片里没念出来的，按 X-003 第 4 条处理，不删字幕了事。
  5. 字幕只显示台词本身，不带说话人名和说话方式的标注。
- 可用短句：
  - 操作句：「字幕文字取 dialogue，识别只对时间；识别或对时失败即停，不回退识别原文。」
  - 检查句：「字幕文件逐条在 dialogue 里能找到一字不差的原句。」
- 错误案例：见 `docs/通用规则_错误案例.md` CASE-001、CASE-002、CASE-003

### 〔X-002〕 【待测】字幕单层不重叠，烧字幕只做一次（G18，txt L48）

- 原则：任何时刻画面上最多一条字幕，观众才看得清。
- 适用条件：生成字幕时间轴、把字幕烧进画面、重新导出已交付过的集时。
- 正确写法：
  1. 字幕只有一层。按时间排序后，每一条的结束时间不晚于下一条的开始时间；相交时把前一条的结束时间提前到下一条开始之前，不让两条同时显示。
  2. 一条字幕一行放不下时，在标点处拆成前后两条、各占自己的时间段，不让它自动折行压到别的字幕或画面内容上。
  3. 烧字幕只在最终合成时做一次，输入用不带字幕的干净片。重新导出前先确认输入片上没有旧字幕；已经烧过字幕的成片不作为再次导出的输入。
  4. 导出前检查时间轴：有任意两条时间相交就停止导出并报错。
- 可用短句：
  - 操作句：「烧字幕前确认输入片是无字幕的干净片；本次只烧一层。」
  - 检查句：「字幕按时间排序后，逐条满足：本条结束 ≤ 下一条开始。」
- 错误案例：见 `docs/通用规则_错误案例.md` CASE-004

### 〔X-003〕 【待测】交付前核对字幕：和 dialogue 逐字比、和语音对着听（G18，txt L70、L132、L166、L168）

- 原则：字幕、dialogue、听到的话三者是同一句，并且同时出现。前两条规则管住导出，本条管交付前的最后一关。
- 适用条件：每集交付前；台词改过或有镜头重出后重新交付前；做交付检查的人。
- 正确写法：
  1. 文字比对：把要交付的字幕文件逐条和该集各镜的 dialogue 比（去掉标点后逐字相同）。有一条对不上就不交付。
  2. 时间比对：按 X-002 第 4 条查一遍没有重叠。
  3. 听看一遍：带声音、正常速度从头看到尾，每条字幕在那句话响起时出现、说完后消失，文字和听到的话一致。
  4. 发现语音和字幕不符时，先分清是哪一边错，再处理：
     - 字幕文字和 dialogue 不同：字幕错，按 X-001 重新导出字幕。
     - 文字对、出现的时间不对：重新对时，或手工调整这一条的起止时间。
     - 字幕和 dialogue 一致，但语音念错、漏念或念成别的话：语音错，登记重出该镜；不改字幕去迁就念错的语音。
     - dialogue 和提示词里要念的台词本来就不一致：退回写稿环节改齐（写稿规则 E-004、E-010），再重出、重新导出。
  5. 写稿规则里标明「显示的字和念出来的字不同」的谐音替换台词是唯一例外：字幕照 dialogue 显示，语音照替换后的读法，听看时不算不符。
  6. 台词改过或镜头重出后，该集字幕整份重新导出，不沿用旧字幕文件。
- 可用短句：
  - 检查句：「字幕与 dialogue 逐字比对：0 条不一致；时间重叠：0 处；带声音通看一遍：字幕与语音一致。」
  - 登记句：「字幕不符，属〔字幕文字错／字幕时间错／语音念错／dialogue 与提示词不一致〕，处理：〔重新导出字幕／重新对时／重出该镜／退回写稿〕。」
- 错误案例：见 `docs/通用规则_错误案例.md` CASE-001、CASE-005

### 〔X-004〕 【待测】交付片只从当前选用片导出，交付前逐镜对账（G19，txt L213、L222）

- 原则：用户看到的交付片，必须就是制作系统里现在选用的那一版。镜头重出、改稿、换选用以后，旧的交付片就过期了，不能继续当交付版。
- 适用条件：每集交付前；任何一镜重出、换选用片或改稿之后；做导出和交付的人。
- 正确写法：
  1. 交付片只由导出环节从制作系统当前选用片生成。手工拼接、另行重剪、放大的文件不直接放进交付目录；确需例外时由负责人明确指令，并按第 5 条留记录。
  2. 每次导出同时出一份交付清单：每镜的编号、选用视频的标识和生成时间、时长，导出记录的标识，成片文件的校验值。
  3. 交付前对账：按镜号顺序把制作系统当前选用片和交付清单逐镜比。选用视频不同、镜数不同或总时长对不上，这一集就是「交付落后」，不交付，重新导出。
  4. 一集里任何一镜重出并选用、换了选用片或改了稿，这一集的交付片立即记为「已过期」，重新导出并重新对账后才算交付版。
  5. 每次往交付目录写文件都留记录：时间、写入人、来源文件和校验值、对应的导出记录或指令、被替换的旧文件校验值。没有记录的覆盖视为违规。
  6. 对账只说明交付片和当前选用片一致，不说明当前选用片本身没问题；选用片是否过时按 X-007 查。
- 可用短句：
  - 检查句：「交付对账：共〔N〕镜，交付所用视频与当前选用片逐镜一致；总时长一致；落后 0 镜。」
  - 登记句：「〔集〕交付落后：〔镜号〕当前选用片晚于交付所用片，处理：重新导出。」
- 错误案例：见 `docs/通用规则_错误案例.md` CASE-007、CASE-010

### 〔X-005〕 【待测】新片出来先审片选片，每个新片都有结论，再导出（G19，txt L215）

- 原则：出了新片不等于用上了新片。没人选，导出时用的还是旧片，重出的功夫白费，问题原样留在交付片里。
- 适用条件：一集里有镜头重出过、而且要重新导出交付时；审片的人和做导出的人。
- 正确写法：
  1. 每个重出的新片都要有选片结论：「选用」或「不用（写原因）」。没有结论的不算审完。
  2. 导出前列出本集「有比当前选用片更新的片、但还没有选片结论」的镜。清单不为空就不导出，先回审片（审片规则 Q-004）。
  3. 新片审过不合格、决定继续用旧片的，写明「保留旧片」和原因；旧片原来被指出的问题仍然算未解决，继续留在问题清单里。
  4. 选片全部有结论后再导出，导出后按 X-004 对账。
- 可用短句：
  - 检查句：「本集重出〔N〕镜：选用〔a〕镜，不用〔b〕镜（均有原因），未选 0 镜；可以导出。」
  - 登记句：「〔镜号〕新片未选，退回审片；本集暂不导出。」
- 错误案例：见 `docs/通用规则_错误案例.md` CASE-009

### 〔X-006〕 【待测】全剧交付规格统一：分辨率、帧率、画幅一个标准（G19，txt L214）

- 原则：同一部剧各集的清晰度和画幅要一样。有的集单独放大、有的集没放大，连着看会忽清忽糊。
- 适用条件：每次导出交付片；决定做放大（提高分辨率）时；做导出和交付的人。
- 正确写法：
  1. 交付规格（分辨率、帧率、画幅比例、编码）每个项目只有一份，写在该项目的项目常量里；规则里不写具体数值。
  2. 导出后逐集探测成片的实际分辨率、帧率和画幅，和项目常量比，不一致不交付。
  3. 放大是全剧统一的一步：要么全部集都做，要么都不做，并且放在全部集定稿之后。不单独给某几集先放大后交付。
  4. 改交付规格时，已经交付的各集一起按新规格重新导出，不留新旧两种规格混着。
  5. 同一集内各镜的源片规格不同（例如重出的镜和旧镜分辨率不一样）时，在导出时统一到交付规格，并在交付清单里注明哪些镜是缩放过的。
- 可用短句：
  - 检查句：「全剧〔N〕集交付片实测规格一致，与项目常量相同；不一致 0 集。」
  - 登记句：「〔集〕实测规格与项目常量不同，处理：按统一规格重新导出。」
- 错误案例：见 `docs/通用规则_错误案例.md` CASE-008

### 〔X-007〕 【待测】改稿或换资产后，旧片镜要列清单；局部重出要和没重出的镜对上（G19、G27，txt L205、L222、L223）

- 原则：稿子或资产改了，在这之前出的片就可能和现在对不上（衣服、场景、人物）。只重出一部分镜时，新镜和旧镜放在一起也可能对不上。这两种情况都要在导出前查出来，不能不提示就导进交付。
- 适用条件：人物、服装、场景、道具的资产换过图，或提示词里的服装、场景定义改过之后；一集只重出部分镜时；做导出的人，配合审片的人。
- 正确写法：
  1. 旧片清单：导出前列出本集「选用片的生成时间早于它所绑资产最近一次换图时间、或早于它的提示词、visual、dialogue、sub_shots、绑定最近一次修改时间」的镜，标为「旧片」（2026-11-26 补；案-A-X007-E22S03-01，执行方管理会话）。
  2. 旧片逐镜给结论：「重出」或「保留（写原因、谁定的）」。有旧片没结论，这一集不导出。
  3. 同一场戏里只重出部分镜时，把重出的镜和它前后没重出的镜连着看：同一人的衣服、同一个场景、同一件道具要一样。对不上就把同场没重出的镜一并列入重出，按同一套现行资产和现稿出；不拿对不上的新旧镜拼成一集交付。
  4. 一场戏补绑或换了场景资产后，这场戏的所有镜都按新资产出，不只重出当初被指出问题的那几镜。
  5. 重出的片按新片审（审片规则 Q-004）：原来的问题改掉了，并且没有带出新问题，才选用。
- 可用短句：
  - 检查句：「本集旧片〔N〕镜：重出〔a〕镜，保留〔b〕镜（均有原因和决定人），无结论 0 镜。」
  - 检查句：「重出镜与同场未重出镜连看：服装、场景、道具一致；不一致 0 处。」
  - 登记句：「〔镜号〕为旧片（早于〔资产换图／改稿〕），与现稿〔服装／场景／人物〕不符，处理：〔重出／保留，原因〕。」
- 错误案例：见 `docs/通用规则_错误案例.md` CASE-006、CASE-010、CASE-011

### 〔X-008〕 【待测】BGM 在导出时对整集一次合成；改了镜头就整集重新合成，不在混好的成片上打补丁（G20，txt L178）

- 原则：BGM 是铺在整集时间线上的一条连续的轨。在已经混好 BGM 的成片上切一段、换一段、静音一段或另铺一段底噪，音乐就会在接缝处断、跳或重复，听起来就是卡壳。
- 适用条件：每集合成 BGM 时；交付后有镜头重出、换片、改时长需要再出成片时；做导出合成的人。
- 正确写法：
  1. 分轨保存：各镜的原声（对白、现场声）和 BGM 分开保存。合成的输入永远是不带 BGM 的干净原声片加 BGM 轨，不拿已经混了 BGM 的成片再加工。
  2. 一次合成：画面拼接定下来以后，BGM 按 Cue 表对整集时间线合成一次。不按镜、按块各自铺好 BGM 再拼起来。Cue 表、主曲连续、交接淡变和循环接缝的做法，按 `剪辑与配乐基础规范.md` B01、B03 和其中的淡变时长、循环条款。
  3. 改了就重合：任何一镜重出、换片或时长变了，先重拼画面和原声，按新时长重排 Cue 表，再把整集 BGM 重新合成一遍。不在旧成片上只替换那一段。
  4. 不用静音加循环底噪去补一段声音。确实要修某一镜的声音，在该镜的原声上修，修完按第 3 条整集重合。
  5. 另行重剪、试验用、自己标了「不作交付」的版本不进交付目录；交付片只走导出环节（X-004 第 1 条）。
  6. 写稿环节不让模型在镜内出配乐（写稿规则 B-001），所以成片里的音乐只应该来自这一条 BGM 轨；听到镜内自带音乐，按审片规则 Q-005 第 4 条处理。
- 可用短句：
  - 操作句：「本集有镜头变动：重拼干净原声片，重排 Cue 表，整集 BGM 重新合成；不沿用旧成片的音轨。」
  - 检查句：「本次合成输入为无 BGM 的原声片加 BGM 轨；BGM 整集一次合成；没有在已混音成片上做局部替换、静音或铺底噪。」
- 错误案例：见 `docs/通用规则_错误案例.md` CASE-012

### 〔X-009〕 【待测】交付前查 BGM 连续：机检接缝，再整集听一遍并留记录（G20，txt L178）

- 原则：BGM 卡壳只有听才能确认。波形和响度检查能提示可疑位置，不能代替耳朵；没听过就不能写「配乐已核」。
- 适用条件：每集配了 BGM 的成片交付前；整集 BGM 重新合成之后；做交付检查的人。
- 正确写法：
  1. 机检（提示可疑位置）：在 BGM 轨上查 Cue 表以外的突然断开、音量突跳和整段无音乐。Cue 表登记的静场段和登记为硬切的位置不算；判定阈值按 `剪辑与配乐基础规范.md` B03、B04 的检查项。
  2. 对 Cue 表：BGM 实际的起止、交接和循环位置和 Cue 表一致；成片时长变过而 Cue 表没重排的，退回 X-008 第 3 条。
  3. 听一遍：带声音、正常速度把整集从头听到尾，重点听镜头接缝、重出过的镜前后、曲子交接和循环处。听这五样：音乐突然断一下或顿一下、跳拍、同一小段来回重复、底噪或环境声突然断开或换了一种、音乐盖住台词。
  4. 留记录：听的人、时间、听的是哪个成片文件（校验值）、结论和有问题的时间点。没听的写「未听」，不写通过。
  5. 听出问题：回到 X-008 重新合成整集 BGM，不在成片上就地修；重合后再从第 1 条查起。
  6. 这一遍可以和 X-003 第 3 条的字幕听看合在一次做，但两项各写各的结论。
- 可用短句：
  - 检查句：「BGM 听审：整集听完，无卡顿、无跳拍、无重复段、底噪连续、台词清楚；与 Cue 表一致。听审人〔 〕，时间〔 〕，文件校验值〔 〕。」
  - 登记句：「〔时间点〕BGM〔断／顿／跳拍／重复／底噪断开／盖住台词〕，处理：整集重新合成 BGM 后重听。」
- 错误案例：见 `docs/通用规则_错误案例.md` CASE-012

### 〔X-010〕 【待测】【通用】规则口径变更后全剧存量扫描

- 目的：口径改了，旧写法还留在已写好的镜里（例如心声改口径后，旧的后期配音写法漏网出片）。
- 做法：管理会话在规则改口径时，同时写出按新口径查旧写法的检查项（关键词或检查器）；用它扫全剧未交付和已交付的镜，列出命中清单，逐镜走 IC 重写、重出。
- 要求：清单清零（或逐镜写明保留原因和决定人）之前，不宣布新口径已生效。写作者遇到旧写法怎么改见 A-006。
- 校验：扫描报告写明检查项、扫描范围、命中数和每镜处理结果。
- 正例：心声口径改了，当天按新检查项扫全剧，旧写法的镜列清单逐一重写，清单清零后宣布生效。
- 反例：只改规则文字，不扫存量，几集后旧写法的镜照样出片。
- 案例（项目规则案例库，待建）：案-C-X010-E30S01-01

### 〔X-011〕 【待测】【通用】导出前核写入来源

- 目的：防外部改稿绕过 IC（A-002）：外部写进库的稿子，服装、场景锁常常不全。
- 做法：导出环节（或管理会话）导出前逐镜查提示词最后一次写入是否来自 IC 写稿任务（对写入记录和提示词历史的时间与任务）。
- 要求：不是 IC 写的镜列清单，回 IC 重写重出，或由负责人逐镜写明接受；清单没处理完不导出。
- 校验：导出报告写「非 IC 来源镜＝0」，或列明已接受的镜和决定人。
- 正例：导出前查出两镜是脚本直接写库，退回 IC 重写、重出、选用后再导出。
- 反例：只看片子质量没问题就导出，没查来源，交付里混着外部改的稿。

### 〔X-012〕 【待测】【通用】导出前做同人同装、同场景对照审查

- 目的：绑定对了不等于成片对了（颜色跑了、短裤变长裤、换脸、背景空场、桌上菜时有时无），这些只有拿成片对照才看得出，不能等用户看片发现。
- 做法：每集导出前，由管理会话按服装资产分组，第一格放资产图，后面放绑了它的每镜现选片中间帧，拼成对照图；按场景资产再拼一张（看背景人数、桌面）。交独立审片会话逐张看：颜色、款式、脸、伤妆、背景人群、桌面是否与资产图和相邻镜一致。
- 补充做法（2026-11-26）：
  1. 衔接对照：把每对相邻镜的上一镜尾帧和下一镜头帧并排，逐对看站位（左右、朝向）、服装、人数、道具、场景是否接得上。
  2. 声音检查：没念出声、念错按 X-003 第 4 条处理；另用语音转写查没台词的时段却有人声（E-013）。
- 要求：写稿、分镜 Agent 不做本条；高、中问题修完才导出；对照图和审查结论随交付记录保存；「有人物却没绑他的服装」的镜一并列出。
- 校验：交付记录里有本集对照审查结论（含衔接对照和声音检查），高、中问题数为 0。
- 正例：导出前拼出某角色裙子的对照图，一眼看出两镜近景跑成鲜红，修完再导出。
- 反例：只核绑定 ID 一致就导出，用户看片才发现裙子变色、背景空场。
- 案例（项目规则案例库，待建）：案-A-X012-E19S24-01
