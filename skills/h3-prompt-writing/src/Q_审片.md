## Q 审片

### 〔Q-001〕 【审片】逐镜要看的已验证项

审片（成片、预览、抽帧）时逐镜对下面各项，看到就按原规则记问题，写清类别：

1. 同一个人在画面里出现两次（含前景半截头肩、画面边缘、倒影）；在场的人突然消失或突然多出一个人（TR-B03）。
2. 同场同一人物的衣服变了，而原著这里没换衣服（TR-B02）。
3. 脸部状态（眼袋、疲态、气色）和剧情节点对不上（TR-V01）。
4. 系统说话时光幕没同秒出来；光幕字超过两行、看不清、带「」『』【】；系统声没念出来（TR-V04、系统声）。
5. 特效为了出效果切了近景（TR-V05）；交易少了步骤或用了替代物（TR-V06）；打戏反应慢、有人发呆、人群飘着后退（TR-V08）。
6. 人物为了听心声停下动作；心声镜里嘴在动（TR-V09、心声节）。
7. 同场相邻两镜人物左右位置互换、坐变站没有动作（TR-V10）。
8. 电话那头的声音中途变了（TR-V02）；关键道具变大变小（TR-V03）；念出来的数字读法不对（TR-V14）。
9. 整个画面变成了参考图、三视图或灰色棚拍背景（TR-B01）。

审片流程：问题分大、中、小，只有大问题（影响主线、换人换衣、同一人出现两次、声音给错人、参考图泄漏）进本轮重出，其余记账（TR-A02）；已经通过的集不整集重出，只重出有问题的镜（TR-H01、TR-S01）。

### 〔Q-002〕 【待测】【审片】待测项也要看

审片时，除【审片】已验证项外，也逐镜看：前景半截头肩或倒影里多出一个人（TR-B09）；镜头旁多补出一个人（TR-D01）；坐站、座位前后对不上（G07）；桌上东西数量或位置变了、多出东西（TR-B06–B08）；背景人群忽有忽无（G05）；说话的人没看说话对象（G06）；相邻镜、跨集首镜衔接不上（G17、TR-C02）；小角色换了性别或长相（G01、G02）；场景用途不对、背景来回跳（TR-V17、G08）；道具牌子型号不对（G10）；动作或台词不合原著（G23）。一镜出了问题，当场扫一遍全剧同样写法的镜，一起登记（TR-P01）。字幕另按 Q-003 看。重出的片和选片另按 Q-004 看。配乐另按 Q-005 听。剧情、动作和台词看不看得懂另按 Q-006 看。台词是不是对的人说的另按 Q-007 看。念出来的数字和关键词听得准不准（听成另一个词也算），对照 adapt-rules R-003、E-012 的写法查。物理穿帮和机位拍错空间另按 Q-008 看。场景看着像不像它该是的地方另按 Q-009 看。

### 〔Q-003〕 【待测】【审片】字幕三项：错字、重叠、和语音不符（G18，txt L48、L70、L132、L166、L168）

- 原则：字幕问题大多出在导出环节，不在镜头本身。审片要把它看出来，并且分清该重新导出还是该重出镜，不因为字幕错去重出镜头。
- 适用条件：审带字幕的成片或预览时；审片的人。和 Q-001、Q-002 的逐镜项一起看，本条只管字幕。
- 正确写法：
  1. 错字：逐条看字幕，对照该镜的 `dialogue`，逐字相同。重点看同音字、近音字（听起来对、字不对）。
  2. 重叠：同一时刻画面上只有一条字幕；看到两条叠在一起、字幕压字幕，记下时间点。
  3. 和语音不符：带声音看，字幕和听到的是同一句，并且在那句话响起时出现。
  4. 登记时写清属哪一边错：字幕文字和 `dialogue` 不同、字幕重叠、字幕时间不对，记为「字幕／导出」问题，按导出合成通用规则 X-001、X-002、X-003 重新导出，不重出镜；字幕和 `dialogue` 一致而语音念错、漏念，才记为该镜的声音问题，进重出。
  5. 字幕问题不按大、中、小排队等下一轮：重新导出不占出片，发现的当轮改完再交付。
- 可用短句：
  - 检查句：「字幕逐条对 dialogue：无错字；无重叠；与语音同句同时。」
  - 登记句：「〔时间点〕字幕〔错字／重叠／与语音不符〕，属〔字幕导出／该镜语音〕，处理：〔重新导出字幕／重出该镜〕。」

### 〔Q-004〕 【待测】【审片】重出的片按新片审，审完每个新片都要有选片结论（G19、G27，txt L205、L215、L222、L223）

- 原则：重出只说明出了新片，不说明问题改好了。新片可能原问题还在，也可能带出新问题；审了不选，导出用的还是旧片。
- 适用条件：审重出的镜（返修片、局部重出片）时；一集里新旧镜混在一起时；审片的人。
- 正确写法：
  1. 重出的片当新片从头审，Q-001、Q-002 的各项都看一遍，不只看原来被指出的那一项。
  2. 对着原问题看：原来登记的问题在新片里确实没有了，才算改掉。
  3. 连着前后镜看：重出的镜和同场没重出的镜放在一起，同一人的衣服、同一个场景、同一件道具一样；重出后和别的人撞衫、背景换了地方、人换了，都算新问题，照常登记。
  4. 审完给每个新片写结论：「选用」或「不用（原因）」，并在制作系统里把选用片选上。有新片没结论，这一集不算审完，不能导出（导出合成通用规则 X-005）。
  5. 看到一镜明显是旧片（衣服、场景和现稿或同场别的镜不一样），按「旧片」登记，交导出环节按 X-007 列清单处理，不当成这一镜单独的问题反复重出。
- 可用短句：
  - 检查句：「重出〔N〕镜逐镜重审：原问题已改；无新问题；与前后镜一致。选用〔a〕镜，不用〔b〕镜。」
  - 登记句：「〔镜号〕重出片：原问题〔已改／仍在〕，新问题〔无／写明〕，结论：〔选用／不用，原因〕。」
- 错误案例：见 `C:\Users\usazr\Documents\moviePro\docs\通用规则_错误案例.md` CASE-006、CASE-009、CASE-011

### 〔Q-005〕 【待测】【审片】听配乐：卡壳、跳拍、重复、底噪断开（G20，txt L178）

- 原则：配乐卡壳出在合成环节，不在镜头本身。审片要带声音听出来，并且记成导出问题去重新合成，不因为配乐卡壳去重出镜头。
- 适用条件：审配了 BGM 的成片时；审片的人。和 Q-001、Q-002 的逐镜项分开，本条只管配乐和底噪。
- 正确写法：
  1. 带声音、正常速度听整集，不静音看、不只抽帧。重点听镜头接缝和重出过的镜前后。
  2. 听这五样，听到就记时间点：音乐突然断一下或顿一下、跳拍、同一小段来回重复、底噪或环境声突然断开或换了一种、音乐盖住台词。
  3. 这五样都记为「配乐／导出」问题，按导出合成通用规则 X-008 整集重新合成、X-009 重听，不重出镜。
  4. 例外：音乐是镜头自己带出来的（去掉 BGM 轨，单听这一镜的原声里就有音乐），记为该镜的问题，按 B-001 改稿重出。
  5. 配乐问题和字幕问题一样，当轮重新合成后再交付（同 Q-003 第 5 条）。
- 可用短句：
  - 检查句：「配乐整集听完：无卡顿、无跳拍、无重复段、底噪连续、台词清楚。」
  - 登记句：「〔时间点〕配乐〔断／顿／跳拍／重复／底噪断开／盖住台词〕，属〔配乐导出／该镜自带音乐〕，处理：〔整集重新合成 BGM／改稿重出该镜〕。」

### 〔Q-006〕 【待测】【审片】剧情看不看得懂：动作有没有原因、台词听不听得懂、场和场接不接得上（G23，txt L25、L57、L59、L60、L65、L71、L99、L116、L131、L133–L136、L146）

- 原则：审片的人要站在没看过原著的观众位置上看。这类问题出在剧本和分镜，重抽同一份提示词改不掉。本条细化 Q-002 里「动作或台词不合原著（G23）」一句，Q-002 不变。
- 适用条件：审成片或预览时；审片的人。先不看原著和分镜通看一遍，再对原著查有疑问的地方。
- 正确写法：
  1. 动作：人物做的每个大动作（起身、坐下、走开、推打、鼓掌这类）看得出原因，而且原著里有。看不出原因或原著没有的，记下。
  2. 台词：每句台词听得出是谁对谁说、说的什么事。听不懂、不知道在回应什么、意思和原著不一样的，记下原句。
  3. 语气：语气和人物这时候的处境相符（服软的不意气风发）。
  4. 衔接：换场以后知道人物在哪、怎么来的；一句回应的台词之前，看得到它回应的那件事；中间没有跳过观众需要知道的事。
  5. 登记时写清该谁改：台词怎么写、语气标注归剧本（adapt-rules R-002）；动作、进场、衔接镜归分镜（adapt-rules S-016、S-011）；分镜是对的而提示词多写、换了动作或语气写反，归提示词（L-004）；分镜和提示词都对、只是这一次出片演错了，才直接重出。前两种先改稿再重出，不拿原提示词重抽。
- 可用短句：
  - 检查句：「不看原著通看一遍：动作都有原因；台词都听得懂；语气合处境；换场接得上。」
  - 登记句：「〔时间点〕〔动作没原因／台词听不懂／语气不对／场间接不上〕：〔现象〕；应为〔按原著的写法〕；归〔剧本／分镜／提示词／出片〕，处理：〔改稿后重出／重出〕。」
- 错误案例：见 `C:\Users\usazr\Documents\moviePro\docs\通用规则_错误案例.md` CASE-013 至 CASE-022

### 〔Q-007〕 【待测】【审片】每句台词是不是对的人说的（G13，txt L84）

- 原则：台词挂错人，剧情就变了味。Q-001 已把「声音给错人」列为大问题，那是声音和人对不上；本条查的是这句话本来就不该由这个人说。Q-001 不变。
- 适用条件：审有两个以上人物在场、有出口台词的镜时；审片的人。
- 正确写法：
  1. 逐句看：成片里这句话是谁说的，对照这一镜 `dialogue` 的说话人，是不是同一个人。
  2. 有疑问的再对原著：这句话在原著里是谁说的。`dialogue` 的说话人和原著不一样，也算挂错人。
  3. 重点看这几种镜：邻桌、路人、店员这类小角色有台词的镜；一镜里三个人以上的镜；说话人在背景里或在画面边上的镜。
  4. 登记时写清错在哪一步、该谁改：`dialogue` 的说话人和原著不一样，或说话人没绑进这一镜，归分镜（adapt-rules S-017），先改稿补绑再重出；`dialogue` 和绑定都对、提示词把这句写到了别人名下，归提示词（E-011）；稿子都对、只是这次出片由别人说了，按「声音给错人」直接重出。
  5. 这一项算大问题，进本轮重出。
- 可用短句：
  - 检查句：「有台词的镜逐句核对：成片说话人和 dialogue 说话人一致，和原著一致。」
  - 登记句：「〔时间点〕台词『……』成片由〔甲〕说，应为〔乙〕说；归〔分镜／提示词／出片〕，处理：〔改稿补绑后重出／重出〕。」

### 〔Q-008〕 【待测】【审片】物理穿帮和机位拍错空间（G23，txt L141、L151）

- 原则：人从栏杆里穿过去、戏在车里却拍车外，观众一眼就出戏。这两种多半是分镜没定清楚，光重抽不一定改得掉，登记时要分清该改哪一步。
- 适用条件：审有人物走动、过门、上下楼的镜，和戏在车内、电梯、隔间这类空间里的镜时；审片的人。
- 正确写法：
  1. 穿帮：人或东西穿过实体（栏杆、墙、玻璃、门、柜台、家具、车身、别人）；脚没踩在地面或台阶上；手里的东西穿过身体或桌面。看到就记时间点和穿过了什么。
  2. 机位空间：对照分镜，这一镜的机位该在里面还是外面、该对着谁。戏在里面而画面拍的是外面，或对着的不是戏里的人，记下。
  3. 登记时写清归哪一步：分镜没写机位在哪个空间、路线本身走不通或没必要地用了楼梯和门，归分镜（adapt-rules S-018）；分镜写了而提示词没落下去，归提示词（H1-004）；两边都写清了、只是这次出片穿了，直接重出。
  4. 同一镜重出过仍然穿帮：不再原样重抽，退回分镜按 S-018 第 4 条避开那个结构（改走平地，或切到人已经到了）。
- 可用短句：
  - 检查句：「走动、过门、上下楼的镜逐镜看：没有人或物穿过实体，脚在地面或台阶上；有里外之分的镜机位空间和分镜一致。」
  - 登记句：「〔时间点〕〔人物〕穿过〔栏杆／墙／家具〕，归〔分镜／提示词／出片〕，处理：〔改分镜避开后重出／补提示词后重出／重出〕。」
  - 登记句：「〔时间点〕戏在〔车内〕，画面拍的是〔车外〕，归〔分镜／提示词／出片〕，处理：〔 〕。」

### 〔Q-009〕 【待测】【审片】场景看着像不像它该是的地方（G08，txt L100）

- 原则：场景像别的场所，问题在场景图，不在这一镜。原样重抽还是照那张图画，改不掉；要回到资产换图。本条细化 Q-002 里「场景用途不对」一句，Q-002 不变。
- 适用条件：审每个新场景第一次出现的镜时；审片的人。
- 正确写法：
  1. 不看分镜和资产名，只看画面：这是什么地方。看着像的地方和剧情里的地点不一样，记下「像什么」和让人这么觉得的那样东西（例如某种隔断、窗口、柜台）。
  2. 再对常理：这类场所现实里会不会有这样东西。不会有的，算场景不符。
  3. 查来源：打开这一镜绑的场景图。图本身就像别的场所，归资产（adapt-rules J-002），标勿用、换图；图是对的而成片画偏了，归提示词或出片（J-005、F-005），补场所句后重出。
  4. 归资产的，同一张图的所有镜一起登记，不只记被看出来的这一镜；换图后这些镜按导出合成通用规则 X-007 列旧片清单，逐镜定重出还是保留。
- 可用短句：
  - 检查句：「新场景首镜遮名看：看着是〔 〕，与剧情地点一致；没有别的场所才有的结构。」
  - 登记句：「〔时间点〕场景应为〔 〕，看着像〔 〕（因为有〔 〕）；来源：〔场景图本身／出片画偏〕；处理：〔换场景图，同图各镜列旧片／补场所句重出〕。」
- 错误案例：见 `C:\Users\usazr\Documents\moviePro\docs\通用规则_错误案例.md` CASE-028
