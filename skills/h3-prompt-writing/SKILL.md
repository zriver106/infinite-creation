# H3 Prompt Writing

## Workflow

1. Identify the input mode: T2VA, I2VA, FL2VA, L2VA, or full-reference Ref2VA.
   - If the model supports image input, view each unique character/scene/prop reference image ONCE via `view_asset` and reuse it across shots — do NOT re-view the same image per shot; use `view_shot_references(shot_id)` only when a shot introduces an asset you have not yet seen.
2. For base text/keyframe modes, read `references/base-en.txt` and follow its final prompt structure.
3. For full-reference mode, read `references/ref-en.txt` and follow its six-section rewrite format.
4. Preserve the exact field names, section order, labels, and timing notation from the selected guide.
5. For a multi-segment short film (hardware limits prevent one long H3 generation), compile from a storyboard contract instead of writing prompts by hand — see “Storyboard-Driven Multi-Segment” below.

## Base Modes

- T2VA: build the full audiovisual timeline from text.
- I2VA: start from the first frame and develop forward from it.
- FL2VA: describe the continuous path between the first and last frames.
- L2VA: infer a plausible opening and converge to the supplied last frame.

Use `integrated_multimodal_description`, `overall_soundscape`, and `non_diegetic_music` in the order shown in `references/base-en.txt`.

## Full-Reference Mode

Ref2VA rewrites use `subject_definitions`, `summary`, `retention_analysis`, `detailed_description`, `overall_soundscape`, and `non_diegetic_music` in that order. Reference labels stay consistent across all sections. In `subject_definitions` each subject is defined by **name + role only** — its appearance and clothing are carried by the reference image and must not be spelled out (see `references/ref-en.txt` §2.1).

Read `references/ref-en.txt` for label rules, retention analysis, and complete examples.

## Project rule: no in-shot score — `non_diegetic_music: N/A` (2026-11-18)

Every shot's video prompt in this project writes the music section as exactly `non_diegetic_music: N/A`, in the base modes and in Ref2VA alike. No music is generated inside a shot.

- Why: all scoring is laid in post when the chapter is assembled, from the chapter BGM and its cue table (`set_chapter_music` / `set_chapter_music_cues`). Music generated inside a shot clashes with the chapter BGM and breaks the main track's resume-from-breakpoint after a silent or inserted segment.
- This overrides the music examples in `references/base-en.txt` §4.7 and `references/ref-en.txt` §6; they remain a format reference only.
- Do not describe background music, score, BGM or a soundtrack anywhere else in the prompt either (not in `overall_soundscape`, not in the body). Sound the characters can hear in the scene (a radio, a ringtone, a street musician) is ambience: write it in `overall_soundscape` only when the story needs it.
- Free-text prompts (the `Sound: … Background music: …` style) write no music sentence at all; if a music slot must be filled, write `Background music: none.` The `Sound:` sentence carries only sound heard in the scene. When rewriting an existing prompt that has a `Background music:` sentence, delete it.
- Do not bind `music` assets as a shot's audio reference (`audios`); only voice and sfx assets go there.
- The render-time music check (`lib/core/music-check.js`) warns when `non_diegetic_music` is not N/A, when an H3-sectioned prompt has no `non_diegetic_music` section, or when a shot binds a `music` asset.


## Output Rules

- Write rewrite sections in English; preserve dialogue, lyrics, and visible scene text in their original language.
- Describe each shot by composition, subjects, environment, actions, camera, sound, and the exact point where referenced content appears.
- **Never describe a character's appearance or clothing (hard rule)**: when a character has an image reference, that image already carries the face, hair, skin tone, build, costume, shoes, accessories, fabric and colour palette. In every reference line and every shot, write only who the character is — character name + role/identity, e.g. `__MINIMAX_H3_REF_1__ is Ye Xueji's spirit body` — and never add age, facial features, face shape, hairstyle or hair colour, skin, build, costume, shoes, accessories, trims, materials or colours. If the task input itself supplies a character's look (asset description, character bible, continuity notes, 「角色一致性」 line), do not copy it into the prompt, and do not write `keep the look of __MINIMAX_H3_REF_N__`, `keep the look of each reference`, `stay faithful to the reference image` or any similar sentence either (R22: these make the shot drift into the reference image at its end). The reference line itself carries consistency. End the prompt with the live-scene lock instead, e.g. `The last frame is still the live <scene> scene.` This overrides the `keeps the look of <Picture N>` advice in references/ref-en.txt. Scenes, props and environments are not covered by this rule — describe them normally. **Scoped exception (rulepack-lock-20261123, pending 总导/Andy):** the clothing ID required by *Same-scene presence and costume lock* below is not a look description and is allowed: in every shot with two or more people on screen, and in every solo shot of a scene where any other shot has two or more people, each bound character gets one short clothing ID (colour + garment + hair, plus an injury/dirt state when the story has one), copied from the bound costume or character asset description and word-for-word identical in every shot of that scene. Write it inside the reference line or the headcount lock sentence. Everything else in this rule still applies: no faces, ages, materials or accessories beyond that ID, and never `keep the look of` / `stay faithful to the reference image`.
- **Make every character action emotion-driven and physically specific**: never write only inert/still verbs (stands / sits / walks / looks) with no force. State the action's intensity, speed, and body language so the motion has visible energy (e.g. `slams the table`, `paces frantically`, `clenches his fists`, `leans in intensely`, `snatches the letter`, `stumbles back breathless`) — and keep the action consistent with that line's emotion. Static characters plus a monotonous read come across as lazy; give each beat visible, purposeful movement. **Inner-monologue exception:** in an OS block the force goes into the eyes, brows, head, hands and body only — never into the mouth (see “Inner-Monologue (OS / 心声) Shots”).
- Avoid plot summaries, unresolved reference labels, and timing that does not match the requested duration.
- **Annotate every spoken line's delivery (emotion + speech pace + tone/volume) with a bias toward high energy**: before each `<d>…</d>`, after the speaker ID `(Sx)`, explicitly state how the line is spoken — emotion (furious / ecstatic / frantic / explosive / urgent / breathless / anxious / annoyed / amused / sad / nervous / hesitant / calm …), pace (fast / hurried / breathless / rapid-fire / measured / slow / drawn-out / hesitant …), and tone or volume (shout / cry out / whisper / murmur / rising / trembling / flat …). Pick the high-tension end of these lists unless the beat genuinely calls for calm. Never write a bare `S1 says, <d>…</d>` with no delivery description. Vary delivery and intensity between lines, speakers, and emotional turns within the same shot instead of one flat monotone. Follow the delivery wording shown in `references/ref-en.txt` (e.g. `exclaims with light annoyance`, `says in a casual young male voice with a playful tone and an easy conversational pace`, `replies … with an amused cadence`) — and prefer its higher-energy phrasings for conflict, urgency, or strong emotion. **Exception for inner monologue:** the delivery description applies to the voice only; the on-screen face never acts the line with the mouth. For an OS line use the fixed rule-4 sentence `An off-screen male/female inner-monologue voice (S1), <emotion>, <pace>, <voice quality>, narrates <d>…</d>. Nobody on screen is speaking; …` with voice adjectives only. The subject of the voice sentence is the unnamed off-screen voice, never the on-screen character: never write `<Name> says / speaks / talks / exclaims / shouts / whispers / cries out`.
- **Speaker IDs follow the speaking order inside this shot (2026-11-16 voice-swap fix)**: each IC shot is its own video, and H3 gives `(S1)` to the first voice heard in it and `(S2)` to the next new voice (`references/ref-en.txt` §5.4). So the first voice in this shot, OS included, is `(S1)`; never fix an ID for the whole chapter. The voice-reference line uses the same ID as that character's lines, whatever its REF number (`__MINIMAX_H3_REF_4__ is Jiang Che's voice (S2)` is fine); in the OS fixed sentences `(S1)` means the OS speaker's ID in this shot. Jobs 70f12d2f shot 17 and 231e6bc2 shots 1–2 tagged the shop owner, who spoke first, `(S2)`: both voices came out swapped.

## Inner-Monologue (OS / 心声) Shots — hard rule

An inner-monologue line is a character's silent thought heard as voice-over. The character on screen must **never** move their lips for it. H3 lip-syncs any `<d>` line to whoever looks like the speaker unless the prompt makes the closed mouth explicit, so follow these rules exactly whenever a shot contains an inner-monologue line.

**1. How to recognise an OS line.** A dialogue/sub-shot line is inner monologue when the speaker label carries `（OS）` / `(OS)` / `（内心）` / `（心声）` / `（内心独白）`, or the shot text says 内心独白 / 心声 / inner voice / inner monologue for that line. Everything else (normal speech, phone voices, system voice 系统, narrator 旁白) is NOT OS.

**2. Shot structure (best case; the storyboard stage should already deliver it).**
- Consecutive OS lines in the same scene (nobody else speaks between them) go in one shot, shot ≤ 15 s. The OS shot has no spoken line from anyone (no dialogue, no phone voice, no system voice).
- Several OS lines in one shot are the normal case. If spoken lines are mixed in, the OS lines are still written as voice in the prompt and generated by H3: each OS line uses the fixed OS sentence of rule 4 with its `<d>`, word for word the same as the shot's `dialogue` field (see “Inner voice, hand props and glasses” rule 4, revised 2026-11-22; the old “OS goes to post” rule is void). Do not drop any line or rewrite two lines into one. Write it as follows: give each OS line its own time block, written as closed-mouth acting; keep the OS speaker's face and closed mouth visible in every OS block; put any spoken line in its own block **before or after** the OS blocks, never interleaved, and end that block with the speaker's mouth closing. Keep a ≥ 0.5 s silent beat between blocks.

**3. Framing.** For every OS block: frontal or near-frontal (within ±30°) close-up or medium close-up of the OS speaker, face and mouth clearly visible in the centre of frame, camera steady or a slow push-in. This overrides any general preference for angled/side views. Do not hide the mouth (no hand over mouth, no back to camera, no wide shot, no head bowed, no cup at the lips) — the closed mouth must be visible. Anyone else in frame stays silent with a closed mouth and is in the background, out of focus or in profile.

**4. Fixed sentences — copy them verbatim, only fill the `<…>` slots.**
- Voice reference line: `__MINIMAX_H3_REF_n__ is <Name>'s voice (S1), used only as an off-screen inner voice-over, not spoken by anyone on screen.`
- Shot declaration (once, right after the style/subject lines): `Inner-monologue shot for <Name>: nobody on screen speaks aloud. <Name>'s lips stay pressed tightly shut for the whole shot and never part; teeth never visible; he never sighs, gasps, laughs, grins or breathes through his mouth; all emotion shows in his eyes, brows, head and hands.` (use she/her for a female speaker.)
- Mouth shape (once per OS block): `Mouth shape: <closed-mouth phrase from the table below>.`
- Each OS line: `An off-screen male inner-monologue voice (S1), <emotion>, <pace>, <voice quality>, narrates <d>[Chinese] <original line, unchanged></d>. Nobody on screen is speaking; <Name> only listens to his own thoughts with his lips closed.` (use `female` / `her` for a female speaker.)
  - The voice is an independent, unnamed off-screen narrator voice (like `台词（女声轻缓独白）` in `docs/run_demo.md`), not the on-screen person talking. Its timbre still comes from the REF audio line above (`__MINIMAX_H3_REF_n__ is <Name>'s voice (S1), used only as an off-screen inner voice-over…`) — keep that line unchanged.
  - **Never put the character's name and a speech verb in the same sentence.** No `<Name> says / speaks / talks / tells / replies / narrates / voices`, no `<Name> (S1) …<d>`, no `in <Name>'s voice he says`. The visual sentences of an OS block describe only <Name>'s actions, expression and closed mouth.
- Emotion turn inside one line: `at <t>s his expression shifts to <emotion B>, mouth still closed: <mouth phrase B>.`

**4b. OS line while the character is on the phone.** If the OS speaker is holding a phone (mid-call, the other side talking), the shot shows him **listening**, not talking. Write it as: `<Name> is listening, phone pressed to his ear, not talking; the person on the other end is the one speaking, and <Name> stays silent with his lips pressed shut.` Add one visible *listening reaction* that fits the line, e.g. `his brows knit as he listens`, `his gaze sinks to the floor while he listens`, `his jaw tightens and he gives a slow small nod`, `his free hand grips the edge of the desk`. Never use words that imply he is speaking into the phone: `call`, `phone call`, `phone conversation`, `on a call with`, `talking into the phone`, `talks on the phone`, `answers / answering`, `replies`, `responds`, `argues`, `chats`, `conversation`. The phone stays at the ear; framing rule 3 (frontal close-up, mouth visible) still applies.

**5. Expression must match the meaning of the line.** First decide the line's emotion from what it says, then take the matching row. All mouth shapes are closed, no teeth. Adjacent OS lines (in the same shot and in neighbouring shots) must use different mouth shapes and change at least one of eyes / brows / head / hands; never pick a shape that contradicts the line just to vary it. Rows 11 and 16 only in a subtle version, rarely.

**6. Banned inside any OS block** (they open the mouth): grin, laugh, chuckle, giggle, smile showing teeth, sigh, gasp, pant, huff, exhale through the mouth, sucks in a gasp, mutter, murmur, whisper, mouths, says, tells, replies, answers, talks, exclaims, shouts, yells, cries out, blurts, says aloud, speaks, jaw drops, mouth falls/hangs open, lips part, half-open mouth, bares teeth, bites his lip, sips/drinks, eats. Describe the voice with adjectives (tense, hushed, rapid, rising, trembling, low, bright, biting, almost breaking), never with speech-act verbs. The only verb the off-screen voice gets is `narrates`, and its subject is always `An off-screen male/female inner-monologue voice (S1)`, never the character's name.

**7. Exception to the energy rules above and below.** For inner monologue the "high-energy delivery" and "forceful action" rules apply to the **voice** and to the **eyes, brows, head, hands and body** only — never to the mouth. The on-screen face never acts the line with the mouth.

**8. No ledger words in the prompt.** Never write storyboard bookkeeping such as `台词：无`, `无对白`, `（无对白）`, `（沉默）`, `（内心）`, `OS`, `心声` anywhere in the prompt — H3 reads them aloud. Inside `<d>` put only the language tag and the original words; everything else goes outside `<d>` in English.

**9. Self-check before returning the prompt.** Every OS line of the shot's `dialogue` field appears in the prompt as a `<d>` line, word for word, in mixed shots too (see “Inner voice, hand props and glasses” rule 4); every OS line uses the fixed sentence of rule 4 (`An off-screen male/female inner-monologue voice (S1), … narrates <d>…</d>. Nobody on screen is speaking; <Name> only listens to his/her own thoughts with his/her lips closed.`); the character's name never appears in the same sentence as says/speaks/talks/narrates or right before `(S1)`; phone shots follow rule 4b (listening, no call/conversation/answering words); the shot declaration is present; each OS block has a frontal close-up and one mouth-shape phrase that matches the line; no banned word from rule 6 appears in an OS block; no Chinese ledger words outside `<d>`; the first voice in the shot is `(S1)` and each voice-reference line uses that character's ID.

## Q-version (chibi), exaggerated VFX, slang and homophones — hard rule (2026-11-16, v3.1 · v4 entry and switches)

The show's baseline is photorealistic live-action. A Q-version insert is a short, extreme-emotion exception, not a style change for the whole shot. Two presentation modes follow the 2026-11-11 definition: a chibi miniature beside the character, or a brief chibi head swap. The 2026-10-02 ban on head-swaps is revoked. A brief head swap is allowed; the live-action face must return within 1–3 seconds.

**v4.4 必读（硬规矩）.** 写 Q版/金光/卡姿兰/接力前必须先调用 skill_reference(name="h3-prompt-writing", ref="expression-v44.md") 读全文。Hard rule: before writing any shot or line that has a 【表现】 line (chibi, G01, S01, a chibi / VFX relay, slang, jokes), call that tool and read the whole file; it is the v4.4 text and wins over this section where they differ.

**0. Expression switches (v4) — read first.** If the task text contains a section titled 「本项目表现手段开关」, read its four switches: Q版插入 (chibi inserts), 夸张特效 (exaggerated VFX), 网络流行语与谐音 (slang and censor-safe homophones), 段子与接梗 (jokes and comebacks). A switched-off device is not used anywhere in this chapter, and every rule below about it does not apply: write plain live-action acting instead, even if the storyboard still carries a 【表现】 line for it. If that section is absent, treat all four as on. A switch that is on only permits the device; the storyboard decides where.

**0b. Where the decisions come from.** The storyboard marks every chosen device with a first line in `visual` / `sub_shots` such as `【表现】P3｜特效·G01 金光眼｜0.0–1.8s｜…`, `【表现】P4｜Q版·方式一（身旁小人）｜1.0–3.0s｜…`, `【表现】P6｜Q版·方式二（换头）｜…`, or `【表现】L1｜谐音｜配音替换：「我cy！」读作「我去！」`. Turn each 【表现】 line into the English visible state described below, at the time window it gives. Never copy the 【表现】 line, the Pn/Ln codes or any Chinese bookkeeping into the prompt. If a shot has no 【表现】 line, do not add a chibi or a VFX burst on your own.

**1. When it appears.** Only if the shot has a `【表现】…Q版·方式一` or `【表现】…Q版·方式二` line. The storyboard places these only on an extreme-emotion beat (cognitive shock, sudden windfall, collapse, or extreme joy), one mode per beat, at most two per episode. Ordinary surprise, a normal smile, ordinary anger, and serious or sad beats (a breakup, betrayal, grief) get real acting only — no chibi, no cute effects.

**2. Mode 1 — chibi miniature beside the character (positive wording).** Write a short visible action, then a return. The chibi's motion must be exaggerated and unrestrained — a sliding kneel, clutching the belly laughing, clutching the head with both hands, or both fists pumped in the air. Never a meek standing pose, a cute idle, a slight nod, or a kawaii wave.

> For about 1–2 seconds, a small super-deformed chibi miniature of <Name> pops in beside <Name>'s head, about as tall as his real head, matching the hair colour and outfit colours of __MINIMAX_H3_REF_N__, with a cool deadpan face, and [one exaggerated unrestrained action: a sliding kneel / clutching the belly laughing / clutching the head with both hands / both fists pumped in the air]. The live-action <Name> and the real scene stay fully visible and photorealistic; the chibi never covers his eyes, mouth, the key prop, or the system panel. Then the chibi disappears, and the shot stays live-action.

**3. Mode 2 — chibi head swap (positive wording).** Write the swap and the revert in the same shot:

> For about 1–2 seconds, <Name>'s head briefly becomes a super-deformed chibi head matching the hair colour of __MINIMAX_H3_REF_N__, with [specific expression, e.g. a dead-fish-eye look of shock, the head cocked hard to one side], while his live-action body, clothes and the scene stay photorealistic. Then his head returns to the live-action face of __MINIMAX_H3_REF_N__ and stays that way for the rest of the shot.

**3b. Chibi reference asset (hard rule, v4.2).** Every chibi shot must have the character's chibi design asset 「<Name>·Q版设定」 bound in the shot's props, so it arrives as its own reference image (label like `江澈·Q版设定（道具）`) next to the live-action character image. In `subject_definitions` write it as: `__MINIMAX_H3_REF_N__ is the chibi design of <Name>, used only as the style and identity reference for the brief chibi miniature / chibi head; this design image itself never appears in the frame.` In Mode 1 / Mode 2 sentences, match the chibi to that REF (`a small super-deformed chibi miniature of <Name> matching __MINIMAX_H3_REF_N__ (the chibi design)`), while the live-action body and face still follow the live-action character REF. Never treat the chibi design as a prop on screen. If a shot carries a 【表现】 Q版 line but its references contain no chibi design image, write no chibi: use plain live-action acting and say so in your report, so the binding can be fixed.

**4. VFX (this project) — dedicated 1–2s eye ECU, staggered from dialogue and OS.** On a windfall or high-value reveal, a single main effect is enough. These effects must be their own 1–2 second extreme close-up of the eyes. Do not bury them inside a hand close-up or a medium shot of rubbing the eyes. Do not put spoken dialogue or an OS / inner-monologue line in the same shot; put the line in an adjacent shot. Community-tested direction on Hailuo / MiniMax H3: a macro or extreme close-up, a rapid iris change, visible gold rays or a flare, and luminous particles beating outward — not a mild glow described in passing.

Preferred positive sentences:

- Golden eyes (G01): `Extreme close-up of <Name>'s eyes, filling the frame, for about 1–2 seconds. Nobody speaks and no voice is heard in this shot. The irises rapidly turn into bright glowing gold; thin golden light rays and luminous gold particles shoot outward from the pupils; a brief gold flare rims the eyelids; the skin around the eyes stays photorealistic. Then the glow settles, leaving a residual gold tint in the irises.`
- Kakuzilan-style wide eyes (S01), allowed as a power-fantasy beat: write only the v4.4 strong version, item 2 of `expression-v44.md` (load it as stated at the top of this section).
- Pupils snap wide (S02): `Close-up of <Name>'s face, for about one second. His pupils suddenly contract to pinpoints and then snap wide, the eyes opening fully, a sharp catch-light flashing in each eye; his whole body freezes for a beat.`
- Time freeze (S07): `For about one second the moment freezes: <Name> and everything around him hold perfectly still mid-motion, the colours briefly desaturate except for <Name> and <key object>, then motion and colour snap back.`
- Golden treasure glint (G07): `As <Name> looks down at <object>, a sharp four-pointed golden star glint flares on its edge for half a second and a faint warm glow rises from it, lighting his face from below.`
- Throbbing temple vein (A01): `Close-up of <Name>'s face; a vein on his temple visibly throbs twice, his jaw clenches, his eyes narrow and stay on <target>; the rest of his face stays still.`
- Awakening eye glint (P01): `Extreme close-up of <Name>'s eyes; a cold bright glint sweeps across both irises from left to right, his gaze sharpening and locking forward.`
- Tooth gleam (W02, only after a payoff): `<Name> gives a slow one-sided smirk toward the camera; a single bright star-shaped gleam flashes on his front tooth for a fraction of a second.`
- Dead-fish eyes, live-action (E04): `<Name>'s eyelids drop to half-closed, his eyes go flat and lifeless, his face completely deadpan for about a second.`

Pick the one effect the 【表现】 line names; do not substitute or stack a second one.

Do not write heart-shaped eyes, star eyes, pink sparkles, a cute little train, flower-throwing, or stomping. Do not stack a chibi insert and a heavy VFX burst on the same second. Do not only write "warm gold light wells up" in a medium shot, and do not treat "he rubs his eye and looks again" as the effect.

**4b. No empty frames after the effect (2026-11-16).** IC shots last at least 2 seconds, longer than the 1–1.5 second effect, and H3 fills leftover time with an empty corridor if the prompt runs out. Cover the whole shot duration in the timeline: either keep the extreme close-up of the same eyes to the last frame (glow builds, peaks, then a residual gold tint stays in the irises), or merge it with the reaction: `0–1.5s: extreme close-up of <Name>'s eyes … 1.5s to the end: the camera pulls back to a close-up of <Name>'s face and shoulders, still in the <scene>, <concrete action, e.g. he looks down at the gold bar in his hand, the corners of his mouth fighting a grin>; <Name> stays in frame until the last frame.` Never end the timeline before the shot ends.

**4c. No stand-alone 2–3 second silent VFX or chibi shots (2026-11-16 test).** In this project a silent 2–3 second shot without a first frame repeatedly opened on the character sheet (0–0.2s) and then drifted to an empty corridor. Give every VFX or chibi shot at least 4 seconds and open it with at least one second of in-scene live-action acting (the character already in the scene, doing a concrete action), then the effect or chibi window, then back to live-action acting until the last frame. If the storyboard hands you a 2–3 second silent VFX/chibi shot, still write a full timeline that starts and ends on the live-action character in the scene.

**5. Style lock.** Never turn the whole shot into anime, cel-shading, or a full-screen chibi scene. The corridor, street, body, costume and skin stay photorealistic before, during (except the brief chibi head in Mode 2), and after the insert. If a chibi reference image is attached, bind it as the chibi only; the live-action character still follows the live-action reference.

**6. Mouth and OS.** If the beat is an OS / inner-monologue shot, the 心声 mouth rules still apply: the live-action mouth stays closed. The chibi may make an exaggerated expression, but it must not cover the live-action mouth. If the beat is spoken dialogue (e.g. `我去！`), the live-action mouth may speak that line. In Mode 2 nobody speaks and no OS line plays during the 1–3 second chibi-head window; put the line before the swap or after the live-action face has returned.

**7. No ledger words.** Do not write Chinese bookkeeping such as `【表现】`, `P3`, `L1`, `配音替换`, `Q版方式一`, `换头`, `特效G01` in the prompt. Those decisions stay in the storyboard; the prompt only describes the visible state in English.

**8. The shot must open already inside the scene (hard rule). Reference images, character sheets and three-views must never appear in the frame.** In this project a character reference is often a character sheet / three-view (left: a face close-up; right: front, side and back full-body stands on a light or white background). That image is an identity reference only. Never show a character sheet, turnaround, three-view, contact sheet, style board, or any reference board in the video, not even for a single frame at the start. Do not write "character sheet", "turnaround", "three-view", "reference board", or "white-backdrop lineup" as visible content. Even if the storyboard says "continuing from the previous shot", this shot often has no first-frame image attached — you must still write a concrete in-scene opening at 0s (place, camera, body position, lighting) so the first frame is already the corridor, the street, or the room, never the sheet. Put this lock near the start of every Ref2VA prompt:

> The video begins already inside the live-action <scene>. The reference images are identity and location references only; never show a character sheet, turnaround, three-view, contact sheet, or any reference board in the frame, not even for a single frame at the start. 0s: <concrete in-scene composition>.

**9. System panel position (hard rule).** If the storyboard requires the system holographic panel, write it as a translucent cyan-blue holographic panel with a thin gold border, floating in mid-air off to one side of the character at shoulder-to-head height, in the empty part of the frame beside him, so that his chest and shirt stay fully visible; separated from the body by a clear gap of air (2026-11-16 test: wording like "in front of him" or "to his left at chest height" in a frontal shot made H3 paint the panel over his chest). Frame the character off-centre so the panel has its own space — never stuck to the chest, never worn like a badge, never fused to the shirt. It appears only when the storyboard says it is on. If the previous beat already faded it out, do not write "still floats in front of his chest". A blue lanyard ID badge on the costume is clothing, not the panel — do not light the badge up as a UI.

**10. Display text vs voiced text (2026-11-16 rule).** The storyboard `dialogue` field is the on-screen subtitle text; `<d></d>` is what the voice actually says. They are identical for every line, except a censor-safe homophone line marked `【表现】Ln｜谐音｜配音替换：「X」读作「Y」` — then `<d>` carries Y, not X. Example: `dialogue` = `江澈：我cy！`, so write `<d>[Chinese] 我去！</d>`. Never put 「我cy」 inside `<d>`, never voice the original swear word, and keep every other line inside `<d>` character-for-character equal to `dialogue`.
- The voiced word for the censor-safe exclamation is 我去 (never 我超, which H3 pronounces close to the swear word). Delivery: `He blurts out <d>[Chinese] 我去！</d> under his breath, short and punchy, a clear "wǒ qù".` Keep the speaker's lip-sync natural for a spoken line (this is not an OS line).

**11. Slang and comeback delivery.** A line upgraded with slang or a comeback (marked `【表现】Ln｜流行语…` or `【表现】Ln｜段子…`) is acted, not decorated: a half-second beat of silence after the other person's line, then <Name> answers flatly, one eyebrow slightly raised, a small one-sided smirk, eyes steady on the other person; if the other person's face is visible in the shot, his own face shows at least in profile while he speaks (see 「Faceless speaker vs a visible face」); then he goes straight back to business. No VFX, no chibi and no text on screen for these lines.

**正例（谐音）：** storyboard `dialogue` = `江澈：我cy！`, visual first line `【表现】L1｜谐音｜配音替换：「我cy！」读作「我去！」` → `Jiang Che glances left and right down the empty corridor, leans in over the gold bar and blurts out <d>[Chinese] 我去！</d> under his breath, short and punchy, a clear "wǒ qù".`

**正例（方式一，金砖狂喜）：** `The video begins already inside the live-action office corridor. The reference images are identity and location references only; never show a character sheet, turnaround, three-view, contact sheet, or any reference board in the frame, not even for a single frame at the start. 0s: medium close-up, Jiang Che already standing screen-left of centre in the corridor, facing the camera, left hand holding the gold bar at chest height. For about two seconds, a small super-deformed chibi miniature of Jiang Che pops in to the right of his head, about as tall as his real head, matching the hair colour and shirt colours of __MINIMAX_H3_REF_1__, deadpan, and drops into a short sliding kneel with both fists pumped in the air. Live-action Jiang Che stays fully visible in the office corridor, clutching the gold bar, trying to hold in a laugh with his lips pressed shut. The chibi never covers his mouth or the gold bar. Then the chibi vanishes and the corridor stays photorealistic.`

**正例（方式二，冷却打击）：** `The video begins already inside the live-action street outside the gold shop. The reference images are identity and location references only; never show a character sheet, turnaround, three-view, contact sheet, or any reference board in the frame, not even for a single frame at the start. 0s: frontal medium shot, Jiang Che already standing centre frame on the pavement facing the camera, his right hand sliding off his forehead. A translucent cyan-blue holographic panel with a thin gold border floats in mid-air in the empty space at the left side of the frame, beside his shoulder and head, a full arm's length away from his body; his chest and shirt stay fully visible. For about two seconds, Jiang Che's head briefly becomes a super-deformed chibi head matching the hair colour of __MINIMAX_H3_REF_1__, with a dead-fish-eye look of shock, the head cocked hard to one side, while his live-action body and the street stay photorealistic. Then his head returns to the live-action face of __MINIMAX_H3_REF_1__ and stays that way; the panel dims and fades away.`

**正例（金光眼，独立眼部大特写）：** `The video begins already inside the live-action office corridor, on an extreme close-up of Jiang Che's eyes filling the frame. Nobody speaks and no voice is heard in this shot. For about two seconds the irises rapidly turn into bright glowing gold; thin golden light rays and luminous gold particles shoot outward from the pupils; a brief gold flare rims the eyelids; the skin around the eyes stays photorealistic. Then the glow settles, leaving a residual gold tint in the irises.`

**反例：** `cute chibi, sparkles, oversized kawaii eyes, anime style throughout, he turns into a cartoon character and remains that way`；或只写 `add Q version` 而不写位置、时长和回到本相；或开场不写场景内起幅，让人物三视图/设定图出现在画面里；或把系统光幕写成 `floats in front of his chest` 贴在身上；或把金光眼写进手部特写/中景的「揉眼再看」里一带而过。

## Storyboard-Driven Multi-Segment

When H3 cannot generate the whole film in one pass, generation is split into short segments chained by the previous segment's last frame. Drive this from a **data contract** rather than hand-copied prompts, so segments stay consistent and none of them silently repeats another.

Write `storyboard.json` with the domain tools (`set_storyboard` / `update_shot`); the `scripts/*.py` compiler helpers are for a **human/offline terminal**, not a runtime step. Offline compiler steps 1–5 and their notes (author `storyboard.json`, compile, gates, segment typing) are for a human/offline terminal only; they now live in `references/offline-compiler.md` (2026-11-16, moved verbatim). The in-app Agent does not need them.

## Tips for Better Results
- Always match the total duration of the description to the requested video length (2–15 seconds), driven by content rhythm: a single short line of dialogue needs only 2–4 seconds — do not pad short shots to 10+ seconds.
- Keep reference labels consistent (e.g. `<Picture 1>`, `<Video 1>`, `<Audio 1>`) across every section.
- Prefer concrete visual and audio details over abstract words like "cinematic" or "beautiful".
- Give every spoken line a concrete delivery description (emotion + pace + tone) with real intensity so the speech carries feeling, speed variation, and emotional thrust instead of a lazy flat monotone; pair loud/urgent delivery with big physical actions. (For inner monologue: big actions of eyes, brows, head and hands only; the mouth stays closed.)
- When using keyframes (I2VA / FL2VA / L2VA), clearly state how the first and/or last frame connects to the timeline.
- **注意事项（2026-11-18，总导）必读：** 写或改镜头前调用 skill_reference(name="h3-prompt-writing", ref="注意事项.md") 读全文——镜头渲染只读 `video_prompt`（改动作 / 时间轴必须改 `video_prompt` 的英文时间轴）；多人同框逐人写区分特征并写明「几个人长相各不相同，不是姐妹」。

## Faceless speaker vs a visible face — 看不见脸的人别和露脸的人同镜开口（2026-11-16, voice-bleed fix）

H3 gives each spoken `<d>` line to whoever *looks like* the speaker on screen and uses that face's voice, even when the line is tagged with the right `(Sx)` and the voice references are correct. 2026-11-16 (job 70f12d2f): shot 17, over-the-shoulder with Jiang Che's back in the foreground, and shot 21, Jiang Che at the door with his back to the camera — in both, the shop owner's face was the only face on screen, and Jiang Che's short reply came out in the owner's voice. Speaking with the back turned is a legitimate shot; the problem is only a faceless speaker next to a visible face. For every spoken line (not OS, not a phone voice from the other end):

1. **A speaker whose face can't be seen may speak only when no one else's face is visible in the shot** — a lone figure from behind, an empty frame, a voice from beyond the door or out of frame are all fine.
2. **If another face is visible, a faceless speaker gets that person's voice.** Fix it one of three ways: the speaker turns his head so at least a profile with the mouth shows while he speaks (`he stops at the door and turns his head over his shoulder, face and mouth in profile to the camera, and says …`); or the line goes into its own shot in which no one else's face is visible; or only the speaker stays in frame. If the storyboard hands you such a shot, change it this way and say so in your report.
3. **No over-the-shoulder shots at all (2026-11-22):** never write an over-the-shoulder or 过肩/越肩 framing, including over the shoulder of someone looking at a phone. A phone being looked at becomes a separate close-up insert of the phone screen; a conversation is single-person shot / reverse shot plus a side two-shot medium shot with both faces in profile. If the storyboard hands you an over-the-shoulder shot, rewrite it this way and say so in your report. (Turning the head *over his shoulder* as an action is fine; this bans the framing only.)
4. **The listener's lips stay closed** while the other person speaks: `<Listener> listens with his lips closed.`

## Same-scene presence and costume lock — 同场在场人物入画 + 服装锁（2026-11-18, A1 QC fix）

H3 only draws people who have a reference and are named in the prompt, and it freely swaps faces and clothes between references. A1 QC (2026-11-18) lost people and mixed clothes in 7 shots: 5-1 #8/#10/#12 and 19-2 #18 / 20-1 #5 (a seated table-mate was left out of `character_ids` because he had no line, so he vanished), 16-R-V1 #18 (the lead in a crowded wide shot was drawn in another character's dark green shirt), 17-2 #22 (the host got the side-table classmate's orange polo), 20-2 #27 (the speaker was written as "squeezing in from behind", so H3 put the wrong man in the centre and gave him the line). For every shot with two or more people:

1. **Everyone the storyboard places in frame is a reference and is named.** If the scene's blocking map / whiteboard puts a present character inside this framing (edge of frame, soft-focus foreground, back view included), that character must be in the shot's references and must be written into the 0s opening with screen side, facing and state (`lips closed` if silent). Never drop a present character just because he has no line. If the framing really excludes him, say where he is (`off screen-left`).
2. **Write a clothing ID for each person** in `subject_definitions` and again in the 0s opening: colour + garment + hair (`__MINIMAX_H3_REF_2__ is Han Zixiao: dark green long-sleeve shirt, slicked-back black hair, right cheek swollen`). `fully_preserved` alone is not enough.
3. **Add the lock sentence** whenever two people could be confused (same sex, similar age, strongly contrasting clothes): `Each person's face and clothing come only from his or her own reference; never move one person's clothing onto another person. Exactly one person in the frame wears <garment>.`
4. **Costume inheritance.** Inside one scene and continuous time, a character keeps the costume reference he wore in the previous shots of that scene (same `costume_ids`) until the story shows a change. Describe the same clothing ID in every shot.
5. **The speaker is already in place at 0s.** Do not make the speaking character "enter / squeeze in / push to the centre" to take his speaking position; put him there from the first frame and state `only <clothing ID> moves his mouth; <others> keep their lips closed`.
6. **Wide and crowd shots:** the named leads are at least medium size or in the foreground, with their clothing IDs; extras are described as "other guests" and must not wear a lead's colour.
7. **Who does the action comes from the novel/script, not from a similar-looking extra.** If the visual line names a character (e.g. "支架青年 deletes the clip"), the reference bound for that action must be that character; flag the shot if the binding names someone else.
8. **Headcount lock in every multi-person shot (2026-11-23, ch3 0:54–2:37 / 2:20 two identical men):** besides the count in the first sentence, write once in the body: `Exactly <N> people are in this shot and each of them appears only once: <A> (__MINIMAX_H3_REF_a__) in <clothing ID>; <B> (__MINIMAX_H3_REF_b__), a different man with a different face, <clothing ID>, never in <A's garment>. There is never a second <A> or any look-alike of him in the frame.` N counts only people on screen (voice-only and off-screen people are named as off screen).
9. **No half person:** `No half person at the frame edge: nobody else's shoulder, arm, hand or back of the head enters the frame.` A shoulder-only person at the edge was drawn as a second lead in ch3 #13.
10. **Per-shot lock inside a scene:** items 2, 8 and 9 apply to every shot of the scene that binds the character, including solo shots, reaction shots and the last shots of the scene, not only the first ones (ch3 #22/#24/#37 lost the lock and Han Zixiao became a second Jiang Che).
11. **Costume changes only where the story changes them:** inside a scene the costume reference and clothing ID stay the same. Switch only from the first shot where the novel or script shows the change (changes clothes, puts on or takes off a coat, gets dirty or wet, gets injured). From that shot bind the matching `costume_ids` and use the new clothing ID. A prop-holding variant (e.g. "holding the bouquet") is not a costume change: keep the costume and bind the prop. An injury state must match the novel (a slap gives a red swollen cheek and blood at the mouth, not scratches). Read the costume-state trajectory table when one exists.
12. **Gaze lock when three or more people are on screen and someone speaks to a person who is not the lead:** `Gaze lock: whenever <A> speaks to <B> or listens to him, her eyes stay on <B>'s face and her head, shoulders and upper body are turned toward him; she never looks at <C> and never looks into the camera lens.` Add where B is on screen (screen side, standing or sitting) from the blocking.
13. **Voice references:** every voice IC attaches gets its own reference line, `__MINIMAX_H3_REF_k__ is <name>'s voice (Sx)`, with Sx in speaking order inside this shot (see Output Rules). A voice reference with no definition line is a duplicate-person risk.
14. **Scene lock:** the first body sentence names the location and two or more visible landmarks. A close-up with a blurred background still names one or two landmarks that remain recognisable in the blur. Use one negation only: `never a plain grey wall or a photo-studio backdrop`. IC always orders references as characters, then scenes, then props. Keep the scene reference early: do not bind background extras who are not needed (or bind a cropped single image, not a grey multi-view board), crop prop images, and never replace a detailed scene image with a rougher one (ch8 #20: e4b85050 → S095 moved the scene from REF_2 to REF_4 and the shot came out on a grey studio wall).

## Visual follows the prompt — 改提示词就同步重写 visual（2026-11-22, temporary rule, in force now）

`video_prompt` is what renders. Whenever you write or change a shot's `video_prompt`, rewrite these parts of that shot's `visual` from the new prompt in the same PATCH, then read the two back together:
- who is in frame, who enters or exits, and who is only a voice;
- whether each person stands, sits or walks, and where each one is;
- movement direction and camera direction;
- what each hand holds and where the props sit;
- what any system UI or screen shows;
- the end-frame state.

When `visual` and the prompt disagree, the prompt wins and `visual` is rewritten to match.
- **Never edit only `visual` to get past a lint check if that makes it contradict the prompt.** Example: writing "the panel has not appeared yet" when the prompt opens the panel at 1 s. Fix the prompt or the binding instead, or report the lint item and ask for a waiver.
- Before handing a batch in, compare each changed shot's `visual` with its prompt on the items above. List every contradiction in the report.

## Multi-view scene sheet (`_MV`) for shots with two or more people — 多人同场绑多视角定义图（2026-11-22, temporary rule, in force now）

Source: moviePro `docs/临时规则/场景多视角定义图_临时规则.md` (Andy, in force from 2026-11-22 13:45 without waiting for the S400 test; still temporary until Andy makes it permanent).

- **When:** a shot has two or more people in the same location, and that location has a `<场景号>_MV` asset (one 16:9 2×2 sheet: A main view, B reverse view, C side view, D 90-degree top-down floor plan). Single-person shots keep the ordinary single scene image.
- **Binding:** bind the `_MV` asset in `scene_ids` *instead of* the single scene image. It takes one reference slot. Never bind both for the same location.
- **Before writing the episode:** write the location's D-plan position table first (where every person stands or sits on D, which side the door, window, aisle and fixed furniture are on, and which of A/B/C each multi-person shot is shot from). Keep every shot of that location consistent with the table.
- **The prompt must contain this spatial paragraph as the sheet's REF definition line** (replace N with the sheet's REF number). Keep it one sentence (colon and commas, no full stops or semicolons inside), so the lint still reads the headcount sentence as the first content sentence:
  `__MINIMAX_H3_REF_N__ is a multi-view spatial definition sheet of one single location, not a storyboard and not the first frame of the video: panel A is the main view of the location, panel B the reverse view of the same location, panel C a side view of the same location and panel D a 90-degree orthographic top-down floor plan, all four panels show the same physical space, the final video shows only one normal perspective shot and never shows the grid, the panel letters or the floor plan, object positions and spatial directions come from D while appearance, materials and structure come from A, B and C, and when the camera moves the doors, windows, furniture, walls and the characters' positions keep the same relative layout.`
- **Per person:** say where each person is on the D plan (e.g. "at the window-side workstation", "in the aisle behind the desks"), and say which direction the shot is taken from ("shot from the A direction", "from the C direction, along the aisle"). These go alongside the headcount first sentence; they do not replace it.
- **Never** describe the sheet's layout as the picture ("a four-panel image", "split screen"), never ask for panel letters or a floor plan on screen, and do not write compass directions.
- The `_MV` sheet carries no story props or people; hand-held or changing objects still come from prop references and the prompt.

## Scene reference image time-of-day and lighting — 场景图时段光色一致（2026-11-18, narrowed 14:51; ch30 16b fix）

H3 copies the lighting of a bound scene reference image almost unchanged: time of day, sun angle, warm or cool cast, and which lamps are lit. Text such as "use it only as a layout reference; do not take its lighting" does not override it (ch30 16b, 2026-11-18: S189 is a low warm-sun image with the wall lamps and hallway lights on; the prompt said "mid-morning, not dusk, entrance hallway lights off, layout reference only" in English and Chinese, and the clip still came out warm with every lamp lit). Before binding a scene reference, look up its class in the project's scene time-and-lighting table (built by looking at the images; the asset description's 状态 field is not reliable): daylight from above / low-angle warm sun / night / interior artificial light / multi-panel board; lamps lit or not; indoor, outdoor or car.

1. **Blocking errors are only clear conflicts.** (a) Day and night reversed: a night shot bound to a daylight or warm-sun image, or a day shot bound to a night image. (b) The image has lamps lit and the shot gives no reason for them: the shot says the lights are off, or it is a daytime exterior and the shot never mentions lamps. (c) Indoor and outdoor light sources that cannot match: an exterior shot bound to a purely artificially lit interior image, or an interior shot bound to an exterior image.
2. **Explainable differences are warnings, not unbinding.** Warm vs cool, early morning vs late afternoon, "morning" vs a low warm sun, lamps on in an interior: keep the image and rewrite the prompt's lighting to match it (e.g. the balcony image has a low warm sun, so write `early-morning warm low sun with long shadows`). Never write lighting that contradicts the bound image.
3. **Inherit first.** If shots of the same scene have already been rendered and accepted with a scene image, later shots of that scene bind the same image and describe the same light, unless that image has a blocking error for this shot.
4. **Fixing a blocking error.** (a) Bind another final image of the same place whose time and lighting match. (b) Otherwise unbind the scene image and write the layout in the prompt as text, inside `detailed_description` after the style and lighting sentences: `Location (no scene reference image is used for this shot; build the place from this description): <the place, its main surfaces and furniture, depth, and what is on screen-left / screen-right>.` Remove the scene's `subject_definitions` and `retention_analysis` lines and every `(__MINIMAX_H3_REF_n__)` that pointed at it, renumber the remaining references in binding order, and change "identity and location references only" to "identity references only". Keep the shot's time-of-day and lighting sentence. Never keep a conflicting image with a "layout reference only" disclaimer.

## Dialogue window = visible speaking mouth — 台词时间窗与可见开口对齐（2026-11-18, 16-R-V1 #18 fix）

H3 places each `<d>` line by the time window it is written in and lip-syncs it to a face it can see. If the window falls while the speaker is still off screen, walking in, turned away or covered, the line is either given to another visible face or heard with no matching mouth. 2026-11-18 (a1 16-R-V1 #18): the female classmate's line was written for 3-6s but she was turned sideways with a hand at her cheek; QC could not confirm her lips. The rewrite said "0-3s nobody speaks; the line starts at 3s; she turns three-quarter to the camera, mouth visible, hand never covers it", and it passed. For every shot with a line:

1. **An on-screen line sits only in a window where its speaker is already in frame, facing the camera at least three-quarter (hard rule: a pure profile or a back view never counts as a visible mouth), mouth clearly visible and not covered (no hand, cup, phone or other person in front of it), and doing a speaking action** (turning or leaning toward the listener, a gesture). Write the start second: `the line starts at <t>s`.
2. **Before the speaker enters the frame, while he walks in, while his back is turned or his mouth is hidden, there is no on-screen line.** Move the line to a window where rule 1 holds, or write it as an off-screen voice (画外音): `an off-screen voice (Sx), <emotion>, says <d>[Chinese] …</d>; nobody on screen moves their lips`, or leave the window without dialogue.
3. **Say when a window is silent:** `0-3s (no dialogue: nobody says a word in this window)`. When a shot has one line, name it as the only dialogue window.
4. **Inner monologue (OS), phone voices from the other end and the system voice are always off-screen voices** and follow the OS and faceless-speaker sections above; they need no visible speaking mouth, and every visible face keeps its lips closed during them.
5. **Check before you hand over:** for each `<d>` line list window -> speaker -> in frame and at least three-quarter to the camera (not pure profile, not back view)? -> mouth visible? -> speaking action? Any "no" must be fixed, not just noted.

## Close framing on a wide scene reference — 场景图是全景、本镜是中景/近景/特写（2026-11-18, ch30）

When the bound scene reference image is a wide or establishing shot and this shot is a medium shot, a medium close-up or a close-up, H3 copies the whole wide layout from the image and shrinks the characters to fit it. For every such shot:

1. **The shot-size sentence comes first and is explicit.** It is the first sentence of the prompt (free-text prompts) or the first sentence of `summary` and of `detailed_description` (Ref2VA sections; `subject_definitions` stays first). Name the size, the body crop and the face size, e.g. `Medium shot, framed from the waist up; each face is about one quarter of the frame height.` / `Medium close-up from the chest up; the face fills about one third of the frame height.` / `Close-up of Jiang Che's face; the face fills most of the frame height.` (中景/腰部以上/脸约占画面高度 1/4). Do not open with the location.
2. **The scene reference describes only the background visible behind the character.** Its definition says what this framing shows behind and beside the character (e.g. `__MINIMAX_H3_REF_2__ is the background behind Jiang Che: the green wall with the gold peony relief`), not the whole room.
3. **Retention is "background only / partially".** Ref2VA: `__MINIMAX_H3_REF_n__: partially_preserved - background only: <what is visible behind the character>`. Free text: `use __MINIMAX_H3_REF_n__ for the background only, partially`. Never `fully_preserved` for the scene in such a shot.
4. **The layout list keeps only what this shot can show.** Keep the items behind or next to the character in this framing; drop the far door, distant tables, the ceiling chandelier and anything else that cannot be in frame at this size.
5. If the scene image itself is already a medium or close view of that spot, rules 2–4 are already met; rule 1 still applies.

## Inner voice, hand props and glasses — 心声闭嘴、手持道具位置、眼镜（2026-11-18, ch30）

1. **Inner-voice (OS) shots: lips closed throughout, no mouthing.** Besides the official `while his lips remain completely closed`, write `his lips stay closed throughout the shot; he does not mouth the words` for every OS line. The face may react (eyes, brows, breath); the mouth never moves in time with the voice.
2. **Hand props: write where the prop stays and where it never goes.** When a character holds anything that could go to the face (cup, glass, bottle, can, phone, cigarette, food, chopsticks), write its position for the whole shot, e.g. `she holds the cup at chest level the whole time; it never goes to her mouth`. If the story needs a sip or a call, write the exact second it is raised and when it comes down, and keep the mouth clear during any `<d>` line (see the dialogue-window section).
3. **No glasses unless the story gives a reason.** Write `no glasses` into each character's lock (the look / costume lock sentence). A character who wears glasses by design keeps the same pair in every shot (`wears the thin black-rimmed glasses from his reference`); glasses never appear, disappear or change mid-shot.
4. **Every line is voiced by H3 in the shot itself, OS and phone voices included (2026-11-22; replaces the 2026-11-18 r58 “OS / phone voice goes to post” rule, which is void).**
   - Every line in the shot's `dialogue` field (spoken, OS, phone voice) appears in `video_prompt` as a `<d>[Chinese] …</d>` line, word for word the same. A change to a line changes `dialogue`, `sub_shots` and `video_prompt` together; read all three back and check they match.
   - Mixed shots (spoken dialogue + OS): the OS line uses the fixed OS sentence of the Inner-Monologue section (`An off-screen male/female inner-monologue voice (Sx), … narrates <d>…</d>. Nobody on screen is speaking; <Name> only listens to his/her own thoughts with his/her lips closed.`). Give it its own time block, written as closed-mouth acting with the face and closed mouth visible; put each spoken line in its own block before or after, never interleaved, with ≥ 0.8 s between blocks (2026-11-22; time fields are whole seconds, so in practice ≥ 1 s). Speaker IDs follow the order the voices are first heard in the shot.
   - No batch edit, lint fix or template may delete or skip a `<d>` line. After any batch edit, compare every shot's `<d>` text with its `dialogue` field before writing back.
5. **Phone voices (the far end of a call) are voiced by H3 too.** Write the caller's line as a `<d>` line with the caller's own speaker ID, described as the voice heard through the phone, e.g. `the caller's voice (S2) comes faintly through the phone's earpiece, tinny and slightly compressed, <emotion>, <pace>: <d>[Chinese] …</d>`, and bind the caller's own voice reference (`__MINIMAX_H3_REF_n__ is <Caller>'s voice (S2)`), so the timbre stays the same in every shot of the call.
   - The on-screen call-taker acts normally: phone at the ear, listening reactions (brows, gaze, nod, free hand), and their own spoken replies as normal `<d>` lines with visible mouth. While the far end talks, the call-taker's lips rest closed.
   - The far end may be shown (2026-11-22): either as its own shot in the caller's location, or inside the call shot with hard cuts to the caller (at most 2 cuts per shot, every cut at least 1 s, each cut shows exactly one person). When the caller is on screen her line is an ordinary spoken line with her mouth visible; when she is not, it is the earpiece voice above. Bind the caller in `character_ids` and her location in `scene_ids`, and use the same voice reference in both cases. Never a split screen or an inset.
   - Rule 4b of the Inner-Monologue section (listening wording, banned call/conversation words) still applies to an OS speaker on the phone.
6. **Voice references keep one timbre per person.** A character's voice reference is the same sample for every line they have in any shot (spoken, OS, phone), so the voice never changes between shots. Never bind two different samples to one character.

Checker: `skills/short-drama-director/scripts/validate_prompt.py` H13a–H13g warn on these rules (warn by default; `H3_SHOT_RULES=block` turns them into errors, `H3_SHOT_RULES=off` turns them off).

## Camera, one-take and fight shots — 机位运镜与一镜到底（2026-11-16）

Applies to every shot's `video_prompt`. Read the shot's `camera` field first: the storyboard stage marks it `FIXED`, `MOVE`, `ONE-TAKE` or `CUT@Ns` (see sd-storyboard-engine「机位运镜与一镜到底」). If the field has no mark, treat it as `FIXED` unless the storyboard text clearly describes one continuous camera path. The inner-monologue rules, the Q-version / VFX rules, the opening "video begins already inside…" sentence and the expression switches all stay in force; this section never overrides them (an OS block stays a frontal close-up, steady or slow push-in; the 1–2 s of a Q-version insert keeps the camera still).

**1. One camera instruction ≈ one cut.** H3 reads every new camera verb (`pushes in`, `pans`, `whips`, `cuts to`, `orbits`) as a new shot. So:
- `FIXED`: one sentence, once: `The camera holds a fixed position (static shot) for the whole shot.` Time blocks after that describe only action and sound.
- `MOVE`: one small, slow move written once; no second camera verb. Sentence form (v4.4): item 1 of `fight-v44.md`, loaded with skill_reference(name="h3-prompt-writing", ref="fight-v44.md").
- `ONE-TAKE`: one continuous move, stated once at the start, with at most two continuation sentences at path nodes, each phrased as the same move continuing.
- `CUT@Ns`: write the cut only at the marked second: `At <N>s, the camera cuts to <new framing, side, distance>.` No other camera verbs in between.

**2. One-take template (`ONE-TAKE`, 8–15 s).** Fill the 〔…〕 slots; keep everything else.
> `This is one continuous take with no cuts from the first frame to the last. 0s: 〔framing〕, the camera starts 〔behind / beside / in front of〕 〔who〕, about 〔N〕 metres away at 〔chest / eye / knee〕 height; 〔who〕 is on screen-〔left/right/centre〕 facing 〔direction〕, 〔who〕 is on screen-〔…〕 facing 〔…〕; 〔prop〕 is in 〔whose〕 〔left/right〕 hand. 0-〔t1〕s: 〔action〕; the camera 〔follows / tracks alongside / pushes forward〕 at 〔slow / steady / walking〕 speed. 〔t1〕-〔t2〕s: 〔action〕; the same unbroken move carries the camera past 〔landmark〕 〔toward / around to the right side of〕 〔who〕. 〔t2〕-〔end〕s: the camera slows and settles into 〔end framing〕 of 〔who〕, 〔positions and facings at the end〕; 〔held micro-action or dialogue〕. The camera never passes through walls, glass, furniture or people.`
- Every time block still needs a visible body action (a moving camera does not count as action). The camera may keep drifting while a character freezes for a beat — that contrast reads well; do not make both camera and character violent at once.
- Never write `cuts to`, `whip pan`, `quick cuts`, `dynamic camera`, `shaky cam throughout`, or a new camera verb in every block inside a one-take shot.
- If the path crosses the line between two characters, write the visible route (`the camera circles behind A's back to his right side`); never jump sides.

**3. Fight shots — v4.4 必读（硬规矩）.** 写打斗/冲击镜前必须先调用 skill_reference(name="h3-prompt-writing", ref="fight-v44.md") 读全文。Hard rule: before writing any impact or reaction shot, or a walking / closing-in / chasing shot, call that tool and read the whole file. All fight wording now lives only there: impact shot, reaction shot, force and injury, the four things per exchange, attack axis, taunts, no VFX, gait, examples and counter-examples.

**4. Space-time whiteboard (时空白板).** When the storyboard gives a `时空白板` line, carry each time point into the matching time block in English: camera position, every character's screen side and facing, and who holds each prop. The last time point is the end frame; describe it exactly so the next shot can start from it.
