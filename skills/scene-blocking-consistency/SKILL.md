# 人物/道具站位一致性（scene-blocking-consistency）

把「站位」当成与人物外貌、服装、画风同级的**一致性锚点**来管理。核心思想：先为每个场景定一张**站位表（blocking map）**，之后同一场景内所有镜头一律从这张表取方位，禁止逐镜自由发挥导致左右关系漂移。

## 何时使用

- 拆分镜前、写视频提示词前，凡涉及多人同场、人物与道具同框的场景，都必须先建立/读取站位表。
- 排查「上一镜人物在左、下一镜跑到右」「两人对视方向相反」「道具从左边瞬移到右边」等问题时，按本技能重建站位表并逐镜校正。

## 站位表结构（每个场景一条）

站位表写进 `bible.md` 的「场景站位表」章节。每张表包含四块：

```
【场景 01】图书室·黄昏
- 空间锚点：门=画面左；窗=画面右；书桌=画面中偏左；书架=画面右后
- 角色站位：
  - 林默：画面左侧，面向右（朝向苏婉），距门约1步
  - 苏婉：画面右侧，面向左（朝向林默），背对窗
- 道具锚点：
  - 茶壶：书桌上，位于两人之间偏左
- 轴线与机位：以「林默—苏婉」连线为轴线；机位统一在轴线下方（两人正前方偏左），禁止越轴
```

### 字段说明

| 字段 | 含义 | 必填 |
|------|------|------|
| 空间锚点 | 场景内固定参照物（门/窗/桌/床/台阶/柜台…）相对画面的左右/前后方位 | 是 |
| 角色站位 | 每个入镜角色相对锚点的方位 + 朝向（面向左/右/前/背对镜头） | 是 |
| 道具锚点 | 关键道具相对角色/锚点的方位（尤其会被拿取/强调的道具） | 有道具时必填 |
| 轴线与机位 | 角色连线的轴线，及本场景允许的机位侧（统一同侧） | 多人同场时必填 |

## 七条铁律

1. **180 度轴线规则**：同一场景内，机位必须始终保持在角色连线（轴线）的同一侧；确需越轴时，必须先用一个「全景/两人同框」镜头交代，或让角色走位自然换边，否则禁止直接越轴。
2. **屏幕方向一致**：同一角色在连续镜头中位于画面的左右侧保持一致（画面左/画面右），除非剧情明确要求其走位移动，且该移动路径在镜头里被写清。
3. **视线匹配**：面对面对话时，一方看向左、另一方看向右；视线方向跨镜一致，不得出现两人同看一边的「镜像跳」。
4. **道具锚点一致**：道具相对角色/场景锚点的方位跨镜一致（桌上的茶壶始终在两人之间偏左），不得瞬移。
5. **换位/走位必须显式交代**：若剧情要求角色换位（起身、走到窗边、绕到对方身后等），必须在该镜头的 `sub_shots` 里写清「起点→路径→终点」，并**更新站位表**为新站位；换位之后的镜头沿用新站位。
6. **镜头间上下文承接（先判断转场，再决定是否参考）**：写分镜 N 前，先比较它与分镜 N-1 的 `scene_name`/场景头与时间——**同一场景且时间连续 → 必须参考站位**：分镜 N 起幅 = 分镜 N-1 落幅（角色左右方位、朝向、道具位置、动作方向一致）；**发生转场（场景头变化/地点切换/时间跳跃/淡入黑场等）→ 不参考上一镜位置**，为新场景重建站位表。
7. **同场在场人物入画 + 服装继承（2026-11-18）**：同一场景且时间连续的一组镜头，先按站位表列「在场人物名单」（谁在场、坐/站哪、穿哪套服装）。每一镜按机位与景别判断哪些在场人物落在画幅内（含画面边缘、虚焦前景、背影）——这些人**都必须**写进该镜 `character_ids`，并在 `visual` / `sub_shots` / `video_prompt` 里写出位置、朝向与状态（不说话写「嘴闭合」）；不得因为「本镜没台词 / 不是动作主体」漏绑，否则 H3 只画被引用的人，在场人物会凭空消失。服装：在场人物在本场绑定过的服装（`costume_ids`），本场后续凡入画都必须继承同一服装，直到剧情明确换装（换装时间点写进白板）。景别确实把某在场人物排除在画外时，在 `visual` 写明「X 在画外（画面左外侧）」。

## 执行步骤

### 1. 拆分镜前：建立/读取站位表

- 先按场景聚合本章，为每个场景建立站位表（见「站位表结构」）。
- 若 `get_project` 返回的 `context.bible` 里已有该场景的「场景站位表」，直接沿用；剧情走位变化时才更新。

### 2. 持久化到 bible（注意覆盖式写入）

- `bible` 是覆盖式写入：**先 `get_project` 读回现有 `context.bible`**，把「场景站位表」章节合并进全文（保留已有的人物外貌/衣橱等内容），再 `save_context('bible', 合并后的全文)`。
- 站位表按场景分条，随剧情推进可追加新场景、更新走位后的旧场景。

### 3. 写分镜时复述站位（含镜头间承接）

- 每条 `set_storyboard` 的 `visual` 与 `sub_shots` 必须明确写出「角色X在画面左/右、面向左/右、距某锚点远近」，不写「同上/保持原样」这类零指代。
- 子分镜之间若有人物走位，写清移动路径与起终点。
- **先判断是否转场**：写分镜 N 前，比较它与分镜 N-1 的 `scene_name`/场景头与时间。同场景且时间连续 → 参考站位（承接上一镜落幅）；发生转场（场景切换/地点变化/时间跳跃）→ 不参考上一镜位置，为新场景重建站位表。
- **按 idx 顺序逐条写分镜**：同场景连续时，写第 N 条前先回顾第 N-1 条 `sub_shots` 的结尾一段（落幅），第 N 条的起幅站位承接第 N-1 条的落幅；续跑追加时用 `list_shots` 读回已有分镜的最后落幅再接写。

### 4. 写视频提示词时复述站位（英文）

- 写 `video_prompt` 时，把站位表方位翻译成英文并复述进每个镜头，例如 `Lin Mo stands on screen-left facing right; Su Wan stands on screen-right facing left`。
- 参考标签（`__MINIMAX_H3_REF_N__`）与站位描述并存，互不替代。

## 常见错误（写分镜时自查）

- 越轴：两人对话，A 镜从左侧拍、B 镜突然从右侧拍，导致人物左右互换。
- 镜像跳：同一场景两人对望，却都写成「面向右」或都「面向左」。
- 道具瞬移：上一镜茶壶在两人之间，下一镜跑到窗边。
- 零指代：`sub_shots` 写「人物位置保持原样」，但没写「原样」具体是什么。

详见 `references/blocking-map.md`（模板与示例）与 `references/continuity-rules.md`（规则判定细节）。

## 段内时空白板（2026-11-16 新增 · 站位表的时间版）

站位表管「这个场景里大家默认站哪」；时空白板管「这一条分镜里，每个时间点相机、人物、道具各在哪」。一镜到底（ONE-TAKE）、打戏、三人以上走位的分镜必须写，其他分镜可选。写法和字段的权威定义见 sd-storyboard-engine「机位运镜与一镜到底」第 6 条，这里只补三条和站位表的关系：
1. 白板里的人物位置、朝向、攻击轴线必须能从本场景站位表推出来；剧情里有人走位、被打飞、换边时，先在白板里写清路径，再在 bible 的「场景站位表」里更新该场景的「当前站位」，后续分镜按更新后的站位承接。
2. 打戏开始前在站位表里加一行「攻击轴线」：谁在画面左、谁在画面右、往哪边打；整场打斗不越轴，绕位必须写路径。
3. 道具归属按时间点写（「t=0s 车钥匙在甲右手 → t=6s 掉在地上画面左下」）；道具换手、掉落、被抢，必须在中间的时间片里写出动作，下一条分镜起幅照抄白板末点。

## 同场在场人物与服装继承（2026-11-18 新增 · A1 质检 7 镜复盘）

站位表回答「大家站哪」，这一节回答「这一镜谁必须出现、穿什么」。拆分镜和写词时：
1. **建在场名单**：每个场景在站位表里加一行「在场人物：主角（桌左座，C001_O57 灰蓝洗旧T）、人物A（桌右座，基础形象）、人物B（桌右端站）……」。人物进出场要在白板里写时间点。
2. **逐镜判断入画**：按机位景别把在场名单过一遍，落在画幅内的人全部进 `character_ids`；不说话的写「嘴闭合」，可以虚焦、在画面边缘，但必须在。
3. **服装继承**：同场、时间连续，人物服装绑定沿用上一镜；同一晚/同一场戏中途换镜头不换衣服。
4. **说话人与动作人以原著/剧本为准**：`visual` 里写了「支架青年删视频」，绑定就必须是支架青年，不能换成长得像的路人角色；说话人必须在 `character_ids` 里且 0s 已在说话位置。
5. **多人同框写服装鉴别点**：两人以上同框（尤其同性别、衣服对比色强）时，`video_prompt` 按 h3-prompt-writing「Same-scene presence and costume lock」写服装鉴别点与锁定句。

A1 复盘（2026-11-18）：5-1#8/#10/#12、19-2#18、20-1#5 因在场人物没台词未绑定而消失；17-2#22 新入画的同学（橙红 Polo）与人物C（深绿衬衫）服装互换；16-R-V1#18 全景里主角被画成深绿衬衫；20-2#27 写成「起哄同学从后面挤进来」，结果站在中间开口的是同学男；5-2#27 删视频的人原著是支架青年，却绑成了举手机食客。

## 场景参考图时段/光色一致（2026-11-18 新增，14:51 收窄 · 第30章 16b 复盘）

站位表管「在哪、站哪」，这一节管「绑哪张场景图」。H3 会把场景参考图的光色（时段、阳光角度、灯亮不亮）几乎原样搬进成片，文字里写「只作布局参考 / 不取它的光色」压不住。
1. **绑场景图前先看图分类**：时段（白天高位光 / 低角度暖阳（清晨或傍晚，长影）/ 夜 / 室内人工光 / 多格板）、灯（亮 / 未见亮灯）、内外（室内 / 室外 / 车内）。以看图为准，资产描述里的「状态：白天」只作参考（第30章复核 226 张里 15 张描述和图对不上）。
2. **只有明显冲突才是 ERROR**：①日夜颠倒（夜镜绑白天/暖阳图，白天镜绑夜景图）；②图里灯亮、镜头没有亮灯的理由（镜头写了灯不亮；或室外白天镜、图里壁灯/路灯亮着而镜头没写灯）；③室内外光源根本不兼容（室外镜绑纯人工光的室内图、室内镜绑室外图）。
3. **能解释的差别只记 WARN、不解绑**：冷暖色差、清晨 vs 傍晚、上午 vs 低角度暖阳、室内开着灯等。处理办法是把提示词里的光线描述改成和图一致（例：阳台图是低角度暖阳 → 写「上午早些时候的暖阳 / early-morning warm low sun with long shadows」），不要硬写和图相反的光。
4. **继承优先**：同一场景里已经出片（验收过）的镜用了哪张场景图，后面的镜优先继承同一张，光线描述也跟它一致；不继承要有 ERROR 级理由。
5. **ERROR 的修法**：①换同地点、同时段（对得上）的定稿版；②没有就解绑场景图，把布局（门、墙、地面、家具、纵深、左右方位）写成文字放进提示词，镜头的时段光色照写；在缺资产清单登记「<场景> <时段>版」给资产管理补图，补好后可换回。

第30章复盘（2026-11-18）：16b 绑 S189（1301院门，低角度暖阳、壁灯玄关灯全亮），提示词中英文都写了「上午、不是黄昏、玄关灯不亮、场景图只作布局参考」，成片仍是暖光、灯全亮（V3_16b）→ 灯亮冲突，解绑。阳台 S397 是低角度暖阳、镜头是上午 → 可解释，保留绑定、光线改写为上午早些时候的暖阳，与已出片的 13a/13b 一致。08 回忆夜景绑了暖黄午后光的诊室 S136 → 日夜颠倒，解绑。

## 全景场景图 + 中近景镜头（2026-11-18 新增 · 第30章复盘）

站位表照旧管全场；但绑定的场景图是全景/大全景、本镜是中景/中近景/特写时，提示词只取这一镜看得见的那一块：
1. 景别句放在提示词最前面，写明景别、身体取景和脸占画面高度（例：中景、腰部以上、脸约占画面高度 1/4）。
2. 场景参考图的描述只写人物身后看得见的背景；保留度写「background only / partially」（Ref2VA：`partially_preserved - background only: …`），不写 fully_preserved。
3. 站位/布局清单只留这一镜画得进来的部分（人物身后、身旁），远处的门、别桌、吊灯等删掉。
细则见 h3-prompt-writing「Close framing on a wide scene reference」；validate_prompt.py H13a 只告警。
