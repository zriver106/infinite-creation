# 模式 A · 小说转剧本（novel-to-script）

把一部小说（或一段素材）改编成**可分镜的文学剧本**。目标是结构清晰、场景标注规范、对白动作分离，便于模式 B 直接拆分镜。

## 触发

用户说「把小说改成剧本 / 小说转剧本 / 改编剧本 / 文学剧本」，或提供小说文件并意图改编。若未指定，回退 SKILL.md 菜单。

## 输入

- 粘贴的小说正文，或小说/素材文件路径（`.txt`/`.md`）。
- 若只给梗概/创意，先与其确认核心设定再写。

## 步骤

### Step 1 · 素材挖点（提炼四要素）

先不动笔，向用户确认或自行提炼：

| 要素 | 要回答 |
|------|--------|
| 前提（Premise） | 一句话核心设定：「如果一个__，会怎样？」 |
| 主角与欲望 | 谁、想要什么、阻碍是什么 |
| 核心冲突 | 人物 vs 人物 / 环境 / 自我 |
| 主题 | 想表达什么（一句话） |

输出一段「改编要点」给用户确认（门控点 1）。

### Step 2 · 三幕结构搭建

按 `references/style-guide.md` 与 `templates/script-template.md` 搭骨架：

- **第一幕 起（~25%）**：钩子（前 30s 抓住观众）→ 世界观呈现 → 主角登场 → 触发事件。
- **第二幕 承转（~50%）**：上升行动 → 中点转折 → 危机加深（All Is Lost）。
- **第三幕 合（~25%）**：高潮对决 → 结局 → 余韵（可选钩子）。

给出「分场大纲」（每场一句话 + 功能），请用户确认（门控点 2）。

### Step 3 · 场景剧本成稿

逐场写成文学剧本，严格遵守场景头与标注规范：

```
【场景 01】室外·废弃工厂·傍晚
───────────────────────────────
[画面：橙红夕阳将工厂铁架拉出长影。锈蚀铁门半掩。]
[音效：风声，远处城市嘈杂声渐渐淡出]

林晨（从铁门缝隙中侧身而入，手持手电筒，神色警惕）："来了三次了……每次都差一点。"

[画面：手电光扫过墙壁，定格在一组奇异符文上。]
系统音（机械感）：「检测到能量残留——强度：S 级」
```

规则：
- 场景头统一 `【场景 NN】地点·子地点·时间`。
- 对白：`角色名（动作/情绪）：「台词」`。
- 客观画面用 `[画面：…]`，声音用 `[音效：…]`/`[BGM：…]`，情绪用 `[情绪：A→B→C]`。
- 台词每句有目的；动画台词单句 ≤20 字；少用解释性台词。

### 表现手段入口 · 剧本层（2026-11-16 v4 · 取代 v3.1「台词局部升级与过审谐音」）

本剧有四类表现手段：**Q 版插入、夸张特效、网络流行语与过审谐音、段子与接梗**。口径：表情表演 > 特效 > Q 版 > 心声；台词只做局部替换，剧情关键信息照原著。剧本层只做两件事：① 标出候选点（画面上用什么手段由分镜层 `sd-storyboard-engine` 决定）；② 在少数最出彩的位置做台词局部升级。改的是说法，不是剧情。

**先看开关（v4）：** 任务文本里若有「本项目表现手段开关」一段，先读其中四项：**Q版插入、夸张特效、网络流行语与谐音、段子与接梗**。被关掉的手段本章一律不用，本节里和它相关的条目、配额、选择表那一列都不适用（改用真实表演；台词保持原著平实说法）。没有这一段，视为四项全开。开关只管「能不能用」：开着也要按选点标准和上限来，不是必须用。**（v4.4-B）开关段里那句「不是每章必须用，宁缺毋滥」说的是不堆砌：本章没有够格的点可以不用；有够格的点（见下文 A 表与 B·5、B·6 的本剧落点）却一处不落，算漏做，不算克制。**

#### A. 候选点标记（每章必做）

每场写完后回头扫一遍，在触发那句台词或动作的**下一行**加一行候选标记，和 `[画面：…]` 同级：

`[表现点 P序号｜情绪：<具体情绪>｜强度：中/高/极端｜触发：<原著事实一句>｜可选：<表演/特效/Q版/流行语/段子>]`

例：`[表现点 P3｜情绪：暴富狂喜、憋笑｜强度：极端｜触发：外卖变成一块金砖｜可选：特效/Q版]`

| 该标的位置 | 强度 | 本剧常见例 |
|---|---|---|
| 爽点兑现：第一次见到高价值之物、到账数字、对方态度突变、打脸 | 高 / 极端 | 金砖入手、779000 到账、老板噌地站起改口叫「老板」 |
| 情绪极值：认知炸裂、暴富瞬间、崩溃、极端狂喜、极度无语 | 极端 | 「这得有1000克吧」、发现还有冷却时间 |
| 反转：系统突然出现、附加条件（冷却、限制）、身份揭开 | 高 | 「叮——检测到可交易物品」 |
| 吐槽位：配角抛来一句能原路打回的话；场面荒诞；主角心里想翻白眼 | 中 / 高 | 骑手边打电话边走到跟前；老板前倨后恭 |

**`可选` 要写全（v4.4-B）：** 爽点兑现、情绪极值的 `可选` 必须含「特效」，只有全章最极端的那一处（最多两处）再加「Q版」，其余极端点不写「Q版」；吐槽位必须含「流行语」或「段子」。不许只写「表演」——只写「表演」等于替分镜层把路堵死（2026-11-16 验证：骑手、老板变脸、改口叫「老板」三个吐槽位全写了「可选：表演」，全章流行语 0、段子 0）。

**不标：** 分手、背叛、伤痛、生存压力、关键交易因果的说明（严肃悲伤段），以及普通惊讶、日常微笑、一般生气。 **但原著自己就有的自嘲和苦笑不许删（v4.4-B）：** 严肃段里禁的是新加的梗和喜剧特效；原著本来就写在那里的主角自嘲（如「才华就像怀孕，不得时间久了才能被看出来吗？」「老天这是给他开了哪门子的玩笑？」）是人物的声音，照原著保留成心声，不升级、不加特效、不标表现点，一字不改。
**数量：** 一章通常 4–8 个候选点；一个都没有时，在剧本末尾写 `[表现点：无｜理由：…]`。候选点是给分镜层的菜单，标了不等于必须用。标记行写在 `[ ]` 里，不写进台词，下游不念、不上字幕。

#### B. 台词局部升级（流行语、谐音、段子）

1. **先保留事件，再改口。** 数额、条件、先后顺序、谁知情、谁对谁说话，必须与原著一致。
2. **先对上人物再选词。** 沉稳的人说「我去」，嘴碎的人说「好家伙」「我人傻了」，被拿捏时「行吧，我认了」。不要给每个角色统一口头禅；本剧受众 1985–1995 男性，口吻偏痞、冷、干练。
3. **选点：** 只升级候选点里最出彩的那一两句（情绪峰值、吐槽位）。一场戏情绪峰值优先只抬一句；能靠眼神、动作或特效完成的，不必再叠口头禅。
4. **过审谐音：声画分工（2026-11-16 定）。** 原著有「卧槽 / 我操」这类脏话，且该处是极端情绪：
   - 台词写**屏幕字幕显示的字**，紧跟一行配音标注：
     ```
     江澈：我cy！
     [配音：我去！]
     ```
   - 对白栏 / 字幕显示「我cy！」，配音实念「我去！」。**只有这类过审谐音句允许显示和配音不同**；其他所有台词显示与配音一字不差，不加 `[配音：]` 行。
   - 其他脏话直接换干净说法，显示与配音相同：他妈的 → 他喵的 / 真是够了；牛逼 → 牛啊；傻逼 → 离谱 / 你认真的吗；我靠 → 我去。
   - 只给情绪外放的人（江澈独处爆点、损友）；每集「我cy」这组最多 1–2 次，优先 1 次。
   - **配音默认「我去」，不要用「我超」**（2026-11-16 验证：H3 把「我超」念成接近 cāo 的音，过审有风险）。备选配音：我靠、好家伙。字幕显示照旧用「我cy！」这类软化写法，由 `dialogue` 显示、`<d>` 配音分工完成。
   - 「网络流行语与谐音」开关关掉时：不做升级；原著脏话改成干净说法「我去」，显示与配音相同。
5. **流行语、口头禅：** 先写清事件证据和情绪，再选词，不能先挑梗再改原著。可选（受众核心）：我去 / 我的天 / 好家伙 / 我人傻了 / 这合理吗 / 有点东西 / 行吧，我认了 / 我承认，我破防了 / 呵，有点意思。每次只抬一句，不连用「这波」「好家伙」。 **本剧落点（v4.4-B）：** 流行语是换说法，不是加句子——把原著那句的感叹或口气词换掉，数字和名词不动；主角独处的心声、自语最合适（剧本层是唯一允许改口的地方，心声也可以改）。最出彩的三类位置：① 系统或好事突然砸下来（原著「哦吼，终于触发交易系统了。」自带口头禅，保留即算本章 1 处，不再叠）；② 钱到手后回过神（「好家伙，七十七万九。」）；③ 被规则卡住（原著「竟然还有冷却时间！」→「还有冷却时间？这合理吗。」）。每章 0–2 处，通常 1 处；不和谐音句放在同一场。
6. **段子与接梗：** 结构是「把对方甩过来的球原路打回，再转一个弯」，接完立刻回到正事。例：对方说「哥哥你猜我在哪？」→「你猜我猜不猜你在哪。」；「有个好消息，还有个坏消息」→「坏的先说。好的我怕是假的。」；「拜托，这能一样吗？」→「一样不一样，数字会说话。」只放在对方真的抛了球的位置（问句、卖关子、嘲讽、油腻话）；同一句式全剧只用一次；严肃的分手、背叛、伤痛、关键交易因果不靠梗消解。没有现成的球就不加，不为塞梗新增对白对象或事件。「段子与接梗」开关关掉时不加。 **三种段子和本剧落点（v4.4-B；原文只写了接梗一种）：** ① **接梗**——对手抛球时，允许给主角加一句回话（≤12 字），不加新人物、不加新事件、不改对方原话、不改变剧情和关键信息，每章 ≤1 句。例：老板前倨后恭，送客时说「老板慢走，下次有黄金记得找我啊！」→ 江澈头也不回摆摆手：「行，下次你站着等。」（注：分镜时这一镜里老板若露脸，就把这句拆成单独一镜、不让老板露脸，或让江澈侧过脸再说——画面里有别人露脸时，背身说的话会被视频模型配成露脸那人的嗓音，2026-11-16 验证章串音）（回的是他进门时老板坐着没起身。）② **冷笑话 / 自嘲**——主角独处、苦中作乐的一句心声或自语，原著自带的优先（「行，午饭这点委屈，我受得住！」「才华就像怀孕……」），照原著保留，并在下一行标 `[台词升级 Ln｜类：段子·原著自带｜原著：同]`，让下游按冷面的演法演，别当普通心声平着念。③ **反差吐槽**——看人变脸时的一句冷评，事实取自原著旁白。例：原著「金店老板对江澈的称呼都变了」→ `江澈（OS）：刚才还是「你」，这会儿成「老板」了。` 三种每章各 ≤1、合计 ≤2。
7. **禁用（本剧受众）：** 绝绝子、尊嘟假嘟、无语子、哈人、我嘞个豆、嘻嘻不嘻嘻、City 不 City、集美、卖萌或饭圈口吻；口播原脏话（我操、卧槽）。反派或极年轻配角偶用也控制在一句以内。
8. **每集上限（正片，按成片时长）：** 四类同类（谐音爆粗 / 流行语口头禅 / 嘲讽阴阳 / 冷笑话接梗）每集各 ≤2 次，同类相邻两次间隔 ≥60 秒；全章被升级的台词通常 1–4 句，其余台词保持原著。 **也不能只会谐音（v4.4-B）：** 谐音句有固定的原著触发词（卧槽），所以每次都落得上；流行语和段子没有，两轮验证都是 0。一章里只要有吐槽位、荒诞位或反差位，且对应开关开着，流行语与段子合计至少落 1 句（原著自带的先数上）。一句都落不了时，在 `[表现汇总]` 下一行写 `[流行语/段子：无｜最接近的位置：…｜不落的理由：…]`；理由不能是「原著没有脏话」或「没有现成的球」——没有球还有自嘲和反差吐槽两种。
9. **升级处要留痕：** 每句被升级的台词下一行加 `[台词升级 L序号｜类：谐音/流行语/嘲讽/段子｜原著：「…」]`（谐音句的 `[配音：…]` 行放在它前面）。剧本末尾加一行汇总：`[表现汇总｜候选点 P1–Pn｜台词升级 L1–Lm]`。
10. **改完即新原文。** 本步是唯一允许改说法的地方。剧本锁定后，下游分镜和提示词对剧本台词（含「我cy！」与 `[配音：我去！]`）一字不改：不得改回原脏话，不得把配音改成「我超」或「我cy」。

**正例：** 原著「卧槽！」，江澈独处、看着金砖情绪炸裂 → `江澈：我cy！` / `[配音：我去！]` / `[台词升级 L1｜类：谐音｜原著：「卧槽！」]`，后面再标 `[表现点 P3｜情绪：暴富狂喜、憋笑｜强度：极端｜触发：外卖变成金砖｜可选：特效/Q版]`。情节仍是看见金砖后的惊叹，不新增事件。
**正例（流行语，v4.4-B）：** 原著「竟然还有冷却时间！」→ `江澈（OS）：还有冷却时间？这合理吗。` / `[台词升级 L2｜类：流行语｜原著：「竟然还有冷却时间！」]`。事实（有冷却时间）没变，只换了口气。
**正例（接梗，v4.4-B）：** `金店老板：呵呵，老板慢走，下次有黄金记得找我啊！` / `[画面：江澈头也不回，摆了摆手。]` / `江澈：行，下次你站着等。` / `[台词升级 L3｜类：段子·接梗｜原著：江澈摆了摆手，出了金店（无台词）]`。只加主角一句回话，老板的话一字不改，没有新事件。分镜时老板若和背身的江澈同镜露脸，按上面第 6 条的注拆镜或让江澈侧过脸。
**正例（原著自带的冷笑话，v4.4-B）：** `江澈（OS）：行，午饭这点委屈，我受得住！` / `[台词升级 L4｜类：段子·原著自带｜原著：同]`。台词不动，只是告诉下游这句要冷着脸演。
**反例：** 把分手那场改成接梗互怼；全章「卧槽 / 我去 / 好家伙 / 这波」连用；为了塞梗给老板加原著没有的台词；剧本里一个表现点都不标；下游把配音写成「我超」「我cy」，或改回「卧槽」；全章只升级了一句「我cy」，吐槽位全写「可选：表演」；把原著自带的自嘲句当成「严肃段的梗」删掉。

### Step 4 · 自检与迭代

对照 `templates/script-template.md` 的创作备注项，检查：
- 三幕比例是否合理、钩子是否够强
- 每场是否有清晰功能（推进/揭示/转折）
- 角色语气是否差异化
- 表现手段入口（v4）：先看了「本项目表现手段开关」；严肃悲伤段之外的爽点 / 极值 / 反转 / 吐槽位都标了 `[表现点 Pn｜…]`（或写了「无」的理由）；升级台词都有 `[台词升级 Ln｜…]`，谐音句有 `[配音：…]`；同类梗每集 ≤2；（v4.4-B）吐槽位的 `可选` 含流行语或段子；流行语与段子合计 ≥1，或写了 `[流行语/段子：无｜…]`；原著自带的自嘲句没被删

输出 `script.md` 到 `outputs/<作品名>/`，并附「下集预告钩子」。交付前请用户确认（门控点 3）。

## 产出

- `outputs/<作品名>/script.md`（文学剧本，含世界观/角色一览/正文/备注）
- 可选：`outputs/<作品名>/storyboard.md` 的占位（待模式 B 填充）

## 衔接

把 `script.md` 直接交给**模式 B（剧本转分镜）**，即可得到分镜表与角色卡，无需重新拆解。
