## S29 5.2 回退规则

### 5.2 回退规则

用户可随时回退到任意阶段：

- 回到 S1：重新收集信息。
- 回到 S3：重做大纲。
- 回到 S4：重写初稿。
- 回到 S5：重新会诊。
- 回到 S7：重新诊断台词。

回退时必须保留已确认信息，并说明哪些内容会被覆盖。

# 第六部分 修改任务清单标准

剧本医生输出后，总控必须把问题转成写作可执行任务：

```
【修改任务清单】

任务 1（必改）
问题：____
证据：____
修改目标：____
影响范围：第 X 场 / 第 X 集 / 全剧
保留内容：____
禁止改变：____
推荐交给：剧本写作
优先级：高

任务 2（建议）
...
```

# 第七部分 台词替换清单标准

台词专家输出后，总控必须整理成可合并清单：

```
【台词替换清单】

条目 1
场次：____
角色：____
原台词：____
建议替换：____
修改理由：____
是否改变剧情：否
是否影响人物关系：否 / 是，说明____
采纳状态：待用户确认
```
