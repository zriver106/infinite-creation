## S70 17.4 净化规则（强制）

### 〔S70-001〕 17.4  净化规则（强制）

交付文档**必须删除**以下所有内容，只保留对外可见的成品：

**必须删除的创作过程记录**：
- 创作笔记（核心情绪/取舍/自评不满意点）
- 场后清单表（含六维推进/5视角/信息边界/角色状态/表演层/白描/伏笔登记/创作笔记等行）
- 5 视角实时自检记录
- 会诊报告（24 评委陈述、主治医生归纳）
- 台词诊断报告（十一维诊断、改写建议）
- 飞轮修正指令、质量日志、飞轮总结报告
- 交接摘要、版本命名记录
- 修改任务清单、台词替换清单
- 工作区文件读取报告
- 状态快照
- 任何"自检报告"输出
- 任何与用户的交互对话痕迹

**必须隐藏的内部机制术语**（交付文档中不得出现）：
- 角色坐标九维 / 性格三层
- 伏笔登记表 / 伏笔编号
- 世界观规则表 / 规则编号
- 金手指三道锁
- 人设产能验证 / 危机锁 / 资源锁 / 人设独占性测试
- 信息边界图 / 已知信息清单 / 禁忌信息 / 误信信息
- 质量飞轮 / P0/P1/P2 分级
- 5 视角 / 24 评委池
- 表演层 4 层设计（objective/subtext/emotional vector/body behavior/facial behavior）
- S0-S9 阶段编号
- references/ 路径
- 任何"skill""总控""下游"等内部称呼
- 模式/节奏代码：M1、M2、R1、R2、R3、R4、R5、R6
- 短剧角色轻量档案
- DNA 提取 / DNA 报告 / DNA 规律
- 题材专项模块编号：C1-C6
- 主题深度设计（反命题/隐喻系统/追问路径）
- 角色状态矩阵
- 场后清单 / 三遍过滤 / 底线四维 / 深度七维 / 十一维
- Want / Need / 核心恐惧 / 核心欲望
- 压测 / 压测模式 / 压测样例
- 档位 A/B/C
- 产物传递清单 / 回退衔接 / 自动衔接
- 风格锁🔒（交付文档不出现锁标记，但风格本身要体现在剧本中）
- 【制作基线】中的源版本状态、待补材料等内部状态
- 七层画面检查、出场连续性检查、画面连续性检查、导演画面版交接及其检查结论
- AI 分镜参数附件、避免误解等仅供制作系统使用的技术参数

**角色信息对外呈现规则**：
- 人物简介只写"角色名（定位）+ 2-4 句话描述"（含身份/性格/关键能力/成长方向），不写九维分析
- 不写"Want/Need""核心恐惧""信息边界"等内部字段
- 不写"角色弧光方向""人设产能"等评估术语
- 只写观众/甲方需要知道的：身份、性格特点、关键关系、成长方向
