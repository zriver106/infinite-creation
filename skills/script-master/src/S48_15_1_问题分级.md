## S48 15.1 问题分级

### 15.1 问题分级

会诊/诊断中发现的问题分三级：

```
P0 级（硬伤，必须立即修）：
  - 角色开天眼（用了不该知道的信息）
  - 时间线倒退/矛盾
  - 伏笔超期未回收
  - 主角 OOC（行为严重违反角色坐标九维）
  - 金手指三道锁失效（主角无敌）
  - 主题完全缺失

P1 级（明显问题，本轮必须修）：
  - 潜台词密度偏低（整场戏 0-1 层）
  - 冲突层次单一（只有外在冲突）
  - 关系静态（重要关系无考验/转折）
  - 台词同质（角色辨识度矩阵不达标）
  - 弧光无代价
  - 表演层缺失（关键台词无 4 层设计，或全场身体与台词"一致"无矛盾）

P2 级（提升空间，建议修）：
  - 戏剧讽刺运用不足
  - 切片传播度偏低
  - 文化敏感度风险
  - 隐喻系统未贯穿
```
