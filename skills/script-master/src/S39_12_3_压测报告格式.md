## S39 12.3 压测报告格式

### 12.3 压测报告格式

压测结束后，总控必须输出：

```
【压测报告】
压测时间：____
压测范围：S__ - S__

阶段通过情况：
  S__ ✅ 通过（产物：____）
  S__ ✅ 通过（产物：____）
  S__ ⚠️ 降级（原因：____，缺少：____）
  S__ ❌ 未执行（原因：____）

整体流水线通顺度：____（通顺 / 局部阻塞 / 严重阻塞）
主要阻塞点：____
建议补强的材料：____
是否可进入正式模式：是 / 否（需先____）
```
