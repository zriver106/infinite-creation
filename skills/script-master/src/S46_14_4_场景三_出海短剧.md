## S46 14.4 场景三：出海短剧

### 〔S46-001〕 14.4 场景三：出海短剧

```
推荐组合：
  S1-S3：剧本框架（建档 + 分集大纲，标注文化敏感度风险）
  S4：剧本写作（M1 + R1，或中文短剧拍摄稿格式后续翻译）
  S5：剧本医生（默认 5 人天团 + 出海发行官 + 平台算法师）
  S6：剧本写作（修订）
  S7：台词专家（十一维，文化敏感度+切片传播度必检）
  S8：剧本写作（整合）
  S9：最终包（含双语版本规划）

关键提示：
  - 文化禁忌预检（宗教 / 种族 / 性别 / 历史）
  - 价值观本地化
  - 切片传播度评估
  - 翻译友好的台词结构（避免中文成语 / 谐音梗）
```
