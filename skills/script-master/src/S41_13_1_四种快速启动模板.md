## S41 13.1 四种快速启动模板

### 13.1 四种快速启动模板

用户输入以下任一关键词，总控直接套用对应模板，跳过繁琐的规则说明。

### 模板一：短剧启动

**触发词**：`短剧` / `竖屏短剧` / `抖音短剧` / `红果短剧`

**总控直接输出**：
```
【短剧快速启动】
你的项目类型：竖屏短剧（多集连续）
推荐配置：
  - 模式：M1 标准影视（或中文短剧拍摄稿格式）
  - 节奏：R1 短剧节奏
  - 分集开关：是
  - 单集字数：800-1500 字
  - 集数建议：先写 1-3 集试稿

接下来我需要你确认 4 件事：
  1. 题材方向（例：逆袭 / 重生 / 复仇 / 甜宠 / 战神）
  2. 主角人设一句话（例：被赶出家门的隐藏继承人）
  3. 核心爽点是什么（例：打脸前妻 / 身份反转 / 碾压反派）
  4. 语言风格偏好（标准 / 白描 / 浓烈 / 喜剧——如不确定可说"你推荐"，我会给建议）

确认后我会调用【剧本框架】生成项目档案和分集大纲。
```

**触发词**：`AI 微电影` / `AI 短片` / `微电影` / `Sora 短片`

```

  - 节奏：R5 微电影节奏
  - 分集开关：否
  - 字数：3000-6000 字
  - 下游工具：Sora / 可灵 / Seedance / Runway

接下来我需要你确认 4 件事：
  1. 主题（例：关于"被遗忘的人"/ 关于"第一次相信"）
  2. 主角一句话（例：一个能听见旧照片声音的女孩）
  3. 核心情绪（例：温情 / 哲思 / 反差搞笑）
  4. 语言风格偏好（标准 / 白描 / 浓烈 / 喜剧——如不确定可说"你推荐"，我会给建议）

确认后我会调用【剧本框架】生成项目档案和千字大纲。
```

```

你的项目类型：出海短剧 / 跨文化项目
```
