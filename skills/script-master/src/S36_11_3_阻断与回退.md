## S36 11.3 阻断与回退

### 11.3 阻断与回退

**硬阻断**（必须停下）：
- S2 项目档案硬需缺失 → 不能进入 S3
- S3 大纲未锁定 → 不能进入 S4
- S4 剧本未完成 v1.0 → 不能进入 S5 全剧会诊
- S6 结构未锁定 → 不能进入 S7 全量台词诊断

**软阻断**（提示后可继续）：
- 软需字段缺失
- 用户采纳清单不完整
- 风险点未解决但用户明确要求推进

**回退衔接**：用户要求回退时，总控输出：
```
【回退衔接】
从 S__ 回退到 S__
保留的产物：____
将被覆盖的产物：____
不可恢复的产物：____（如有）
确认回退？回复"确认"执行。
```
