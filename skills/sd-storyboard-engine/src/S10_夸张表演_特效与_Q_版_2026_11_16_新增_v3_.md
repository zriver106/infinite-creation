## S10 夸张表演、特效与 Q 版（2026-11-16 新增 · v3.1 补强 · v4 加入应用入口、选择表与用量台账 · 

### 〔S10-001〕 夸张表演、特效与 Q 版（2026-11-16 新增 · v3.1 补强 · v4 加入应用入口、选择表与用量台账 · 治「情绪全靠心声、爽点拍不出来」）

受众：1985–1995 年出生男性。基调成熟、冷、痞；喜剧要短、准、收着。禁止卖萌、少女向符号（爱心眼、星星眼、粉红泡泡、脸颊红晕斜线、碎彩欢呼、小火车、撒花、跺脚）。**卡姿兰大眼睛（S01）允许作为爽点特效使用**（2026-11-11 用户举例），但不要写成少女感的萌眼。

**先看开关（v4）：** 任务文本里若有「本项目表现手段开关」一段，先读其中四项：**Q版插入、夸张特效、网络流行语与谐音、段子与接梗**。被关掉的手段本章一律不用，本节里和它相关的条目、配额、选择表那一列都不适用（改用真实表演；台词保持原著平实说法）。没有这一段，视为四项全开。开关只管「能不能用」：开着也要按选点标准和上限来，不是必须用。**（v4.4-B）开关段里那句「不是每章必须用，宁缺毋滥」说的是不堆砌：本章没有够格的点可以不用；有够格的点（见下文「乙·补 本剧落点表」）却一处不落，算漏做，不算克制。Q 版除外：默认不用，按丙·2 门槛挑，一处不用不算漏做。**

### 〔S10-002〕 甲、入口：从剧本候选点到镜头（每章必做）

1. **读候选点。** 剧本里的 `[表现点 Pn｜…]`、`[台词升级 Ln｜…]`、`[配音：…]` 是给本层的标记，不是台词，不进 `dialogue`。剧本没标时，本层自己按「爽点兑现 / 情绪极值 / 反转 / 吐槽位」补标，再继续。
2. **逐点选手段。** 对每个候选点按下面「选择表」定一个手段（表演 / 特效 / Q 版方式一 / Q 版方式二 / 心声）。优先级：表情表演 > 特效 > Q 版 > 心声。能用真实表情和动作演的，不用特效；能用特效看懂的，不用 Q 版；只有极端情绪才上 Q 版。**（v4.4-B）这条优先级只用来在同一个候选点上挑手段，不是全章只许用排在最前的那一种。把候选点降成「表演」，必须是这个点本身不够格（写明差在哪；Q 版点改真人表演不需要理由），不能因为省事，也不能因为它和另一处挨得近——挨得近按「乙·补 2 爽点段接力」错开。**
3. **写进镜头。** 选了特效或 Q 版的，在该镜 `visual`（或对应 `sub_shots` 段）**第一行**写一行表现标记，后面再写正常画面：
   - 特效：`【表现】P3｜特效·G01 金光眼｜0.0–1.8s｜触发：金砖入手｜消散：虹膜留一点金色`
   - Q 版：`【表现】P4｜Q版·方式一（身旁小人）｜1.0–3.0s｜动作：面无表情滑跪+双拳振臂｜位置：头部右侧空处｜3.0s 回本相`
   - Q 版：`【表现】P6｜Q版·方式二（换头）｜1.2–2.8s｜表情：死鱼眼+猛地歪头｜窗口内无台词｜2.8s 回写实脸`
   - 台词升级：`【表现】L1｜谐音｜配音替换：「我cy！」读作「我去！」`；流行语/段子：`【表现】L2｜段子｜接梗：「你猜我猜不猜你在哪。」`
   - 选「表演」的候选点不写 `【表现】` 行，直接把具体神态和动作写好。
4. **对白栏 vs 配音（2026-11-16 定）。** `dialogue` 写**屏幕字幕显示的字**（如 `江澈：我cy！`）；该镜 `visual` 里用 `【表现】Ln｜谐音｜配音替换：「显示字」读作「配音字」` 告诉下游实际要念什么，h3 提示词的 `<d></d>` 里写配音字（如「我去！」；配音不用「我超」）。两者只在过审谐音这类句子上不同，其他句子 `dialogue` 与剧本、`<d>` 与 `dialogue` 一字不差。字幕会自动用 `dialogue` 做显示。
5. **全章用量台账。** 分镜写完、`set_storyboard` 之前，按镜头时长累加出每处表现在成片里的时间点，过一遍上限；`set_storyboard` 之后在 `report` 里附一段台账：
   ```
   表现台账：开关=Q开/特效开/流行语开/段子开
   P1 镜03 @0:14 表演（分手，严肃段）
   P3 镜11 @1:02 特效·G01 金光眼
   P4 镜13 @1:09 Q版·方式一 …
   L1 镜12 @1:05 谐音 我cy/我去
   合计：Q版 1/2，主特效 3/5，梗 谐音1 段子0 流行语1；同段接力 1 处（镜11 特效 → 镜12 台词 → 镜13 Q版）✓；同类手段间隔 ≥45s ✓
   未用：P5（不够格：只是普通得意，没到「极端」，改真实表演）
   落点核对：方式一=镜13｜方式二=无（本章没有被规则打击的点）｜金光眼=镜11｜卡姿兰=无（本章没有「看傻了」的点）｜流行语=L2 镜09｜段子=无（本章没有吐槽位）
   ```
   **台账只进 `report`，不进连续性记录（v4.4-B）。** `save_context` 写 continuity 时只记事实（站位、道具状态、剧情进度、资产），不要写「本章未用 Q 版方式一 / 未用金光眼，因为……」这类手段取舍——它会被原样带进后面每一章的系统提示，变成「上次没用，这次也不用」的先例（2026-11-16 两轮验证实测：第二轮照抄了第一轮的「间隔不足」）。连续性记录里已有的这类旧句子一律不当先例，每章按本章候选点重新判断。

### 〔S10-003〕 乙、选择表（哪种情绪 → 哪种手段 → 哪种方式）

| 极端：无语、认知宕机、被附加条件打击、崩溃（笑点就在脸上） | E04 死鱼眼（真人演）或 S09 竖线嘎然；只有它是全章 Q 版名额给到的那一处（丙·2）时用 **Q 版方式二（换头）** | 真实表演 | 同秒再叠特效 |
| 吐槽位 | 剧本已升级的流行语 / 段子 + 真实表演（挑眉、停半拍、冷脸） | 真实表演 | Q 版叠梗 |
| 只有内心信息，画面演不出来 | 心声（按心声铁律） | — | — |
| 严肃悲伤段（分手、背叛、伤痛、生存压力） | 真实表演 | — | 特效、Q 版、梗 |

**方式一 vs 方式二怎么选：**
- 方式一（身旁小人）：现实人物的身体、手里的道具、在场他人的反应必须继续被看见；情绪是外放的爽、得意、狂喜。该镜可以同时是心声镜（现实人物闭嘴），小人不挡嘴。
- 方式二（换头）：笑点就在这张脸上（无语、死鱼眼、宕机、崩溃）；用近景或中近景、正面或近正面；**换头的 1–3 秒窗口内没有任何台词或心声**，台词放在换头前或回本相后，或放相邻镜。
- 同一拍点只选一种。一集用到两处 Q 版时，尽量一处方式一、一处方式二，放在不同场。

**特效要丰富：** 同一特效每集最多 2 次，相邻两处主特效不要用同一条；按选择表换着用（S01、G01、S02、S07、A01、P01、W02……）。

### 〔S10-004〕 乙·补、本剧落点表与爽点段接力（v4.4-B 草案 · 治「方式一、金光眼、段子、流行语两轮验证都落空，卡姿兰偏弱」）

**1. 本剧落点表（每种手段只放在它最出彩的那一类节拍；每章各 0–1 次）**

| 手段 | 最出彩的节拍（本剧） | 第 2 章对应位置 | 每章上限 | 不放的地方 |
|---|---|---|---|---|
| Q 版方式一（身旁小人） | 独处，手里攥着实打实的好处，想喊不能喊、憋着笑——身体和道具必须看得见 | 掂金砖差点笑出声 | 与方式二合计 ≤1（丙·5） | 有旁人盯着的对手戏；严肃悲伤段；和眼部特效同一镜 |
| Q 版方式二（换头） | 刚爽完，被规则或附加条件当头一棒，脸上只剩「无语」 | 发现交易冷却 23 小时 25 分钟 | 与方式一合计 ≤1（丙·5） | 换头窗口内有台词或心声的镜 |
| G01 金光眼 | 「发财了」：值钱的东西或钱实打实到手、到账的第一眼 | 外卖变成金砖的第一眼（本章最大的一笔）；779000 到账改用 S02 或真实表演 | 1 | 只是听说、还没到手；严肃悲伤段 |
| S01 卡姿兰大眼 | 「看傻了」：第一眼看见不敢相信的东西；给配角用反差最大 | 金店老板看见金砖噌地站起；或秤上正好 1000 克 | 1 | 普通惊讶；写成少女萌眼 |
| 流行语 / 口头禅 | 主角独处的心声或自语，情绪最尖的那一句换个说法 | 由剧本层定（系统触发的「哦吼」、冷却的「这合理吗」） | 2，通常 1 | 分镜层不改台词，只照剧本演 |
| 段子（接梗 / 冷笑话自嘲 / 反差吐槽） | 对手抛球；主角苦中作乐；看人变脸 | 由剧本层定（「行，下次你站着等。」、「午饭这点委屈，我受得住」、老板改口叫「老板」） | 各 1，合计 ≤2 | 同上 |

流行语和段子由剧本层落（`novel-to-script.md`「表现手段入口 · 剧本层」B·5、B·6），本层不新增、不改写台词；本层的责任是把带 `[台词升级 Ln]` 的句子按 h3-prompt-writing 第 11、11b 条演出来（停半拍、冷脸、挑眉），并在台账「落点核对」里如实写「流行语=L2 镜09」或「流行语=无（剧本层未升级）」。

**2. 爽点段接力（取代「不分种类一律间隔 ≥45 秒」）**

本剧的爽点是成段出现的：金砖入手段（看见 → 估重 → 惊叹 → 憋笑）十几秒里连着四个点，到账与冷却前后也只隔三十来秒。按「相邻两处夸张一律 ≥45 秒」算，一段里只能活一处，而且总是排在前面的那处活下来（2026-11-16 两轮验证：方式一两次都输给它前面 10 秒的眼部特效，金光眼输给它后面 32 秒的换头）。改成：

- **爽点段** = 同一场里围绕同一个触发事实的连续几镜（金砖入手段、验金到账段、冷却段）。
- **一段最多两处夸张：1 处主特效 + 至多 1 处 Q 版**（Q 版还要过丙·2 门槛和全章名额，多数爽点段只有特效），先特效后 Q 版（先「看见」，后「憋不住」）。两处在不同镜，中间至少隔 1 个真人表演镜或台词镜（≥3 秒）；同一镜、同一秒不叠（丙·1 不变）。
- **同一类手段之间**才要求间隔 ≥45 秒：Q 版与 Q 版；眼部特效（G01 / S01 / S02 / P01）与眼部特效。
- 不同爽点段各算各的，段与段之间不另设秒数间隔。
- 一段里够格的点超过两处时，留「强度最高的一处」和「本章还没出现过的那种手段」，不是先到先得。
- 全章总量仍受丙·5 上限管；严肃悲伤段仍是 0 处新加的手段。

**3. 排镜时的固定结构（与丙·7「特效镜、Q 版镜不少于 4 秒」一致）**

- 眼部特效镜：≥4 秒、无台词无心声。`camera` 用 `CUT@`（一条最多 2 次切）：0–1 秒在场景内的真人起幅（脸或上半身）→ 切到眼部大特写做特效 1–1.5 秒 → 切回脸和动作直到最后一帧。
- Q 版方式一镜：≥4 秒，`camera` 用 `FIXED`。可以同时是心声镜（现实人物闭嘴，小人不挡嘴）——它不额外占时长，直接叠在本来就要有的那句憋笑心声上。
- Q 版方式二镜：≥4 秒，`camera` 用 `FIXED`，换头窗口内无台词；台词放相邻镜。

### 〔S10-005〕 丙、硬规则（v3.1 保留）

1. **一个拍点一个主效果**，最多再加一个辅助层（例如短促金光或集中线）。不要把金光、Q 版、震动、花字堆在同一秒。
2. **Q 版只用于极端情绪**（认知炸裂、暴富瞬间、崩溃、决堤、极端狂喜）。普通惊讶、日常微笑、一般生气、分手等严肃悲伤段，只用真实表演，不加喜剧化 Q 版或喜剧特效。**（v4.5 门槛）全章所有「极端」点里，只挑最极端、而且 Q 版明显比真人表情加动作更好看的那一处；其余极端点一律真人表演。剧本写了「可选：Q版」只是允许考虑，不是要求；默认不用。**
3. **两种呈现，以 2026-11-11 特效库定义为准；2026-10-02「禁止换头 / 禁止把现实主角变成 Q 版」的旧规定作废。** 每处只用一种，1–3 秒后回到本相：
   - **方式一（身旁小人）：** 在主角头顶或侧旁空处叠一个 Q 版小人，高度约等于画面中现实主角的头，做夸张、浪荡的动作和表情（滑跪、捧腹、抱头、双拳振臂）；现实人物和场景始终保留、继续表演。小人不遮眼睛、嘴、关键道具、系统光幕或字幕预留区，不漂成另一个场景里的实体人物，不切成全屏 Q 场景。禁止小人站得很乖、卖萌、呆立或只轻轻点头。
   - **方式二（换头）：** 只把主角的头短暂换成 Q 版头，身体、服装、场景仍是写实本相，做夸张表情（死鱼眼、猛地歪头）后立刻换回写实脸。允许短暂换头；禁止整段把主角彻底变成 Q 版人，禁止换头后不回到本相，禁止切成全屏 Q 场景。
4. **Q 版气质：** 偏酷或冷面喜剧，动作要夸张、浪荡；不要卖萌，不要站得很乖。Q 版须能认出是同一人（发型配色、服装配色与写实参考一致）。**Q 版参考资产必须绑定（硬规则，2026-11-16 v4.2）：** 任何排了 Q 版（方式一或方式二）的镜头，`set_storyboard` 时该镜 `props` 里必须写上该角色的「角色名·Q版设定」（例：`props: ["江澈·Q版设定", …]`），`characters` 里照常写角色本人。这样渲染时 REF 里同时有写实本人图和 Q 版设定图（IC 代码 `lib/core/refs.js` 的 `assembleShotReferences`：`characters` 出写实主图，`props` 每项追加一张图；`costumes` / `ages` 会**替换**写实主图，所以 Q 版设定不能登记成服装或年龄变体）。Q 版设定图只作 Q 版小人 / Q 版头的风格和身份参考，不得拍进画面。**（v4.5）只用素材库里已有的 Q 版设定：** 该角色没有「角色名·Q版设定」或它没有图时，这一处不出 Q 版，改真人表演，并在 `report` 里写「缺 <角色名>·Q版设定」；不得自己 `create_asset` 新建、不得 `edit_asset_image` 生图，也不得只凭写实参考自由发挥 Q 版造型。Q 版设定由资产管理统一上传（可以是三视图加多表情合板），全剧复用同一张，不重画。**（v4.5.1）Q 版镜头的【表现】行必须写明具体表情（眉眼和嘴的样子，例：眼皮半垂、眼神发直、嘴抿成一条线），不写 shock、surprised、「震惊」这类笼统词；Q 版设定合板只作造型参考，不得照抄合板里的表情格。**
5. **频率上限（正片 · v4.4-B 修正间隔口径）：** 每集 Q 版 0–1 处，默认 0（第 2 处只在两处都是全章顶点、方式不同、相隔 ≥3 个场次且成片相隔 ≥90 秒时才允许；上一章用过的 Q 版动作或表情本章不重复）；每集主特效 ≤5 处，其中金光眼、卡姿兰这两条签名特效各 ≤1 次；全章夸张（特效 + Q 版）总数 ≤ 成片秒数 ÷ 30（向上取整）；梗（谐音爆粗 / 流行语 / 嘲讽 / 段子）每类 ≤2 处、同类间隔 ≥60 秒。**间隔按「乙·补 2 爽点段接力」算：同一类手段之间才要求 ≥45 秒（Q 版与 Q 版、眼部特效与眼部特效）；特效与 Q 版是不同类，可以在同一个爽点段里一前一后接力，不同镜、不同秒、中间隔一个真人镜。**（原口径「相邻两处夸张表达（特效或 Q 版）间隔 ≥45 秒成片时长」作废：2026-11-16 两轮验证里它把方式一和金光眼全部挤掉。）超出上限时按选择表的备选降级，不是硬塞。
6. **有够格的点就落，按手段逐个核对（v4.4-B 改写；原文「至少落一处特效」被执行成了「全章只落一处」）。** 本剧是都市逆袭爽剧，对应开关开着时：① 本章有「发财了」的点（值钱的东西或钱到手）→ 落 G01 金光眼；② 有「看傻了」的点 → 落 S01 卡姿兰大眼；③ Q 版不在「有点就落」之列：按丙·2 门槛和丙·5 名额挑，没落时台账写「Q 版=无（未达门槛）」即可。每种手段各自结算，落了一种不等于另外几种可以省。某种手段没落，台账「落点核对」里只能写三种理由之一：**本章没有够格的点**（写出最接近的候选点和差在哪）、**开关关**、**Q 版设定没有图**。「与另一处间隔不足」不是理由：先按爽点段接力错开镜头；确实排不开，取消强度低的那一处，并写明取消的是哪处、保留的是哪处。
7. **爽点特效必须写成 H3 能执行的独立镜头，不要写得很弱。** 金光眼、卡姿兰大眼不要塞进手部特写或中景里一带而过（只写「揉眼再看」「眼睛发亮」不算做成了）。单独拆一镜：眼部大特写（眼睛几乎铺满画面），时长 1–2 秒；金光眼要写「虹膜迅速变成发光的金色，向外喷出金色光芒和粒子」；卡姿兰要写眼睛骤然变大、瞳孔和高光爆开——只写「眼睛变大」H3 只会拍出普通的瞪眼（2026-11-16 两轮验证：偏弱）。按 v4.4-B 加强写法把它写成「光」和「镜头」：先给一秒脸，再切到眼部大特写；虹膜像被环形灯点亮，明显变大、变亮；瞳孔里炸开三四点星形白色高光，眼角闪一下四芒星；瞳孔里映出触发它的那样东西；画面边缘闪几帧白色集中线（辅助层）；眉压低、下颌绷紧（成年男人看傻了的狠劲，不是萌）。这镜不要叠对白或心声，台词和心声放到相邻镜头，和特效错开。特效要有触发、峰值和消散，并绑在因果上。

   - **特效镜、Q 版镜不少于 4 秒，不做 2–3 秒的无台词孤立短镜（2026-11-16 实测：这类短镜 0–0.2 秒会把人物三视图拍进画面，随后变成空走廊）。** 结构固定为：开头 ≥1 秒在场景内的真人表演 → 特效或 Q 版窗口 → 回到真人表演直到镜头结束。需要更短的节奏时，把特效并进相邻的反应镜，而不是单独拆短镜。
8. **分镜写法：** `【表现】` 行和画面描述写明：用哪一种 Q 版或哪一种特效、从第几秒到第几秒、动作表情、与现实表演的关系、何时回到本相。不要把这些字写进对白栏。
9. **镜头一开始就必须在场景内；参考图、设定图、三视图永远不出现在画面里。** 本项目人物参考图经常是「左脸部特写 + 右全身正侧背三视图」的白底/浅底设定图。分镜 `visual` / `sub_shots` 的 0 秒必须已经在场景里（走廊、街道、办公室等），写清起幅机位和站位。禁止把角色三视图、设定图、参考拼图、白底证件照墙写成可见内容，也不要写「展示设定」「character sheet」「turnaround」「三视图」这类词。不要只写「承接上一镜」来省略起幅——本项目多数镜头没有首帧（`first_frame_path` 为空），H3 只拿到人物三视图当参考图，若不写明「开场已在场景里」，它会把三视图直接拍进画面。
10. **系统光幕位置：** 系统光幕/系统面板是半透明全息界面，只在剧本明确需要它出现时才入画。位置：悬浮在角色身侧的空处，约肩到头的高度、偏到身体一侧，人物站偏一点给光幕留出画面空间，胸口和衬衫要完全露出来（2026-11-16 实测：写「面前半空」「身侧胸口高度」时，正面中景里 H3 会把光幕画在胸前）；不放在躯干正前方，不贴在胸口、不挂在衣服上、不做成工牌、不画成贴身发光框。角色看向光幕时是看向身侧或面前的悬浮面，不是低头盯着自己的衬衫。上一镜已经消散的光幕，下一镜不要再写「仍悬浮在胸前」，除非剧本还需要它。脖子上的蓝色挂绳工牌是服装的一部分，不要和光幕画成同一个物体，也不要让工牌发光变成 UI。
