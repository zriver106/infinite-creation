## S09 心声（OS）镜铁律（2026-11-23 按手册 M33/M34 重写，与 h3-prompt-writing 心声节同

### 心声（OS）镜铁律（2026-11-23 按手册 M33/M34 重写，与 h3-prompt-writing 心声节同口径；2026-11-16 原版第2、4、5条作废）

心声 = 角色没说出口的内心独白，由 H3 在本镜里直接念出（写进 `<d>`），画面里的人自然闭嘴。分镜层先把心声标出来，下游的 h3-prompt-writing 按心声节写提示词。2026-11-23 第6集实测：写嘴的词（连「抿成一线」「不张嘴」这类否定写法也算）反而让 H3 动嘴，所以分镜里一个嘴部词都不写。

1. **标记**：心声在 `dialogue` 和 `sub_shots` 里一律写成 `角色名（OS）：原文`（例：`江澈（OS）：这得有1000克吧？！`）；普通对白写 `角色名：台词`。电话声、系统声、旁白不是 OS。原文一字不改。此处「原文」指**已锁定的剧本台词**。若剧本层（story-pipeline-cn `references/novel-to-script.md`「表现手段入口 · 剧本层」）已把原著「卧槽」升级为显示字「我cy！」并附 `[配音：我去！]`，则 `dialogue` 逐字写显示字，实念字按本技能「夸张表演、特效与 Q 版」甲·4 用 `【表现】…配音替换` 交给提示词；不得改回原脏话。
2. **不强制单独成镜**：心声按剧情放在当前镜头里，可以压在动作上，人不为听心声停下来（TR-V09），也不为心声单独剪一镜。**一镜只有一种人声（手册 M33 第6条）**：这里的「镜」是视频里两个切点之间的一个镜头（提示词里的一个 `[Shot N]`）。有心声（或电话那头、系统声）的镜头里不放任何出口台词；同一条分镜里既有对白又有心声时，在 `sub_shots` 里用硬切分成两个镜头（各 ≥ 3 秒），对白一个镜头、心声一个镜头，中间隔 ≥ 0.8 秒；分镜太短分不开就拆成两条分镜。心声窗口整个落在自己的镜头里，不跨切点（2026-11-23 20:35 改，原「同一镜各占各的时间段」作废）。
3. **同场心声合镜**：同一场景里连续的心声（中间没有别人开口）合进同一镜，镜长 ≤15 秒。
   - **心声原文一字不改（2026-11-16 v2）**：**禁止**删字、改字、换词、把两句改写成一句、改写语序。唯一例外是念出来的数字：按 TR-V14 写成口语汉字（「月薪三千五百」写「三千五」，「1000克」写「一千克」），`dialogue`、`<d>`、`sub_shots` 三处一致（2026-11-23 改，原「数字原文照抄」作废）。冲突、打戏里太长的心声可以按原著意思压短（TR-V09），三处同改。
4. **机位只按剧情选**：背影、物件特写、反应镜、空镜、正脸近景都可以，只按剧情选，不为防对口型选机位，没有比例上限；不用捂嘴、背身、遮脸这类回避写法。不要求「正面近景、嘴在画面中间」（原第4条作废）。心声镜里别人在场照常绑定、照常写站位，不说话。
5. **表演只写眼、眉、头、肩、手**：`visual` / `sub_shots` 里每个露脸的人，开头写手册原句「他双唇自然合拢，嘴角放平，下颌放松，整个镜头里他只用眼睛、眉头和肩膀表现情绪。」，镜尾写「双唇一直自然合拢，保持到镜头结束。」每个心声窗口写 2–3 个眼神、眉头、点头摇头、肩膀、手的动作，贴合这句心声的意思，相邻两句至少换一项。整镜不写任何嘴部和呼吸的词，否定写法也不写（抿嘴、抿成一线、咬唇、撇嘴、苦笑、憋笑、咧嘴、张嘴、不张嘴、叹气、倒吸凉气、嘟囔、喘、胸口起伏都不写）。心声窗口里不吃、不喝、不拿筷子勺子杯子往脸前送（原第5条「闭着的嘴型」写法作废）。
6. **不写台账词**：不要在镜头描述里写「台词：无」「（无对白）」「（沉默）」这类字样，下游会被念出来；没有台词的镜头 `dialogue` 留空即可。
7. **连排**：整章不要连续 3 镜都是心声。
