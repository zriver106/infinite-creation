## S14 机位运镜与一镜到底（2026-11-16 新增 · MiniMax H3 / IC 分镜层 · 治「打斗看不清、运镜乱切

### 〔S14-001〕 机位运镜与一镜到底（2026-11-16 新增 · MiniMax H3 / IC 分镜层 · 治「打斗看不清、运镜乱切、人物串位」）

**适用与优先级**：项目视频模型是 MiniMax H3（IC 默认）时，本节对**每一条分镜**生效，打戏、追逐、走位、对峙尤其要用。本节与本文件 §六「长镜头（一镜到底）全片禁用」「站桩说话不超3秒」冲突时以本节为准（§四已写明「全片禁长镜」旧口径废止）。打戏**不再整段交给 sd-combat-engine 落地**：它只提供构思（为什么打、牌面、招式物理链），镜头切分和写法按本节和 h3-prompt-writing 的「Camera, one-take and fight shots」。心声（OS）镜、夸张表演/特效/Q 版、表达开关的条款不受本节影响：心声块仍是正面近景、固定或慢推；Q 版插入那一两秒机位不动。

**1. 先对齐单位。** IC 的一条分镜 = 一次 H3 生成（2–15 秒）。`sub_shots` 里的「0-3s｜」是**镜内时间片**，不是切镜；时间片只标进度。镜内真要切镜，必须在那个时间片里明写「切到〔新景别/机位〕」，没写就等于同一镜头继续。

**2. 每条分镜先定镜头形态（四选一，写进 `camera` 字段开头）：**
- **A 固定**：`FIXED / 景别 / 机位`。默认形态。冲击命中、手物接触、大动作（起身/倒地）、心声块、Q 版插入、有系统大面板的分镜一律 A。
- **M 简单运镜**：`MOVE / 景别 / 慢推（或慢拉、慢跟、慢摇）`，整条只有一个小幅、慢速的运动，不跨空间、不换拍摄对象，不算一镜到底，不写时空白板。心声块要慢推时用 M。
- **B 一镜到底**：`ONE-TAKE / 起幅景别→落幅景别 / 运动路径`，整条分镜只有一条连续的摄影机运动，没有切镜。
- **C 镜内有意剪切**：`CUT@Ns / 前景别→后景别`，一条分镜里最多 2 次切，每次写明在第几秒、切前切后各是什么画面、为什么此刻切（眼线、冲击、证据→反应）。

**3. 什么时候用一镜到底（B）。**
- 适合：同一时空里连续走位或逼近（主角大步走向对手、对峙绕步）；追逐；注意力从一个人移到他手里的东西、再移到另一个人；打斗里**不含命中特写**的一段（逼近、对峙、推搡后拉开距离）；情绪一路积累的连续对话（靠人物调度、前中后景、遮挡、移焦推进，不靠机械正反打）。
- 不用：冲击命中（扇、拳、踹、拍、砸）那一下；倒地/起身这类大动作；心声块；Q 版插入；系统大面板；精细的手物接触（递、接、数钱）；三人以上同时有动作；相机路线要经过的空间没有场景参考图（不能靠一句「无缝」凭空变出房间）。
- 用量：每章 1–3 条 B，挑最能体现空间和气势的段落；不要每条都推，不做无动机环绕、甩镜。
- 时长：B 形态一条 8–15 秒；短于 6 秒、只是靠近或跟一下的运动标 M，不标 B。
- **最好做、优先排的四类（v4.4）**：① 发现 → 逼近 → 站定对峙；② 打完之后的收束（相机从倒地的人缓缓移到站着的人，两人都不再出手）；③ 两人边走边说；④ 追、逃穿过一个有地标的空间。有打斗的章，优先把「逼近」做成一条 B，收束可以再做一条；命中那一下仍然不进 B。job 8d086e01 镜 3（背后跟拍 → 绕到右前侧停稳，10 秒）成片连贯，照它的写法。

**4. 一镜到底在分镜里怎么写（B 必填五项）。**
1. **触发**：哪个动作、目光或声音让镜头开始动（「甲看到车旁两人，迈步走过去」）。
2. **起幅**：相机在谁的哪一侧、多高、多远，画面里谁在左谁在右、各自朝哪。
3. **路径**：相机怎么动（跟、推、侧移、绕到侧面）、经过哪个地标（台阶、玻璃门、立柱）、速度怎么变；旧重点怎么退到边缘，新重点怎么进来。**整条只有一种运动**，可以加速减速，不中途改成另一种运动。
4. **落幅**：最后停在什么景别、谁的哪张脸/哪只手，第几秒停稳，停稳后至少留 1–2 秒给表情或台词。
5. **约束**：相机不穿墙、不穿人、不穿桌；越过轴线只能是相机看得见地绕过去（写清从谁身后绕到哪一侧），不能突然换边。
- `sub_shots` 按 3–5 秒一格写时间片，每格写人物动作；**运镜只在路径节点写，整条最多 3 处**（起步、经过地标、停稳），其余格只写动作，并写「同一镜头继续」。模型按运镜句的条数理解切镜数：每格都写一句新的推/拉/摇，它就会切成好几个镜头。
- **走路别僵（v4.4）**：走位、逼近、追逐的时间片写步态三样——步幅（大步 / 碎步 / 踉跄）、上身（前倾、肩膀随步子摆、手臂摆动或攥拳，手里的东西怎么跟着颠）、速度变化（越走越快，最后两步放慢、后脚跟上站稳）。不只写「走过去」「冲过去」，不从头到尾一个速度。

**5. 打斗：先构思、再分拍、再切镜。**
1. **构思（脑内，不输出）**：双方各有几种手段（远/近、徒手/器械）；距离曲线（远→逼近→交手→被打退→再冲）；至少一条可数的量，首选体力（站→趔趄→跪→蜷地）；伤情只写原著写到的，分级和上限按第 5b 条，不为了「可数」自己给伤情升级。都市写实打斗不加特效光，力量靠身体反应和同步声。
2. **分拍**：逐回合写四项——出手者和出手部位 → 命中还是被挡（打在哪） → 被打者反应（头偏、趔趄、倒地） → 回合结束时两人各站在哪、朝哪；外加同步声（「啪」一声脆响、闷哼）。禁止「两人扭打在一起」「一阵混战」这类概括句。
3. **切分**（一个回合通常拆 2 条分镜）：
   - **冲击镜（A，4–5 秒，v4.4 改）**：一个回合的蓄力 → 挥出 → 接触一次 → 顺势带过 → 被打者第一下反应，写在同一条里，写法按第 5b 条。景别用侧面双人中近景 / 中景，或过出手者肩的中近景：出手者认得出，被打部位朝镜头。这条没有任何台词、心声、电话声，不放系统光幕、Q 版和特效窗口；它和前后的人声都隔开 ≥0.3 秒。人打人不再用「只拍手/脚和被打部位」的局部特写（8d086e01 实测：看不出谁打的、残手入画、同一下被演了两三遍、3 秒短镜后半段空转）；手打物件（拍桌、摔门、砸东西）仍用手和物件的特写、第一帧手已在途中。
   - **反应镜（A，≥3.5 秒）**：只在被打的人要倒地、被踹飞、爬起时才单独拆；命中后人还站着的（普通耳光、拳打肩），反应已经在冲击镜后半段，不再拆。全景或中全景，全身入画，景别和冲击镜至少差一级；这条也不放台词。起幅写「命中已经发生之后」的结果状态，全条不再出现出手的动作和字样（第 5b 条第 2 款）。把人踹飞、打飞的回合也可以不拆：用一条全景（5–6 秒，两人全身）从蓄力写到落地。
   - **叫嚣/对骂镜**：说话的人做轻动作（指、瞪、抹嘴角），不在说话的同时出拳；大动作和台词分到两条。
   - **逼近/对峙/追（可用 B）**：没有命中的那一段用一镜到底把两人的距离变化拍清楚。
   - 一场三回合左右的打斗约 5–8 条分镜，其中最多 1 条 B。
4. **轴线**：打斗开始前定攻击轴线——谁在画面左、谁在画面右、谁往哪边打——整场不变；人物绕位时在分镜里写清路径。倒地的人倒向轴线另一侧时写清倒在哪（「倒在画面右侧的车门边」）。
5. **机位停与动**：B 形态里人物蓄力或僵住的那一拍，可以机位继续缓动、人物定住（最强反差）；两边都停是死画面，两边都猛动是糊画面。手持剧烈晃动只用在爆发顶点，计入 §四 的名额（剧烈晃动≤3段落），不另开名额。

**5b. 打斗因果链、力度与伤效（v4.4 · 2026-11-16 新增 · 依据 job 8d086e01「运镜打斗验证」成片 · 治「看不出谁打的、没挥臂、一巴掌扑倒、伤像贴上去、血迹凭空出现、打人者不动、同一下演三遍」）**

1. **冲击镜写满五环，按这个顺序，缺一环不交付：**
   - **谁出手**：出手者在这条里认得出——至少同侧肩、上臂和侧脸（或后脑）在画面里；出手用靠镜头一侧的手/脚，被打部位朝镜头。`characters` 把出手者和被打者都绑上。入画的人要么露到认得出，要么整个人在画外，不留只有一只手、半条手臂、半张脸贴着画面边缘。
   - **预备**：看得见的蓄力——上步、转肩、手臂抡到身后 / 拳拉到腰后 / 提膝。0 秒起幅就写「已经上了一步，手臂已在身后最高点」，随即挥出；不写两人站着对视再出手。
   - **接触**：哪只手的哪个面，打在对方哪一侧的哪个部位，配一声同步声。一个回合只接触一次；接触后手/脚顺势带过、离开对方身体（拳头弹回、脚收回落地），不停在对方身上。
   - **受力方向**：被打者朝出手肢体接触后继续走的方向动，用画面左右、朝镜头、背镜头写死。直拳、蹬踹沿攻击轴线把人推离出手者；耳光、摆拳是横着扫的，头顺着手掌扫过去的方向甩，上身被带向远离出手者的一侧。后面踉跄、倒地都朝这一侧。
   - **反应与力度相称**：按下表写，不加码；出手者自己的身体也要动。

   | 出手 | 出手者身体怎么动 | 被打者反应上限 | 伤效上限 |
   |---|---|---|---|
   | 普通耳光 | 上半步、转肩，打完手落回身侧 | 头甩过去、上身一晃、退半步到一步、抬手捂脸，人还站着 | 1 级 |
   | 含怒全力的耳光 / 重拳，且原著写明打倒 | 上一大步、蹬地转胯、整条手臂抡圆，打完身体跟过去半步 | 头甩 → 上身被带偏 → 脚下绊一两步没站住 → 侧身倒在受力一侧，离原站位不超过两步 | 2 级 |
   | 拳打肩、胸，对方硬吃 | 蹬地送肩，拳头打完弹回 | 肩被砸得后撤、上身一晃、后脚撑住 | 0 级 |
   | 蹬踹腹部 | 提膝、支撑腿站稳、送胯蹬直，再收腿落地 | 弓腰后退；原著写「踹飞」才双脚离地，摔在受力方向两三米内，蜷身 | 0 级 |

   - 原著给定的后果不改（如「一个趔趄栽倒在地」「地板上的牙齿」）：把出手写够重（表第 2 行），让后果看起来确实是这一下造成的。不写「轻轻一下配大后果」，也不自己加码：原著没有的掉牙、吐血、喷血、昏迷、扑出去好几步，一律不加。
   - 倒地是大动作：分 3 步写看得见的姿态（脚下一绊 → 膝盖一软 → 肩或臀先着地），写清倒向画面哪一侧、离原位几步；动作词不用「猛地」「瞬间」「一下子」「飞扑」这类压缩过程或放大幅度的词。

2. **一下只演一次。** H3 每条分镜独立生成，不记得上一条；凡是写到出手的字样，它都会再演一遍（8d086e01：耳光演了两遍；那一脚在镜 11 尾、镜 12、镜 13 头演了三遍）。
   - 前一条的落幅不停在「手挥到半途」「脚已在途中」，停在出手之前的状态：攥拳、咬牙、重心前压、迈出第一步。
   - 冲击镜之后的那一条，0 秒起幅写结果状态：出手者双手垂在身侧（或脚已落地站稳），被打者头已偏、身体已在失衡。全条不出现「刚挥完」「右腿刚蹬出」「手还在他脸边」「被这一巴掌打得」这类字样。

3. **打人的人也有戏。** 命中之后同场的每一条，出手者都写一个看得见的后续：收手、甩一下手腕、胸口起伏、攥拳、目光跟着对方移、上前半步俯视、别过头。原著写「站着不动」时，写成「脚不动，上身、手、呼吸、目光在变」。对方正在倒地的那几秒，出手者只写小动作（收手、喘、攥拳、目光下移）；上前、俯身这类大一点的动作放在对方落定之后。整条只写「站在原地」的不交付。这一条若是出手者的心声镜，照心声铁律写：后续动作只用眼、眉、头、手，嘴闭着，不写张嘴喘气。

4. **伤效：接触之后才出现，慢慢出来，克制。**
   - 时间：0 秒起幅和接触之前的时间片不写任何伤；伤写在接触之后的时间片，用「慢慢泛起」「渐渐红了一片」。
   - 分级（都市写实）：0 级 没有外伤痕迹；1 级 皮肤淡淡泛红，边缘自然晕开；2 级 泛红微肿，嘴角一点细血丝（只一处，不往下淌）——只用在原著写了出血或掉牙的回合。原著明写的结果物（例：地上一颗牙）当道具写清位置，不写它从嘴里飞出来的过程。
   - 不写：手印形状的红块、深红或紫红色块、往下流的血、吐血、带血的唾沫、满嘴是血、地上的血迹、两边脸都红。
   - 伤情台账：第一条打戏分镜 `sub_shots` 里、时空白板之前写一行 `伤情台账：〔谁〕｜〔哪一侧，如 朝镜头一侧的左脸〕｜〔几级〕｜自镜〔N〕第〔几〕秒起`，`report` 里再列一次。之后这个人入画的每一条，0 秒起幅照抄同一侧、同一级，不升级、不换边、不消失；左右按人物自己的左右写，并和连续性记录里前几章的伤情对上。
   - 地面痕迹（牙、掉落物）记进时空白板的「道具」项：必须先有一条分镜拍到它出现的那个动作，之后别的分镜起幅才能写它；没拍到产生过程的不写。

5. **位置接得上。** 前一条落幅写两人相距多远（一臂 / 半步 / 两步），后一条起幅相同；出手距离在一臂以内，够不着先写上步。倒地位置（受力一侧、离原位几步、头朝哪）写进时空白板，后面照抄。第三人每条写清位置和一个不同的反应（松手后退 → 捂嘴 → 上前半步又停住），不连着几条同一个姿势。

**6. 段内时空白板（B 形态、打戏、三人以上走位的分镜必填；其他可选）。** 在这条分镜 `sub_shots` 最后一行写一行「时空白板」，按时间点列三项：
`时空白板：t=0s｜相机：〔在谁哪一侧、高度、距离、朝向〕｜人物：〔甲 画面左、面向右、站在坡道底〕；〔乙 …〕｜道具：〔车钥匙在甲右手〕 → t=6s｜… → t=末｜…（=下一条起幅）`
- 每个时间点三项都写全；相邻两个时间点之间位置、朝向、道具有变化，必须在中间的时间片里写了造成变化的动作（走、绕、推开、被踹飞、掉落）。
- 末时间点就是落幅：同场景且时间连续的下一条分镜，起幅照抄它。
- 同一场景第一次出现时，把场景地标、攻击轴线和人物默认站位写进人物圣经 bible 的「场景站位表」（scene-blocking-consistency），白板里的位置不能和站位表矛盾。

**7. 分镜之间的衔接。**
- 同场景、时间连续、不做一镜到底的两条分镜之间，后一条起幅至少换一样：景别差一级以上，或机位换一类（正面类 / 侧面类 / 背面类）。
- 同一个连续动作（走路、起身、拿放东西、挥拳）不跨两条分镜：要么在前一条做完，后一条从做完的状态开始；要么剪在动作中段，后一条接剩下的动作（动作匹配切），不重复做一次。
- 跨分镜的「伪一镜到底」只用完全遮挡点（人物背部贴镜头、门框、立柱、暗部）或动作匹配，前后两条的运动方向、速度、构图、光线写成一致；IC 自动流程不做首尾帧接链，不要假设下一条会从上一条的最后一帧开始。

**8. 自检（写完全章分镜后逐条过）：**
- 每条 `camera` 以 FIXED / MOVE / ONE-TAKE / CUT@ 开头；FIXED 条里没有推、拉、摇、跟；B 条五项齐全，运镜句 ≤3 处，没有「切到」。
- 冲击命中都在 A 条里，没有台词或心声；每条冲击镜里出手者认得出，蓄力、接触、带过在同一条，接触只有一次；倒地的反应镜全身入画、≥3.5 秒，起幅是「打完之后」，没有把同一下再写一遍。
- 打斗每个回合四项齐全，没有概括句；攻击轴线全场一致。
- 反应幅度对得上第 5b 条力度表；出手者每条都有后续动作；接触前没有伤，伤不超过表里的上限，有伤情台账且各条同侧同级；地面痕迹都有来历；画面边缘没有残手、半张脸；两人距离前后接得上。
