## 一、画风与人

- 派单照抄缺图单开头的「画风」一节，不抄项目风格名；不写「动漫」「国漫」「二次元」「插画」。
- 场景：照片级写实室内或街景摄影，像建筑效果图或实拍剧照。人物 / 服装：照片级写实，像真人定妆照。道具：照片级写实产品摄影。
- 人物和人群：中国人长相，当代中国城市普通市民穿着。人群图逐张脸看。
- 画风样张在本技能 resources/画风样张/（审图用 view_style_sample 看）。

## 二、底图

- 前作（V2）有定稿图的，拿它做图生图（缺图单行的 base_ref）。冲突时：场景以底图为准；人物、服装、道具原著写明的照原著，原著没写的照底图；同场季节一致优先（例：民警统一夏季短袖）。剧本人数冲突的列存疑，不改剧本。

## 三、场景多视角图（手册 12 原文）

## 场景多视角图（_MV）制作手册

用户 2026-11-26：「场景的多视角一致性非常重要，否则后面无论怎么改都会有问题，因为第一步就错了。」

多视角图是整个场景的地基。站位、机位方向、人物从哪进出、跨章布局是否一致，都从它来。它错了，后面的分镜、提示词、出片怎么改都改不对。所以这一步宁可慢，要一次做对。

对应规则：adapt J-009（出图与验收）、J-010（场景生命周期与地点表）、J-011（四问）、J-006（有人的阶段变体）；h3 F5V-001、F5V-002（写稿怎么用）。

### 一、开做前要有的东西（缺一样不派图）

| 输入 | 内容 | 出处 |
|---|---|---|
| 戏份说明 | 生命周期（首末章）、每章用到的区域、人数峰值、动线、四问答案 | IC 资产分析（J-010、J-011） |
| 档次 | 按原著的价格、品牌、身份线索定（例：「399一位」= 高端餐厅），写明「不能像」什么 | 戏份说明 · 规模档次（J-009 1c） |
| 布局表 | 每件固定物（门、窗、柜台、桌椅、过道、灯具、设施）的位置、朝向、数量 | 戏份说明 · 布局表 |
| 出入口拓扑 | 内外出入口有几处、各通到哪里，所有章的「谁从哪进、从哪出」都走得通。核法：派图前把每章的进出路线在 D 上走一遍，走不通就先改布局表 | 戏份说明（J-010 2b） |
| 机位和朝向 | 每格机位站在哪、朝哪个方向；人坐在家具的哪一侧、面朝哪（屏幕、桌面朝向由此推出）；时段和光线方向 | 布局表 |
| 画风样张 | V2 定稿里材质、光影最真实的几张，人物和场景都有 | `M\_\am_出图_V3\画风样张\` |
| 底图（有前作定稿时） | 同一地点在前作里已定稿的场景图。A 格拿它做图生图：保留空间、装潢、材质和画风，只去掉人和文字、补上关键件。布局表和底图冲突时以底图为准，差异逐条记下，交 IC 重跑资产分析，让布局表跟底图对齐（走 IC 工作流，不手改）。用户 2026-11-26：「用v2 的场景图 做基础去 做多视角吧」 | 前作资产目录；对应表由审图会话列 |

### 二、出图三步（每一步审过才进下一步）

1. **只出 A 主视角一张。** 派单写清以下几项：
   - 布局表要点；
   - 档次；
   - 画风要求：照片级写实室内（或街景）摄影，像建筑效果图或实拍剧照，对标样张 S400_MV、S434_MV、S156；真实建材纹理、真实光源阴影、写实透视、正常饱和度。不要动画背景画风、平涂、描边、柔光雾化、高饱和卡通色、日系街景；窗外、门外一律是中国城市街道。派单里不写「动漫」「国漫」「二次元」「插画」，也不写 IC 的项目风格名；
   - 不带人、不带剧情道具、画面里没有可读文字。

   审 A：把布局表逐件对一遍，看档次，和画风样张并排比。过了才定稿。
2. **拿定稿的 A 换视角，出 B、C。** 用图生图换机位：
   - B 是反打，C 是侧面。
   - 内容一律不变，只换机位：桌椅的数量和款式、墙地面材质、灯具、陈设、光线都和 A 一样。
   - 逐件拿 A 对着审：A 里有的东西，B、C 在对应位置也要有，数量、款式、朝向都一样；A 里没有的，B、C 不能多出来。
3. **D 平面图照布局表画**，当核对基准：A、B、C 每一件东西在 D 上都要找得到。四张都审过，再拼成 2×2，上传 IC 用拼好的这张。

### 三、逐件对照表（am 交图必须附，审图逐行核）

| 物件 | 数量 | 款式 | 布局表位置（写到偏东、偏西、正中这一级） | 朝向 | A 里在哪 | B 里在哪 | C 里在哪 | D 上在哪 | 一致？ |
|---|---|---|---|---|---|---|---|---|---|

有一行对不上，整张退回，不改其中一格凑合。

**审图纪律：**
- am 自己填的对照表常常全打「✓」，其实有错。审图人必须自己逐行看图核对，不信自填。
- 写退回意见时，先写清这格的机位朝向，再推出左右，避免把左右说反。
- 同一地点的第二张 `_MV`，直接复用第一张的 D 文件，不重画。

### 四、常见错误（见到就退）

| 错误 | 例子 | 怎么防 |
|---|---|---|
| 左右镜像 | 电子秤 A 在左、B 在右；A 格整体左右反了 | 先对 D，再对 A；反打的左右按机位推算 |
| 数量、款式变了 | 每桌一个锅变成两个；多出一组柜子 | 逐件对照表 |
| 门窗、出入口和布局表不符 | 东墙画成了窗；橱窗里的柜台位置和 D 不符 | 出入口拓扑写进派单 |
| 档次不对 | 399 一位的自助画成食堂 | 派单写明档次和「不能像」 |
| 画风偏动漫、日系 | 插画式平涂天空和树；墙地没有材质；工位区人物是日漫脸和描边；网约车内饰柔光雾化像插画；花店门外是日本住宅街。根因：派单抄了 IC 项目风格名「写实偏动漫 3D」 | 派单禁用「动漫」类词，写「照片级写实摄影」；A 先和 S400_MV 并排比，像效果图才过 |
| 常识错 | 国内公交驾驶位在右 | 四问的「功能」一问照现实常识（J-011） |
| 四格不是同一空间 | 一次出四格，三个视角各是一个地方 | 先 A 后换视角，不一次出四格 |
| 侧面格照抄正面构图 | C 从西墙朝东看，东西向的柜台应顺着视线往里延伸，却画成横在正前方 | 派单写明每格机位朝向，并写明「东西向的东西在 C 里是纵向」 |
| 透过门窗看到的室内和 D 不符 | 店外那格透过橱窗，看到柜台贴着玻璃；D 上柜台在店内深处 | 外景格要求「透过门窗看到的内部照 D」 |
| 屏幕、桌面朝向自相矛盾 | 工位面北、人坐南侧，所以屏幕朝南：从南拍看到屏幕正面，从北拍只能看到背面；A、B 两格却都画成屏幕朝镜头 | 先在 D 上标出人坐哪侧、面朝哪，再按每格机位推出看到的是屏幕正面还是背面、椅背还是椅面；长排家具同样先在 D 上定走向，再推每格里是横向还是纵深 |
| 数量和排数不对 | 布局表是 3 排 × 7，画成了 4–5 排 | 对照表单列「数量」 |
| 位置偏移 | 门在「南墙偏西」，画到了正中 | 对照表写到偏东、偏西、正中这一级 |
| 几格之间家具款式不一致 | A、B 有隔板，C 没有 | 对照表单列「款式」 |
| 几格画风、渲染不统一 | A、B 像实拍，C 像 CG | 审 B、C 时和 A 并排比 |
| 光线时段不对 | 要的是白天近中午，画成了金黄的夕阳 | 派单写明时段和光线方向 |
| 四格家具款式、排数、朝向各不相同（典型反例） | 公司工位区：A 是浅木桌面加矮隔板，4 排以上；B 是灰桌面、后排没有隔板，5 排；C 是高隔板长排纵深。布局表其实是 3 排 × 7、每排沿东西排开、全部面北、人坐南侧：A 从南往北拍，三排是横向的三条，看到椅背和屏幕正面；B 从北往南拍，也是横向三条，看到屏幕背面和椅子正面；C 从西往东拍，三排是顺着视线往远处延伸的三条长排。用户原话：「这种其实一致性都是错误的」。这张是一次出四格的老做法出的 | 三步法，每格逐件对 A；派单写明排数和朝向 |
| 人群长相不对 | 大厦门前围观一批，围观者全是欧美人长相，故事在中国城市 | 人群变体和配角单写明「中国人长相，当代中国城市普通市民穿着」，审图必核 |
| 同一地点几张 `_MV` 的 D 画法不一样 | 两张 D 布局一致，画法却不同 | 第二张直接复用第一张的 D 文件 |

### 五、变体和多张

- **有人的阶段（满员、围观、满座）：** 按 J-006 单出一张变体，以审过的 A 为底：同机位、同装潢，人群位置照 D，命名「地点名·阶段」；一个地点几个区域都有人群时，命名「地点名·区域·阶段」。`_MV` 本身一律空场。
- **昼夜、营业前后：** 同一张布局表、同一张 D，只换光线和陈设状态，从定稿 A 改出。
- **一个地点一张装不下：** 按区域各出一张 `_MV`，全地点共用同一张 D，各张只拍本区，命名 `<场景号>_MV·<地点>·<区域>·多视角定义图`。
- **一次性回忆小景（只有一两镜）：** 不出 `_MV`，出一张场景图，人的位置写进剧本（J-013 第 5 条）。

### 六、交付和入库

- **派单方式：** 一个资产一条单，多个 am 会话并行，交一张审一张；返修在原会话出 r2。
- **回图：** 自动落到本机 `V3\资产\am_回图\<资产名>\`。审过后按 IC 缺图单里的 asset_id 上传，不手建资产行。
- **台账：** 每张一行，写明线程、轮次、审图结论。

### 七、验收标准（全部满足才算这个地点做完）

1. A、B、C、D 是同一个空间，逐件对照表全部一致。
2. 档次、画风和样张一致，不偏动漫。
3. 出入口和动线能让生命周期里所有章的戏走通。
4. 有人的阶段变体以 A 为底，人数、位置和戏份说明一致。
5. 不带人、不带剧情道具、没有可读文字（平面图标注只在 D 格）。


## 四、审图口径（交接原文）

一项不符就退回。

1. **画风：**和样张或 V2 底图并排看，要照片级写实。出现动漫、插画、描边、柔光雾化、塑料皮肤，或者窗外门外是日本街景，都退回。派单里不得出现「动漫」「国漫」「二次元」「插画」，也不得写项目风格名。
2. **_MV 一致性：**按三步法做。先出 A，A 审过后拿 A 换视角出 B 和 C，内容不能变。D 按 A 的实际空间画；同一地点有第二张 _MV 时，直接复用第一张的 D。审图时自己逐行核逐件对照表，不信 am 填的打勾。
3. **机位方向：**朝北看，东在右手；朝南看，东在左手。工位要先在 D 上标出人坐哪一侧、面朝哪边，再推算每一格里看到的是屏幕正面还是背面、椅背还是椅面。
4. **人：**一律是中国人长相，穿当代中国城市普通市民的衣服；人群图要逐张脸看。人数照原著和剧本，不减；站位按底图空间安排。
5. **人物：**左 1/3 是面部特写，右 2/3 是正、侧、背三视图，白底或浅灰底。同一个人的不同服装，脸要一致。拿 V2 图做底时，长相要和 V2 一致。
6. **冲突怎么定：**原著写明的按原著；原著没写的按 V2。例外是同场的季节要一致，比如民警统一穿夏季短袖警服。
7. **UI：**字逐字照缺图单，外观照 A 版。

## 五、常见错误（交接「踩过的坑」原文）

- **派单抄了 IC 项目风格名：**派单里写了「写实偏动漫 3D」，am 就整批画成了动漫风，所有场景只能重做。
- **四格一次出完：**_MV 四格一次出，三个视角根本不是同一个空间。
- **人群画成欧美人：**人群图不写「中国人长相」，am 就画欧美人。
- **布局表拓扑没核：**L01 首版出现了两个出口。派图前要在 D 上把每章谁从哪进、从哪出走一遍。
- **退回意见本身出错：**左右没先写清机位朝向，退回意见里给错了方向，结果多返工了一轮。
