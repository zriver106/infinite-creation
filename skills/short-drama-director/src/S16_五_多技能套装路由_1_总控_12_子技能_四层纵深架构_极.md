## S16 五、多技能套装路由（1 总控 + 12 子技能 · 四层纵深架构） · 极速直出模式的套装编排

### 〔S16-001〕 极速直出模式的套装编排

> **前置：两档运行模式（先分清，再执行——治"严格锁 vs 极速直出"的口径冲突）**
>
> | 模式 | 触发 | 〇·0 赛道 | 〇·1 素材来源 | A 模型 | B 画幅 | C 交付 | D 段缝 |
> |---|---|---|---|---|---|---|---|
> | **严格模式**（默认） | 普通需求 | **必须用户指定**，未指定 = 停下询问 | **必须用户指定**，未指定 = 停下询问 | **必须用户指定**，未指定 = 停下询问 | **必须用户指定**，未指定 = 停下询问 | **必须用户指定**，未指定 = 停下询问 | 多段任务必问 |
> | **极速模式** | 用户说 `跳过确认，直接出整集` | 允许按需求**软推断**（交付首行写明推断结果） | 允许按需求**软推断**（交付首行写明推断结果） | **仍必须用户指定／确认——不推断、不默认** | **仍必须用户指定／确认——不推断、不默认** | **仍必须用户指定／确认——不推断、不默认** | 多段任务必问 |
>
> **为什么只有赛道与素材来源可软推断**：这两项只决定"读哪套规则、从哪起手"，推错可回退；而 **A 模型 / B 画幅是决定下游产物格式的技术锁**（提示词语法、参考图能力、API `aspect_ratio` 回填），推错 = 整包产物作废；**C·交付形态决定最终交付件**（离线看板 / md / 两者 —— ★ 2026-10-13 已由「可默认 ③」升格为强制锁）——替用户猜 = 可能白编译一份他并不需要的看板，**故极速模式也不得替用户猜**。若需求里确无 A/B/C 信息，**极速模式仍须停下来问**——"跳过确认"只跳过过程确认，**不跳过锁**。
>
> **口径优先级**：本表 > 本文件 §〇「任一项未指定 = 任务不开始，禁止默认跳过」。**极速模式是对〇节的明文例外，例外范围仅限〇·0 与〇·1**——〇·0/〇·1 之外的任何"默认"仍然禁止。

`跳过确认，直接出整集` 时按管线顺序执行，**每阶段仍必须按上方【强制读取清单】显式读取对应子技能文件**（"跳过确认"只跳过向用户提问，不跳过读规则、也不跳过 A/B 锁）：**〇·0 读 `track-routing.md` 定赛道**（需求里已含非中文 / 海外信号 → ② 海外剧并加读 `sd-overseas-engine`、第一句对白前建语言合同；含 解说 / 拉片 / 盘点 / 历史人物 / 历史事件 / 科普 信号 → ③ 解说叙事类并加读 `sd-jieshuo-engine`、**先定子类型**；否则 → ① 国内剧；**赛道推断结果须在交付首行说明**）→ **〇·1 定素材来源**（需求里出现"对标 / 参考某部剧 / 最近什么火"→ ③/④ 并加读 `sd-recon-engine`、先出《对标情报卡》；给的是小说/原著 → ②；否则 → ①；**素材来源推断结果须在交付首行说明**）→ **A/B 锁仍须用户指定或确认**（需求未含模型或画幅信息 → 停下询问，**不得推断、不得默认**）→ ⓪ 读 sd-decision-engine → 出情绪锚点表 → ① 读 sd-script-engine 六阶段编剧链（可跳过：已有剧本时；**赛道③ 另叠加 sd-jieshuo-engine 旁白稿规范**）→ **素材形态默认 M1**（用户没提图：出图号 + **《素材接线单》**；说"没有图/不要图号"→ 降 M0 改文字锁；说"图出好了"→ 升 M2；**形态须在交付首行声明**，见 `asset-delivery-modes.md`）→ ② 读 sd-asset-engine → 三清单+**按形态产出**（M0 外观档案复述块 / **M1 出图提示词+编号+接线单** / M2 分批出图；九宫格按模板字段写全；**核心场景另交坐标系与 SET_STATE 状态变体登记**，见 `asset-spatial-ledger.md` §四）→ **②′ 调度环：读总控 `blocking-direction.md` → 建场景坐标系与文字平面图 → 摆人物初始位 → 逐拍走节拍闭环 → 定权力几何 → 记道具账 → 选唯一镜头策略模式**→ ③ 文戏读 sd-storyboard-engine；打戏按档分流——通用武侠读 sd-combat-engine / R3 玄幻读 sd-xuanhuan-engine / R1 真人写实读 sd-real-engine → **③′ 图形化环：读 `sd-storyboard-engine/references/storyboard-sheet-template.md` → 每段一张故事板图（动作相位七态拆格；文戏默认 2×2 四宫格 ≥4 格 / 打戏默认 2×3 六宫格 ≥6 格）→ 出 CLEAN_GRID 无文字版**（跨 2 镜以上叙事段/打戏段/重场戏必出）；**另读 `sd-storyboard-engine/references/plot-deduction-grid.md` 按条件必出规则出场次剧情分镜格**；**两件都逐段/逐场写进 P3 图形化交付清单，不出须写「⛔豁免 + 理由」，禁静默跳过** → ④ 读 sd-feed-engine → 过六道闸门并封装 → ⑤ 读 sd-qc-engine → 台账+机检 → ⑥ 总控看板输出。
