## S08 四、 快速指令路由与模式切换

### 〔S08-001〕 四、 快速指令路由与模式切换

| 常用指令 | 对应功能与底层库调用 |
|---|---|
| **`/写剧本`** 或 **`初始化项目`** | 启动五阶门控剧本引擎，输出前提、因果节拍表与标准排版剧本。 |
| **`/剧组产出册`** 或 **`/生成台账`** | 启动 P2 数字资产包：输出《完整资产清单》→ **按素材形态产出**（M0 外观档案 / M1 出图提示词+编号+接线单 / M2 分批出图）→ 交付对应台账（CHR/AUD/PRP/SCN/Uxx）。 |
| **`/数字资产包`** 或 **`/资产图册`** | P2 核心入口：提取全部实体 → 建案清单确认 → **按形态产出并交付**（M0《外观档案册》/ **M1《资产编号册 + 素材接线单》** / M2《资产图册》）。 |
| **`/素材形态`** 或 **`/接线单`** | **素材形态域**：`/素材形态` 查看或切换 M0/M1/M2；`/接线单` 只出《素材接线单》（图号→用途→你该挂哪张→只控制什么/不控制什么），不改提示词。权威 = `references/asset-delivery-modes.md`。 |
| **`/只要提示词`** | 强制降 **M0**：去掉稿件里所有图号槽位，一致性改由**文字锁**（外观档案复述块）承担。 |
| **`/我图出好了`** | 升级 **M2**：登记《资产图册》并切换到图像级核验。 |
| **`/解说`** 或 **`/旁白稿`** | **赛道③ 解说叙事类**：先定子类型（历史人物志 / 历史事件战役 / 科普知识解说）→ 出旁白稿 VO Script（语速 `4.5~6.5 字/秒` · 钩子 · 金句 · 声画信息差）→ 旁白句→画面分镜。规程见 `sd-jieshuo-engine/`（★权威）；**解说类 C14 配额豁免**——出稿机检必须带 **`--track 3`**（走 C14n，否则 C14 篇幅误报）。 |
| **`/方言配音`** 或 **`/方言`** | **外挂参考**：按地区调取 `references/dialect-voice-control-dictionary.md` 的控制口径，写进对白语气位（音质维）。**非规则域、不改任何既有规则**。 |
| **`/情绪曲线`** 或 **`/情绪节拍`** | 启动 12 节拍情绪量化引擎，输出全片张力诊断表并生成情绪波折折线图。 |
| **`/角色资产板`** 或 **`/角色遗传推导`** | P2c·第一批：T1 男女主锁定脸模 → 亲缘推导 T2/T3 并**直接出图**（非文字描述）→ 交付 4 View 角色资产参考图。 |
| **`/顶视图`** 或 **`/机位调度`** | 绘制空间俯视平面机位调度图，标注 CAM1~CAM4 编号与 180° 动作轴线。 |
| **`/做分镜`** | 自动路由文戏微表情流或武戏 15 格动力链 PREVIS，应用三手法六式衔接；**多段任务先过 D 锁（段缝衔接方式四选一，④ 技巧型转场见 `creative-transition-library.md`），段缝两侧逐对标接缝式（`segment-splicing.md`）**。**镜长按法则 17 由剧情倒推，禁等分；出稿机检 C13 拦镜长雷同。** |
| **`/台词诊断`** 或 **`台词体检`** | 启动台词专科医生，输出角色语言指纹、七维诊断与三段式改写。 |
| **`/微表情`** 或 **`/表情诊断`** | 启动 FACS 微表情引擎：空泛情绪词 → AU 配方替换（四区拆解+强度三档+时序+英文 kernel）；可产出角色情绪库 / FACS cue 表，或按自检清单做表情审查。 |
| **`/表演档案`** 或 **`/表演指导`** | 启动**表演指导层**（`references/acting-direction.md` · 2026-10-09 新增）：按五支柱（目标/障碍与代价/战术/节拍/潜台词）为角色写**表演主档案**（含「然而，当 X——」破功句 + Voice 声线锁）→ P3 落成逐镜**节拍表** → P4 只投喂压缩版（≤2 句进镜行）。**与 `/微表情`（FACS 面部层）正交互补：本命令管「行为与动机」。** |
| **`/语速自检`** 或 **`台词语速检查`** | 启动 dialogue-speed-check 语速自检：拆句 $\rightarrow$ 计数 $\rightarrow$ 套档 $\rightarrow$ 判定。 |
| **`/生成视频提示词`** | 输出 Seedance 2.5 / 2.0 / 即梦分层独立三层解耦提示词组（每组时长按模型契约: 2.5 ≤30s / 2.0 ≤15s / 即梦 5~10s）（⚠️ 画幅必须以用户指定 16:9 或 9:16 为准，禁止默认回落竖屏）。**投喂前必过清单（按序）：① `seedance-render-engine`（三层解耦+时长预算）→ ② `aspect-ratio-adaptation`（画幅回填）→ ③ `camera-specs-15rules`（镜头五要素+景别阶梯）→ ④ 有对白必过 `dialogue-speed-check`（语速自检）+ `wenxi-micro-expression`（金句发酵）+ `model-adapters.md` §5.2（**语气位必写**，2.0/2.5 同规格）；有 OS/VO 必过 `vo-os-weaving`（声画分离/配额）→ ⑤ 战斗段**先定档**（`sd-combat-engine/references/tier-and-finisher-system.md` 〇节）**再取库**：R3玄幻 → `sd-xuanhuan-engine` / R2武侠现代 → `sd-combat-engine` / R1写实 → `sd-real-engine`→ ⑥ 出稿前过 `quality-gate-review` → ⑦ **出稿机检**跑 `scripts/validate_prompt.py <稿> --model 2.5\|2.0`，FAIL 清零才交付。完整执行序列见 `references/prompt-feeding-checklist.md`。** |
| **`/H3提示词`** 或 **`/转H3`** | **MiniMax H3 格式支线**（A 锁选 H3 时自动执行）：把当前七段式投喂稿转成 H3 原生格式——模式路由（T2VA/I2VA/FL2VA/L2VA/Ref2VA）→ 六段式/三字段转换（**正文一律英文** ＋ 切镜动词官方绑定短语 ＋ 画外声官方公式 ＋ 语气位/站位·摆位必入画/首镜锚定·单主体/禁令改法/末帧信息入末镜句尾/音效三层逐条转译；同性别多说话人按官方 issue #17 拉满声学对比或拆段）→ 9 张取材策略 → 出稿跑 `scripts/validate_prompt.py <稿> --model h3`（H1~H12）。规程见 `references/h3-adapter.md`（★权威）。 |
| **`/导出工作流参数`** | 导出适用于 WorkBuddy / 豆包工作流 / Canvas / API 的结构化载荷（⚠️ 载荷内 `aspect_ratio` 回填用户指定画幅）。 |
| **`跳过确认，直接出整集`** | **极速直出模式**：后台静默执行全套工业约束，前台直接输出无后台词污染的成品。**软推断范围仅 〇·0 赛道 / 〇·1 素材来源（须在首行说明）；A 模型 / B 画幅仍须用户指定或确认，不得推断**（见 §五·极速直出模式的套装编排）。 |
| **`/看板`** 或 **`编译看板`** | 把项目 md 一键编译为**单文件离线分镜看板**（`scripts/build_board_lite.py`，双击即开；规范见 `references/storyboard-board-lite.md`）。 |
| **`/审查`** | 启动 P0/P1/P2 独立质检门禁与声音三层相对电平诊断；**改稿复验入口**——修改类任务必须跑「局部验证 → 联动冲突检查 → 全量审核」三步闭环并附《改动复验报告》。 |
| **`/拉片诊改`** 或 **`/验片`** | 启动**多模态成片/废图逆向诊断协议**（`references/quality-gate-review.md` §四）：对照 12 类实拍高频翻车症状→C 码根因矩阵，精准定位跑片崩坏原因并直接产出打好补丁的 V2 重抽提示词。 |
| **`/状态台账`** 或 **`/编译投喂`** | 调用 `scripts/sd_core.py --init-state` 维护跨阶段 `project_state.json`，并用 `scripts/compile_feed.py` 一键编译零格式错误的七段式投喂稿与《素材接线单》。 |
