## J2 资产制作（资产分析、派图、审图时读：生命周期、四问、出图与验收）

执行方：出图、审图走 IC 的资产出图步骤（IC 派 am 出图，IC 的审图 Agent 审）；写分镜、写稿的 Agent 不自己画图顶上。出图与审图细则见 asset-image 技能（审图 Agent 读它）；同一份内容在 `skill_reference(name="adapt-rules", ref="资产出图与审图.md")`（三步法、逐件对照表、常见错误、审图方法）；戏份说明照 `戏份说明模板.md`。

### 〔J-009〕 【待测】【资产】资产图的生成与验收：先排布局、先出 A 再换视角、回图逐件核（2026-11-26 用户点出）

1. 标准（派单照抄）：人物服装图白底或浅灰底，左 1/3 面部特写，右 2/3 全身正、侧、背三视图，比例一致；同一个人换不同服装，脸要一致。场景 `_MV` 是 16:9 的 2×2（A 正打、B 反打、C 侧面、D 正俯视平面），同一空间，不带人、不带剧情道具、格内无可读文字，命名 `<场景号>_MV·<地点>·多视角定义图`。
2. 画风：照抄缺图单开头的「画风」段（照片级写实；不写「动漫」「国漫」「二次元」「插画」和项目风格名）；人物、人群写「中国人长相，当代中国城市普通市民穿着」。审图和画风样张并排比：场景对标 S400_MV、S434_MV、S156、S145、S400_02，人物对标 C001_O57、C003_B、C005_B。
3. 底图：前作有定稿图的，拿它图生图，只去人去字、补关键件；人物长相和底图一致。冲突时场景以底图为准，场景结构（例如走廊是玻璃幕墙还是实墙）也照底图，不自己改；人物、服装、道具原著写明的照原著，原著没写的照底图（例：保安照底图穿黑色制服）。同场季节一致优先于底图（例：同场都是热天，民警统一夏季短袖、不打领带）。差异逐条记进底图差异表，布局表跟着改；以图为准的人物、服装、道具，图审过的同时把资产描述改成照图写（年龄、体型、发型、颜色），不留旧文字。
4. 人数照原著、剧本不减；底图装不下时，站位照底图排：人站过道、门口、隔板后，围成扇形或两三层。
5. `_MV` 三步：先写布局表（固定物的位置、朝向、数量），只出 A；A 审过后图生图换机位出 B、C，内容不变，不一次出四格。D：有底图时按定稿的 A 画，布局表跟着改；没有底图时照布局表画。同一地点第二张 `_MV` 直接复用 D 文件。四张都审过再拼成 2×2 上传。派每一格时写明这一格画面里应数出几排、每排几张、人坐哪侧面朝哪、看到的是屏幕正面还是背面、椅背还是椅面；审单格时和已审过的兄弟格并排比墙、窗、幕墙、家具数量，结构矛盾就退。档次按原著价格和身份线索定（「399一位」就是高端）。昼夜版本共用布局表和 D；一张装不下按区域拆，命名 `<场景号>_MV·<地点>·<区域>·多视角定义图`，共用 D。
6. `_MV` 一律空场；有人的阶段按 J-006 以审过的 A 为底出变体，只加人、陈设逐件保留，命名「地点名·(区域·)阶段」。
7. am 交图附逐件对照表；审图人自己逐件核，一件对不上整张退回。审过按缺图单的 asset_id 覆盖入库，资产说明写布局表和站位表（h3 F5V-001）。规则改了，按旧做法出的同类图重出，按原资产 ID 覆盖。
- 要求：只写要求，不加拦截。
- 反例：派单只写「病房：床、床头柜、椅子」，一次出四格，床头柜三处位置不同，直接导入。

### 〔J-010〕 【待测】【资产】场景按生命周期做：先定这个地点在剧情里从哪章用到哪章，只读这一段，汇总功能区、人数、动线，一次定布局（2026-11-26 用户点出）

1. 定生命周期：用地点名、相关人物、区域词和标志性动作检索全书，找这个地点第一次和最后一次真正在戏里的章（只嘴上提到不算）；回忆、闪回另列；同名不同地的分开立。已有戏份说明的直接当输入，只补缺项，已定的规模口径照用。
2. 只读生命周期内的相关章，写「场所需求分析」进戏份说明（例子见 `戏份说明例_虚构.md`，内容只从本项目原著找）：每章的戏和用到的区域、功能区清单、人数峰值、动线、规模档次、时段昼夜、跨章状态变化；原著明写和想象补写分开标。
2a. 定地点身份进地点表（J-004）：同一家店在不同章出现是同一个地点 ID，原著明写是不同的店才分开。先自己读原著判断，推不出来才列存疑，并写明倾向（同 J-013）。每行：地点 ID｜地点名（全剧唯一）｜首末章｜内外景、门口、昼夜变体｜资产 ID。剧本场头、分镜场景名、绑定只用地点表里的名字和资产。
2b. 出入口拓扑：布局表写清内外出入口几处、各通到哪里；派图前把每章「谁从哪进、从哪出」在 D 上走一遍，走不通先改布局表。
3. 一次定布局：生命周期里所有章要用的功能区放进同一张布局表和 D（J-009），各章照它站位，不每章重排。
4. 人物、道具同样按生命周期追踪服装状态、伤势、归属和数量。
- 要求：只写要求，不加拦截；没有场所需求分析不派图。
- 正例：公司场景读第 1–7 章，得出工位区要容纳约二十人围观、功能区七处、进门正对工位区，一次画全，后面的冲突戏不重做。
- 反例：同一家金店先后绑了五六个不同资产；只按第 1 集做了三张桌子的小办公室，第 6 章全公司围观时装不下。

### 〔J-011〕 【待测】【资产】每个资产开做前先答四问：生命周期、范围、功能、状态，再定大小和要出几张状态图（2026-11-26 用户点出）

人物、服装、场景、道具，开做前都在戏份说明里答四问：
1. 生命周期：第几章到第几章，回忆单独标。
2. 范围：场景几个区域、人数峰值、相连空间；人物和谁同场、在哪些地点；道具数量、在谁手里、在哪些场景。
3. 功能：功能区和动线；道具被拿、递、摔、扫码、开合；人物要演的动作。功能决定结构（能翻的墙、能开的车门）；朝向和结构照现实常识（国内车左舵，公交门在右侧）。
4. 状态：一共几个，各从哪一拍进出、原著依据（人物换装、受伤、弄脏、年龄；场景昼夜、陈设、人数、损毁；道具新旧、开合、数量、归属）。

四问答完再定规模和出几张图：一个状态一张母版，挂在同一身份或地点下（J-004）；新状态要有原著依据，不凭视觉偏好加。缺图单从范围内全部戏份说明汇总，每张状态图都有对应行；局部重跑也出合并的整份，被替代的行标「作废，由第 N 行替代」。
- 要求：只写要求，不加拦截；四问没答完不派图。
- 例：金砖有「完整」「切开一处」两个状态，出两张；只出一张，验货切口那场就对不上。

### 〔J-012〕 【待测】【资产】系统光幕就是「系统」这个角色；通用交通工具怎么立地点（2026-11-26 用户拍板）

- 系统：立成一个角色资产，音色是系统声，外观是光幕；各种版式（面板、提示条、交易界面、倒计时）是它的状态变体，每种一张 UI 母版。母版上的字逐字照缺图单写（缺图单照原著原文），外观照 A 版；不让模型在场景里画字，不另立道具或场景。
- 通用交通工具：观众分不出是哪一辆的过场车，立一个通用地点，各章共用；有整段戏、或原著写明特征的那一辆，单独立地点；其他章的同类车不并进有戏的那一辆。

### 〔J-013〕 【待测】【资产】【剧本】存疑先自己读原著判断；拍不拍按呈现效果；一两次的东西不单独立资产（2026-11-26 用户拍板）

1. 先用原著和剧情逻辑回答，答不出才列存疑，并写明倾向哪个、为什么。例：「这家金店是不是上次那家？」去读原著有没有「怕引人注意、换着店卖」的情节。
2. 拍不拍、拍哪里按呈现效果，宁可拍出来，不偷懒只出声（主管接电话拍他在公司；坐公交、去花店的过场拍出来）。
3. 只出现一两次、后面用得少的东西，不单独立地点或资产（例：饭局视频里的饭店，只做手机屏幕里的内容）。
4. 回忆、闪回：画面能讲清就不拍闪回，讲不清就拍。
5. 一次性回忆小景、回忆服装：见基础段 J 卷开头的写剧本要点（第 5、6 条原文）。
- 要求：只写要求，不加拦截。
