## A 铁律与流程

### 〔A-001〕 【通用】铁律：规则先进 IC，写稿、改稿、出片只走 IC 工作流

由来：Andy 11-23 20:20–20:27 原话：「要同步好才开工」「要走ic工作流.改东西也一样」「没走ic工作流出来的片子一律作废」「质量就算没问题可能风格也不对」「这个是铁律要写进手册」「我们的会话多半是管理工作，查缺补漏辅助ic管理ic工作可持续」「和一些资产生成和绑定」。手册第0章 0.0 同文。本条优先于其他技能正文和任何会话派单。

1. **先同步、再开工。** 规则改了，先同步进 IC 技能并核对已经生效（在 IC 里拼出一条提示词，看得到新规则原文），才写稿、出片。
2. **写稿、改稿、返修只走 IC 工作流。** 剧本、分镜、视频提示词的新写和修改都由 IC 工作流完成（`write_shot_video_prompt`、提示词撰写任务、阶段任务等）。外部会话不得手写稿后直接写库（PATCH、SQL、脚本批量写回都算）。改一句也走 IC。
3. **没走 IC 工作流出来的片子一律作废。** 作废看来源，不看单镜质量（质量没问题，风格也可能不对）。先归档，不删除；对应的镜回到 IC 工作流重写、重出。
4. **会话做管理，IC 做生产。** 指挥系统各会话负责查缺补漏、给 IC 补规则和技能、保证 IC 持续运转、资产生成和绑定；写稿、改稿、出片由 IC 工作流完成。
5. **对 IC 内的写作者：** 你就是这条工作流。接到写稿或改稿任务时，按本技能和对应阶段技能写；不要把稿子交给外部去改再写库。发现规则缺口时，在报告里写明，由管理会话补进技能。

### 〔A-002〕 【通用】作废的审片经验：「正脸改成微侧或低头（为防口型）」

由来：总导 2026-11-23 20:33 拍板，依据 Andy 11-23 20:24 铁律（要走 IC 工作流）与第6集心声镜核查（`M\_\ep6_rule_audit_2025\核查报告.md`：6#7 背向镜头、6#6 和 6#10 为防口型改成低头侧脸，都出自外部会话的审片经验，不在手册里）。

1. 这条经验作废，以手册 M33 第7条为准：镜头只按剧情选，不为防口型背身、遮脸、专选背影，也不为防口型改成低头、侧脸。正脸近景照常可以承载心声；防口型靠自然闭嘴句（M33 第3条）和 M34。
2. M33 第6、7、8条现在是错误，不是提醒（检查器 `inner_voice_check_m33_678.py`）：一个镜头（`[Shot N]`）里不能既有心声又有出口台词；不写背向镜头、脸转开、只见后脑、捂嘴、遮脸、「为防口型」；心声窗口写明「The inner voice runs from Xs to Ys」，到切点或段末、两句之间、与对白之间都至少 0.8 秒。

### 〔A-004〕 【通用】文案问题提前解决，出片链不等稿

由来：Andy 原话「文案的问题一律要提前解决提前安排claude新会话搞定」（总导 2026-11-24 02:41 转令）。

1. **文案问题一律提前解决。** 剧本、分镜、提示词、修改要求、服装描述有问题，在出片之前解决，不留到出片时或出片后再改。
2. **怎么解决。** 管理会话提前开 Claude 新会话来改，按集或按段拆开并发，每个会话用完就清理；范围只按 Andy 的问题文档；改稿走 IC 工作流（指定镜重写），过门禁后用 `--after` 排进出片链队尾。
3. **出片链不等稿。** GPU 照常出已过门禁的镜；没改好、没过门禁的镜不进当前链，也不让链停下来等稿。
4. **对 IC 内的写作者：** 写稿时发现本镜文案（台词、服装描述、修改要求）与原著、绑定或问题文档对不上，能在本次任务里改好的改好再存；改不了的在报告里写明，由管理会话提前安排。

### 〔A-005〕 【待测】【通用】改稿只增不删锁

- 目的：重写剧本、分镜或提示词时不丢已有的锁（重写丢服装、人数、场景、视线锁是反复出现的错）。
- 做法：改一镜前先列出旧稿里的锁：服装、在场人物和人数、场景、背景人群、站位和视线、心声闭嘴、身份、道具数量；新稿逐项保留，措辞可改，内容不减。
- 要求：旧稿有的锁新稿缺了就不保存，补回再存。只有修改要求明说删、或剧情变了（人离场、换装那一拍）才删，并在报告里写明删了哪条、为什么。规则口径变了的存量扫描见 h3-prompt-writing X-010；导出前核写入来源见 X-011。
- 校验：报告写「旧锁 N 条，保留 N 条，删 0 条（或删 k 条及原因）」；写库前对锁做新旧比对，丢锁即退回（钩子待加）。
- 正例：只改一句台词的重写，visual 里的服装描述、人数和背景人群句照旧都在。
- 反例：重写分镜时整段重写，原来的服装描述丢了，提示词跟着丢了服装锁。

### 〔A-006〕 【待测】【通用】出片主链：资产齐且对 → 逐镜绑定 → 写稿 → 出片 → 对照审查 → 导出，按顺序做、每步留记录

- 目的：多数一致性错误出在源头，比如缺资产、资产文字与图不符、该绑没绑。源头齐了、对了，写稿和出片才有依据；模型自己画偏的那部分，靠出片后的对照审查兜住。
- 做法（每章按顺序做，每步留记录）：
  1. 资产齐：按分镜列出本章出场的有名人物、各人本场服装、场景（按剧情阶段，见 J-006）、关键道具，逐项查资产库；缺的先导入资产表里已有的定稿或出图（J-007），新配角先做防撞脸比对（J-003）。
  2. 资产对：资产说明的颜色、款式、陈设与图一致（J-005）；同一地点只用一套场景资产（J-004）。
  3. 逐镜绑定（操作细则见 J-008）：每镜出场的人物、他的本场服装、对应阶段的场景、画面里的关键道具都绑上；伤情、疲态按原著程度，用户有裁定的照裁定。
  4. 写稿：照绑定的资产写，同场的服装、陈设、背景人群逐字一致（h3 F-001、FX-005）。
  5. 出片。
  6. 对照审查：导出前拼同人同装、同场景对照图，交独立审片（h3 X-012）。
  7. 导出交付。
- 要求：第 1–3 步的缺口清单（缺什么、谁补、补没补）写进本章记录。资产文字与图不符（第 2 步）先改文字再写稿；缺图的不等图：人物先用基础形象、场景先用现有图写稿出片，同时列进缺图单，图到了再补绑重出（J-006、J-007），缺口只报警告（只报不拦）。第 6 步高、中问题未清不导出。
- 校验：本章记录里有资产清单、绑定检查结果（「有人物没绑其服装」「场景阶段不符」的计数）、对照审查结论。
- 正例：开写前发现两位配角没有服装、宴会场只有空场图，先导入定稿、补出满座变体，绑好再写，出片后对照图上全场一致。
- 反例：资产没齐就写稿出片，出完才发现配角每镜换衣、背景时有时无，整场重出。
