## S 分镜（同场锁、换装、站位、节奏、参考图）

### 【分镜】同场锁、换装、站位和节奏

1. **每镜绑场景（TR-V12）。** `scene_ids` 不得为空；同场景的镜共用同一张场景图和同一句场景句。
2. **在场的人都绑上（TR-B03）。** 站位表里落在这一镜画框内的人（画面边缘、前景虚焦、背影都算）都进 `character_ids`，没台词也要绑；框外的人写明在框外哪一侧。多人镜写人数和「每人只出现一次」（提示词写法见 h3-prompt-writing「Same-scene presence and costume lock」第 8、9 条）。
3. **服装同场继承，换装只从原著那一拍起（TR-B02）。** 同场、时间连续的镜，同一人物沿用前几镜的 `costume_ids`；只有原著或剧本写明换衣服（换衣、穿上或脱下外套）的那一镜起才换。受伤、弄脏、淋湿、疲惫是状态，写成文字叠在原服装上，不换 `costume_ids`。
4. **脸部状态按剧情节点锁（TR-V01）。** 疲态、眼袋、气色变好这类脸上看得见的状态，按原著定开始和结束的那一拍；开始前、结束后各自整段统一，不只写在个别镜里。眼周只写形态和程度，不写颜色深浅。
5. **电话那头的人也绑（TR-V02）。** 电话戏里，打电话那头的人即使不入画也进 `character_ids`，IC 才会给他挂音色参考；否则声音会中途变。
6. **相邻镜站位（TR-V10）。** 同场每镜都写清谁在谁的哪一侧（推搡、拉扯、拥抱之后也写）。只有同场、动作连续的两镜，下一镜才写「人物左右站位与上一镜相同」，再写谁在哪侧；换机位、跳切、换时间的镜只写新构图里的左右关系。只写人的位置，不写把机位锁到上一镜最后一帧的句子。
7. **交易按步骤拍（TR-V06）。** 扫码付款（收款方亮码、付款方拿手机扫）、到账提示、转账成功界面：剧情需要几步就拍几步，让观众看得懂；手机屏幕当道具绑定，不用计算器之类代替。
8. **打戏正常速度（TR-V08）。** 因果紧挨着：挨打到倒地 ≤ 1 秒；后果（掉牙、出血，按过审尺度，不特写血腥）落地即出现，然后才有人说话；旁观者同一秒反应；重物到手马上往下坠；人群后退是脚着地往后走，不飘。
9. **特效在当前景别里出（TR-V05）。** 能力特效（系统光、眼里的数据）在这一镜原来的景别里出，不为特效切近景、特写；有系统光幕的镜固定机位。
10. **Q 版镜 ≥ 4 秒并带特效（TR-V07）。** 只在 Q 版规则本身允许用 Q 版时适用；Q 版只用于极端情绪，本条不鼓励多用。
11. **系统声。** 原著里系统说话的镜，`dialogue` 照常登记系统这句话的完整原文（说话人写「系统」），提示词把完整原文写进 `<d>`、由 H3 直出；光幕上只画一两行短字（取自这句原文）。原著只有界面、系统没说话的，不新增系统台词。旁白不变，仍后期配。

### 【待测】【分镜】【提示词】人数锁覆盖前景、边缘、半截头肩和倒影（TR-B09，双人复制）

人数锁不只写「每人只出现一次」，还要覆盖前景、画面边缘、被裁掉一半的头和肩、背影、玻璃或镜子里的倒影。主角已经在画面里时，不再拿他做前景的半截头肩（这一镜换成不带他前景的构图）。h3-prompt-writing 禁止过肩写法，连否定写法也不写；需要前景人物时写「被裁掉一半的头和肩是〈某人〉的」，并且这个人确实绑定、确实在场。

### 【待测】【分镜】【提示词】机位距离、景别、人物位置不能互相矛盾（TR-D01，双人复制）

同一镜里，机位放在哪、离人多远，必须拍得出要求的景别。机位在桌子另一头、隔着整个房间时，不能同时要求「胸以上近景」；画外的人不写在「紧挨镜头」的位置（模型会在镜头旁再补一个人）。要近景就写机位离被拍的人约一米、第一帧起就是近景、中间没有别人。正常推、拉、跟、摇照常用，不是要求整镜固定。

### 【待测】【分镜】【提示词】姿态、座位继承（G07、TR-B05，场内继承）

同场每镜开头写清每人站着还是坐着、坐在哪个位置，和上一镜结尾一致；要从坐到站（或反过来），镜内写出起身、坐下的动作，不能下一镜直接变了。同桌的两人写相对关系：「A 在桌子左端，B 在右端，隔着桌子正对面，不并排、不成直角」；没人坐的那条边写「没人坐也没人站」。特写镜也写。不能让人物无缘无故站起来、坐到别人腿上。

### 【待测】【分镜】【提示词】桌面和可数道具锁（TR-B06、TR-B07、TR-B08）

1. **可数道具写数量和位置。** 桌上、手里能数的道具（杯、盘、金条、钥匙、电脑）写「正好 N 个、在哪、没人碰」，直到原著写明拿走；拿走那一镜写开场还在哪、第几秒拿起。不凭空多出一台电脑、一束花、一杯奶茶。交易数量按原著（卖几根金条就上几根秤）。
2. **道具离手写去向。** 递出、收起、放下之后写清在谁手里、在哪；后面的镜同步删掉「在桌上」的描述。
3. **桌面锁同场逐字一致。** 同场连续多镜，桌子、桌面上的东西、窗外景、背景、座椅材质写成同一句锁句，逐字照抄；不能只写一句「window table」。

### 【待测】【分镜】【提示词】背景人群锁（G05，场景一致性）

办公室、商场、包厢这类有背景人的场景，每镜写同一句背景人群句：大约多少人、在做什么、虚化、不说话。不能前一镜满屋子人、下一镜空无一人；剧情要这些人离开的，把离开的过程拍出来。

### 【待测】【分镜】【提示词】相邻镜、跨集首镜写开场状态句（G17，场内继承）

同一场、动作连续的相邻镜（包括跨集：上一集最后一镜到下一集第一镜），下一镜提示词开头写一句开场状态句：地点、每人站位或坐位、服装、手里和桌上的东西，和上一镜结尾一致。只写人和物，不写把机位锁到上一镜最后一帧的句子（同【分镜】第 6 条）。

### 【待测】【分镜】服装按原著当前那一身，跨集首镜接上一集（TR-C01、TR-C02）

每章开写前，先按原著查每个角色这时候穿的是哪一身（原著没写换衣服、也没有换衣服的条件，就沿用上一身），`costume_ids` 照这个绑，而不是照「这一章登记的资产」绑。下一集第一镜的服装和上一集最后一镜一致，除非原著在这中间换了衣服。总导或 Andy 明确改了某一场的服装（例如「进店时改穿白T」），从那一场起按新服装绑。

### 【待测】【分镜】【提示词】人物身份：小角色也写服装 ID 和性别（G01、G02，人物一致性）

每个绑定的具名人物（包括中介、经理、同学、邻桌客人这类小角色，包括背影和虚焦里的人），定义句都写服装 ID（颜色＋衣物＋发型，照抄绑定的服装资产），并带一个性别词（a man / a woman），同章同场逐字一致；不能只写「名字，职业」（只写名字时中介被画成了女的）。按 h3-prompt-writing 的 R22，定义句不写脸、年龄、材质、配饰描写（T9 G01 草案里的「大致年龄」不采用）。主角和反复出现的角色，每镜加一句身份锁：同一个人、每镜同一张脸、性别不变、发型不变（句式同 h3-prompt-writing 同场节第 8 条的「a different man with a different face」写法）；人设没有的配饰（眼镜等）写明不戴。不写会改脸的特写（青筋暴起、疤），除非剧情要、而且有状态图。

### 【待测】【分镜】【提示词】关键道具和车绑我方定稿，品牌型号照原著（G10）

正文提到主角的车、店里的展车、金条这类关键道具，`prop_ids` 绑我方定稿道具；品牌和型号照原著（奥迪店里摆奥迪，不摆别的牌子；原著写奥迪 A4 就是 A4）。同场道具绑定前后一致。

### 【待测】【剧本】【分镜】剧情和动作要合原著、合常理（G23）

1. 人物动作要有原著依据，合乎当时的关系和处境：原著没写打人就不打人；该搓手就别鼓掌；没理由不站起来。
2. 台词要让观众听得懂：改写后的台词意思不能变怪（「这空气，有点东西」这类观众听不懂的改法不用，按原著意思说清楚）；语气按人物当时的处境（退缩的人说和解是怂的语气）；台词归属按原著（隔壁桌客人的话不给经理）。
3. 前后两场之间剧情跳得太快、观众接不上时，加一两个简单的衔接镜（人物走进店、谁进门了），让下一句台词有来由。
4. 说话的人要对着说话对象；人物进店、走动的路线和站位按剧情的空间来（从店外走进店里，而不是一开始就面对面）。

### 参考图照着演，不整张贴进画面

参考图是用来还原人物身份和造型的，人物要在场景里活起来，用参考图的长相和服装去演本镜动作。

已交付 EP1–EP11 实测：H3 常在镜头开头（少数在结尾）把参考图原样直出 2–31 帧。闪出来的不是剧情画面，而是灰棚或白底的全身站姿、左特写加右三视图合板、服装商品图、Q 版合板，或道具多角度板。根因是人物、服装、道具的参考图本身就是这类设定板，系统又把原图整张送给 H3。

硬规矩（分镜和视频提示词都必须守；`h3-prompt-writing` 现有手册已到字数上限，细节以本节为准）：

1. 每一镜 0 秒必须已经在剧情场景里。禁止先出现参考图、设定图、三视图、灰棚或白底全身站姿、服装商品图、Q 版合板、道具多角度板。结尾同样不得切回这些板。
2. `__MINIMAX_H3_REF_N__` 照参考图还原长相与服装，不整张贴进画面。不要写 show the reference image、character sheet、turnaround、catalog photo、white background portrait。开场第一句写清场景、人物位置和景别。
3. 提示词时间轴开头加一句（可略作改写，意思不能丢）：`Use the reference images to recreate the characters' faces, hair and outfits inside the scene; never paste a reference board, turnaround or studio portrait onto the screen as its own frame. The shot starts already inside the scene.`
4. Q 版照 Q 版合板的造型来演，合板格子或单人白底设定图不整幅切进画面。

## C 分镜层心声

### 心声（OS）镜铁律

心声 = 角色没说出口的内心独白，由 H3 在本镜里直接念出（写进 `<d>`），画面里的人自然闭嘴。分镜层先把心声标出来，下游的 h3-prompt-writing 按心声节写提示词。2026-11-23 第6集实测：写嘴的词（连「抿成一线」「不张嘴」这类否定写法也算）反而让 H3 动嘴，所以分镜里一个嘴部词都不写。

1. **标记**：心声在 `dialogue` 和 `sub_shots` 里一律写成 `角色名（OS）：原文`（例：`江澈（OS）：这得有1000克吧？！`）；普通对白写 `角色名：台词`。电话声、系统声、旁白不是 OS。原文一字不改。此处「原文」指**已锁定的剧本台词**。若剧本层（`references/novel-to-script.md`「表现手段入口 · 剧本层」）已把原著「卧槽」升级为显示字「我cy！」并附 `[配音：我去！]`，则 `dialogue` 逐字写显示字，实念字按 `sd-storyboard-engine`「夸张表演、特效与 Q 版」甲·4 用 `【表现】…配音替换` 交给提示词；不得改回原脏话。
2. **不强制单独成镜**：心声按剧情放在当前镜头里，可以压在动作上，人不为听心声停下来（TR-V09），也不为心声单独剪一镜。**一镜只有一种人声（手册 M33 第6条）**：这里的「镜」是视频里两个切点之间的一个镜头（提示词里的一个 `[Shot N]`）。有心声（或电话那头、系统声）的镜头里不放任何出口台词；同一条分镜里既有对白又有心声时，在 `sub_shots` 里用硬切分成两个镜头（各 ≥ 3 秒），对白一个镜头、心声一个镜头，中间隔 ≥ 0.8 秒；分镜太短分不开就拆成两条分镜。心声窗口整个落在自己的镜头里，不跨切点。
3. **同场心声合镜**：同一场景里连续的心声（中间没有别人开口）合进同一镜，镜长 ≤15 秒。
   - **心声原文一字不改**：**禁止**删字、改字、换词、把两句改写成一句、改写语序。唯一例外是念出来的数字：按 TR-V14 写成口语汉字（「月薪三千五百」写「三千五」，「1000克」写「一千克」），`dialogue`、`<d>`、`sub_shots` 三处一致。冲突、打戏里太长的心声可以按原著意思压短（TR-V09），三处同改。
4. **机位只按剧情选**：背影、物件特写、反应镜、空镜、正脸近景都可以，只按剧情选，不为防对口型选机位，没有比例上限；不用捂嘴、背身、遮脸这类回避写法。不要求「正面近景、嘴在画面中间」（原第4条作废）。心声镜里别人在场照常绑定、照常写站位，不说话。
5. **表演只写眼、眉、头、肩、手**：`visual` / `sub_shots` 里每个露脸的人，开头写手册原句「他双唇自然合拢，嘴角放平，下颌放松，整个镜头里他只用眼睛、眉头和肩膀表现情绪。」，镜尾写「双唇一直自然合拢，保持到镜头结束。」每个心声窗口写 2–3 个眼神、眉头、点头摇头、肩膀、手的动作，贴合这句心声的意思，相邻两句至少换一项。整镜不写任何嘴部和呼吸的词，否定写法也不写（抿嘴、抿成一线、咬唇、撇嘴、苦笑、憋笑、咧嘴、张嘴、不张嘴、叹气、倒吸凉气、嘟囔、喘、胸口起伏都不写）。心声窗口里不吃、不喝、不拿筷子勺子杯子往脸前送（原第5条「闭着的嘴型」写法作废）。
6. **不写台账词**：不要在镜头描述里写「台词：无」「（无对白）」「（沉默）」这类字样，下游会被念出来；没有台词的镜头 `dialogue` 留空即可。
7. **连排**：整章不要连续 3 镜都是心声。

## H2 表现手段（Q 版、特效、谐音；冷门）

### 表现手段入口

四类手段：**Q 版插入、夸张特效、网络流行语与过审谐音、段子与接梗**。口径：表情表演 > 特效 > Q 版 > 心声。能用眼神、动作、对白、闪回或特效让观众看懂的，不要改成内心独白；只有完全无法演出来时才用心声。

**先看开关（v4）：** 任务文本里若有「本项目表现手段开关」一段，先读其中四项：**Q版插入、夸张特效、网络流行语与谐音、段子与接梗**。被关掉的手段本章一律不用，本节里和它相关的条目、配额、选择表那一列都不适用（改用真实表演；台词保持原著平实说法）。没有这一段，视为四项全开。开关只管「能不能用」：开着也要按选点标准和上限来，不是必须用。**（v4.4-B）开关段里那句「不是每章必须用，宁缺毋滥」说的是不堆砌：本章没有够格的点可以不用；有够格的点（见各层手册里的「本剧落点」）却一处不落，算漏做，不算克制。**

**Q 版门槛与名额（v4.5，2026-11-16 Andy 定；优先于本节和 `sd-storyboard-engine` 里 Q 版的旧配额与「漏做」口径）：** Q 版默认不用。只给全章最极端、而且 Q 版明显比真人表情加动作更好看的那一处；其余「极端」点（包括剧本写了「可选：Q版」的）一律真人表演，Q 版不算漏做。每章最多 1 处；第 2 处只在两处都是全章顶点、方式不同、相隔 ≥3 个场次且成片相隔 ≥90 秒时才允许。上一章用过的 Q 版动作或表情，本章不重复。方式一（身旁小人）给独处憋笑的狂喜，方式二（换头）给被规则当头一棒的无语，同一拍只用一种。该镜 `props` 必须绑定素材库里已有图的「角色名·Q版设定」；没有或没图就不出 Q 版、改真人表演，并在 `report` 写明缺哪个角色；不得新建、生图，也不得凭写实参考自由发挥 Q 版造型。Q 版镜头的【表现】行必须写明具体表情（眉眼和嘴的样子，例：眼皮半垂、眼神发直、嘴抿成一条线），不写 shock、surprised、「震惊」这类笼统词；Q 版设定合板只作造型参考，不得照抄合板里的表情格。
