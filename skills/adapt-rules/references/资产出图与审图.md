# 资产出图与审图（adapt J2 的细则）

对应规则：adapt J-009（出图与验收）、J-010（生命周期与地点表）、J-011（四问）、J-006（有人的阶段变体）、J-001 / J-002（名副其实）；写稿怎么用 `_MV` 见 h3 F5V-001。执行方：IC 资产出图步骤派 am 出图，IC 的审图 Agent 审；写分镜、写稿的 Agent 不自己画图顶上。同一份内容按段整理在 asset-image 技能（审图 Agent 读那份），两处同改。

多视角图是场景的地基：站位、机位方向、人物进出、跨章布局都从它来。它错了，后面的分镜、提示词、出片怎么改都改不对，所以这一步宁可慢，一次做对。

## 一、开做前要有的东西（缺一样不派图）

| 输入 | 内容 |
|---|---|
| 戏份说明 | 生命周期、每章用到的区域、人数峰值、动线、四问答案（J-010、J-011） |
| 档次 | 按原著的价格、品牌、身份线索定，写明「不能像」什么（例：「399一位」是高端餐厅，不能像食堂） |
| 布局表 | 每件固定物（门、窗、柜台、桌椅、过道、灯具、设施）的位置、朝向、数量 |
| 出入口拓扑 | 内外出入口几处、各通到哪里；派图前把每章「谁从哪进、从哪出」在 D 上走一遍，走不通先改布局表 |
| 机位和朝向 | 每格机位站在哪、朝哪；人坐家具哪一侧、面朝哪；时段和光线方向 |
| 画风样张 | 场景 S400_MV、S434_MV、S156、S145、S400_02；人物 C001_O57、C003_B、C005_B |
| 底图（有前作定稿时） | A 格拿它图生图：保留空间、装潢、材质、画风和场景结构，只去人去字、补关键件。和布局表冲突时以底图为准，差异逐条记进底图差异表，交 IC 重跑资产分析让布局表跟底图对齐，不手改 |

## 二、出图三步（每一步审过才进下一步）

1. **只出 A 主视角一张。** 派单写：布局表要点、档次、画风段（见第六节）、不带人、不带剧情道具、没有可读文字。审 A：布局表逐件对，看档次，和画风样张并排比，过了才定稿。
2. **拿定稿的 A 换视角出 B（反打）、C（侧面）。** 图生图只换机位，桌椅数量款式、墙地材质、灯具、陈设、光线都和 A 一样。逐件拿 A 对：A 有的，B、C 对应位置也有，数量、款式、朝向一样；A 没有的，B、C 不能多。B、C 里每件家具看到的那一面，要和 A 相反或侧转（A 看到椅背，B 就看到椅面）。
3. **D 平面图：** 有底图时按定稿的 A 画，布局表跟着改；没有底图时照布局表画。A、B、C 每件东西在 D 上都找得到。同一地点第二张 `_MV` 直接复用第一张的 D 文件，不重画。四张都审过，再拼成 2×2 上传。

## 三、逐件对照表（am 交图必附，审图逐行核）

| 物件 | 数量 | 款式 | 布局表位置（写到偏东、偏西、正中这一级） | 朝向 | A 里在哪 | B 里在哪 | C 里在哪 | D 上在哪 | 一致？ |
|---|---|---|---|---|---|---|---|---|---|

## 四、审图方法与纪律

1. **遮名看图（J-002）：** 遮住资产名和描述，只看图说出这是什么地方；和用途不一样就不合格。审图的人不是画图的人。
2. **对标志物清单（J-001、J-002）：** 派图单写的「必须有什么、不能像什么」逐项对：必须有的齐，易混场所的标志物一样都没有。拿不准的找这类场所的实景照片对一下。
   - 派图句：「场景〔名称〕：是〔什么地方、做什么用〕；必须有〔标志物〕；不能像〔易混场所〕，不出现〔那种场所的标志物〕；对应原著〔段落〕。」
   - 审图句：「遮名看图：看着是〔 〕，与用途〔一致／不一致〕；必须有的〔齐／缺〕；不该有的〔无／有：写明〕；结论〔入库／重出〕。」
   - 入库描述写三项：用途、必须有的标志物、不能像的场所。审不过的不入库；已入库才发现名不副实的标「勿用」，换新图，列出绑过旧图的全部镜交导出环节。
3. **自己逐行核，不信自填的 ✓。** am 自填的对照表常全打勾，其实有错。
4. **一行对不上整张退，** 不改其中一格凑合。
5. **退回意见先写机位朝向，再推左右，** 免得把左右说反、多返工一轮。
6. **机位、朝向、坐向推算法：** 先在 D 上标出人坐哪侧、面朝哪，再按每格机位推出看到的是屏幕正面还是背面、椅背还是椅面。朝北看东在右手，朝南看东在左手。长排家具先在 D 上定走向，再推每格里是横向还是纵深（东西向的长排，从西往东拍是顺着视线往里延伸）。
7. **外景格：** 透过门窗看到的内部照 D；窗外、门外是故事发生地的街景（中国城市街道）。

## 五、常见错误（见到就退）

| 错误 | 例子 | 怎么防 |
|---|---|---|
| 左右镜像 | 电子秤 A 在左、B 在右；A 格整体左右反了 | 先对 D 再对 A；反打的左右按机位推算 |
| 数量、款式变了 | 每桌一个锅变成两个；多出一组柜子 | 逐件对照表 |
| 门窗、出入口和布局表不符 | 东墙画成了窗；一个地点出现两个出口 | 出入口拓扑写进派单，派图前在 D 上走一遍 |
| 档次不对 | 高端自助画成食堂 | 派单写明档次和「不能像」 |
| 画风偏动漫、日系 | 平涂天空和树、墙地无材质、人物日漫脸加描边、车内柔光雾化、门外是日本住宅街。根因：派单抄了项目风格名 | 派单禁用动漫类词，写「照片级写实摄影」；A 先和样张并排比 |
| 常识错 | 国内公交驾驶位画在右 | 四问的「功能」照现实常识（J-011） |
| 四格不是同一空间 | 一次出四格，三个视角各是一个地方 | 先 A 后换视角 |
| 侧面格照抄正面构图 | C 从西往东看，东西向柜台应纵深延伸，却画成横在正前方 | 派单写每格机位朝向 |
| 透过门窗的室内和 D 不符 | 店外格透过橱窗看到柜台贴玻璃，D 上柜台在深处 | 外景格要求「透过门窗看到的内部照 D」 |
| 屏幕、桌面朝向自相矛盾 | 工位面北、人坐南侧，A、B 两格却都画成屏幕朝镜头 | 第四节第 6 条推算法 |
| 数量和排数不对 | 布局表 3 排 × 7，画成 4–5 排 | 对照表单列「数量」 |
| 位置偏移 | 门在「南墙偏西」画到正中 | 位置写到偏东、偏西、正中 |
| 几格家具款式、画风、光线不一 | A、B 有隔板 C 没有；A、B 像实拍 C 像 CG；要近中午画成金黄夕阳 | 审 B、C 时和 A 并排比；派单写时段和光线方向 |
| 四格款式、排数、朝向各不相同（典型反例） | 工位区 A 矮隔板 4 排以上，B 后排无隔板 5 排，C 高隔板纵深；布局表其实是 3 排、全部面北 | 三步法，每格逐件对 A |
| 人群长相不对 | 故事在中国城市，围观者全是欧美长相 | 人物、人群单写「中国人长相，当代中国城市普通市民穿着」，逐张脸核 |
| 同一地点几张 D 画法不同 | 布局一致、画法不同 | 第二张复用第一张的 D |

## 六、画风段（派单照抄）

照片级写实室内（或街景）摄影，像建筑效果图或实拍剧照；真实建材纹理（墙面、地砖、木纹、金属），真实光源阴影，写实透视，正常饱和度；不要动画背景画风、平涂、描边、柔光雾化、高饱和卡通色、日系街景；窗外、门外一律是中国城市街道。派单里不写「动漫」「国漫」「二次元」「插画」，也不写项目风格名。人物和人群写「中国人长相，当代中国城市普通市民穿着」。

## 七、变体和多张

- **有人的阶段：** 以审过的 A 为底，同机位同装潢，只加人，底图陈设逐件保留；人群位置照 D；中国人长相，按剧情季节穿，脚不能踩出铺地范围。人数照原著剧本不减，装不下就站过道、门口、隔板后，围成扇形或两三层。
- **昼夜、营业前后：** 同一布局表、同一 D，从定稿 A 只改光线和陈设状态。
- **一张装不下：** 按区域各出一张 `_MV`，共用 D。
- **道具状态图**（切开、散落等）：以审过的完整图为底，不以前作原图为底。
- **一次性回忆小景：** 不出 `_MV`，出一张场景图（J-013 第 5 条）。

## 八、派单与入库

一个资产一条单，多个 am 线程并行，交一张审一张；返修在原线程出 rN。审过后按缺图单的 asset_id 覆盖上传，不手建资产行。台账每张一行：线程、轮次、审图结论。

## 九、审图口径（7 条，一项不符就退）

1. 画风：和样张或底图并排看，照片级写实；动漫、插画、描边、柔光雾化、塑料皮肤、日本街景都退。前作人物底图本身有塑料皮肤、偶像脸的，照样按真人质感退回，不照底图放行。
2. `_MV` 一致性：照三步法；对照表自己逐行核。
3. 机位方向：先在 D 上标坐向和朝向，再推每格看到哪一面。
4. 人：中国人长相、当代中国城市普通市民穿着，人群逐张脸看；人数照原著剧本不减，站位按底图空间排。
5. 人物：左 1/3 面部特写，右 2/3 正、侧、背三视图，白底或浅灰底；同一人不同服装脸一致；拿底图做时长相和底图一致。
6. 冲突：原著写明的照原著，原著没写的照底图；场景结构照底图；同场季节一致优先于底图。
7. UI：字逐字照缺图单，外观照 A 版。

## 十、验收（全部满足才算这个地点做完）

1. A、B、C、D 是同一个空间，逐件对照表全部一致。
2. 档次、画风和样张一致，不偏动漫。
3. 出入口和动线让生命周期里所有章的戏都走得通。
4. 有人的阶段变体以 A 为底，人数、位置和戏份说明一致。
5. 不带人、不带剧情道具、没有可读文字（平面图标注只在 D 格）。
