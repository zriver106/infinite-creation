# 剧本样稿（R-004～R-008 的参照：节拍表、场头锁定、画面行与运镜、少用心声、表演说明、场间衔接、转换说明）

> 依据：adapt R-004～R-008，以及《叙述转换方法》（已按本项目改过：表演说明要落成看得见的动作；屏幕、光幕上的字用 UI 母版或后期做；闪回只用原著已有的；准确的信息优先放光幕和屏幕）。
> 写法：故事尽量用镜头和运镜讲，心声只留不得不说的几句；一条画面行只写一个时刻；运镜用手册「运镜与景别」的说法；场与场之间写一行衔接。场头锁定只在第 1 场和地点、在场人物变了的场写全，服装只写名字，不抄颜色款式；有母本的地点只写「照母本」加本场站位点。叙述转换表和自检不写进剧本，章末只写一两行转换说明。原著 2108 字。

## 一、本章节拍表

- **主角阶段：** 月薪三千五的普通白领，被生活压着，敢怒不敢言；系统刚出现，半信半疑。
